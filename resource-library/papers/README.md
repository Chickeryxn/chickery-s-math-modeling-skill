# papers/ —— 优秀论文

放**你自己有权使用**的优秀论文（PDF/MD）。每条 = 论文文件 + 同名前缀说明。

## 格式

```
papers/<题目>_<方法>.pdf     # 论文原文
papers/<题目>_<方法>.md      # 说明（同名同前缀）
```

说明模板（`papers/example.md` 可参考）：

```markdown
# <题目>_<方法> 论文说明

- **来源**：<竞赛/出处/链接>
- **亮点**（为什么优秀，2–3 条）：
  - 摘要每问有数、结论可辩护
  - 模型选择理由充分（多范式对比）
  - 图/表达到发表级
- **可迁移要点**（训练时学什么）：
  - 数学素养：<模型抽象/公式严谨>
  - 绘图素养：<配色/版式/标注>
  - 表达素养：<结构/逻辑链/语言>
- **局限**（诚实记录，别只学优点）
```

> 示例文件 `example.md` 为自写演示模板，非真实竞赛内容；`example.txt` 占位可删除。
