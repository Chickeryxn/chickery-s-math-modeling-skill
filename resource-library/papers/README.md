# papers/ —— 优秀论文

放**你自己有权使用**的优秀论文（PDF/MD），训练对照"数学/表达/证据/完整"素养。每条目二选一：

- **条目目录**（推荐）：`papers/<entry_id>/{README.md, content/(论文 PDF/MD), code/(复现脚本可选), figures/(文中关键图可选)}`
- **扁平条目**（兼容）：`papers/<题目>_<方法>.pdf` + `papers/<题目>_<方法>.md` 同名前缀说明。

`content/`、`code/`、`figures/` 为支持目录，由 `scripts/resource_index.py` 归入 `supporting`。
