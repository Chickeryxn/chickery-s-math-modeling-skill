## 亮点（结构层面，为什么值得学）
### 整体结构
- **总—分—总骨架**：摘要每问给一个可辩护的数值结论；正文"问题分析 → 假设 → 符号表 → 逐问建模/求解/验证/分析 → 模型评价 → 结论 → 参考文献 → 附录源码与文件清单"。
- **一个主骨架贯穿全题**：所有子问题复用同一个核心递推/模型，子问题间是**递进依赖**（如 Q3 复用 Q2 碰撞库、Q5 复用 Q4 调头库），而非每题另起炉灶。
- **每问一个完整闭环**：建模型 → 求解（含"为何不选另一范式"）→ 结果呈现（图+表+一核心数）→ 结果分析（含物理解释）。
- **附可复现证据**：附录代码 + 文件清单 + 关键结果表，数字可逐项复算。

### 局部结构
- **每段先结论后展开**；建模决策链写成可检查的"为什么选它 / 为什么不用另一范式"。
- **公式纪律**：编号 + 符号表 + 适用前提 + 数值算例 + 陷阱；正文引用编号严格对应。
- **表格纪律**：booktabs 三线表、列自解释、单位入表头、一张表只讲一个结论、带不确定性/来源。
- **图**：一图一结论、宏观看趋势 + 局部看关键、标单位与显著性。

## 建模决策链（结构层面）
- 先定主线（主骨架）再分问展开，避免"各答各的"；每问的产出最终回到主线。

## 结果呈现（结构层面）
- 结论逐问可查、可复算；用"对象×时刻"网格表 + 关键量汇总表支撑，而非大段文字。
