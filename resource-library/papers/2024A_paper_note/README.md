## 亮点（为什么优秀）
- **同一骨架反复复用**：一串定长连接的刚体沿已知曲线运动，"参数化 → 弧长反参 → 弦约束递推 → 投影传速"这条链贯穿全部子问，把"连续动力学"降为"单点约束迭代"。可解析、可复查、物理清楚。
- **同解可行、路径可异**：同一结论可用解析闭式、隐式+求导、差商、启发式搜索等不同手段达成；选择取决于问题性质（可解析/单峰/不可导），而非"越高级越好"。这是多范式视角的经验。
- **降维是战略决策**：把"两两全检"缩成"代表集"、把"碰撞"缩成"点-线距离"，靠同质性/单调性论证；代价是近似，须诚实标注。

## 建模决策链
- 为什么先参数化后递推：路径已知（曲线），用真实运动学微分方程反而刚度大、需耦合求解；用"前把手→后把手"的显式递推更干净。
- 为什么不用同一套高级算法：不同子问性质不同（求位置/速度→可用解析；求碰撞边界→需几何判据+二分/遍历；求最小螺距/最大速度→单参数或峰值问题，可用遍历/三分/比例缩放），按需选型。

## 结果呈现
- 每问配"图（宏观+局部）+ 结果表（对象×时刻）+ 一核心数"，数字可逐项复算；用初始条件做端点自洽校验（如极径 = b·θ₀）。

## 素养对照（可迁移规则，逐维只填真正示范的）
- **数学素养**：先把动态问题几何化、离散成链式递推；弧长反参依赖单调性，须先证单调再二分。
- **创新素养**：多范式视角（解析/隐式/启发式按题选型）；把"优化/寻优"降成"求解/比值"。
- **表达素养**：结论逐问给数；决策链写"为什么选它/为什么不选另一范式"。
- **证据素养**：结果可溯源、端点自洽；对近似与多解诚实标注，而非隐瞒。
- **完整素养**：问题全覆盖；局限（碰撞近似、缺灵敏度）诚实记录。
