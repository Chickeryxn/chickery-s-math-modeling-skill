## 亮点（为什么优秀）
- **把隐性成本/时间货币化（机会成本）**：排队等待的空耗、空跑成本、潜在载客收益损失统一折算成"单位时间净收益"，再在"排队/空返"间做二选一——这是排队/等待决策的通用范式；比较两个时长不同的方案先归一化为单位时间净收益再判号，切勿直接用总量。
- **"单位时间净收益阈值"定分界**：用"收益相等"的平衡点给司机的决策分界（sgn 判号），把经验判断翻译成可比较的量。
- **排队/系统模拟 + 分状态实验设计**：把复杂、随机、规则驱动的流程显式化为"到达分布→放行机制→状态机→截止时间→多次取均值"，再用单点扰动一个"人为设定参数（截止时间/权重）"检验稳定性；机理可解析用排队论/生灭过程，否则离散事件模拟。
- **上车点/乘车效率优化**：双车道泊位排队论（泊松流/指数完成率）+ 目标优化（max 每小时驶离量/效率=1/(平均乘客逗留+平均车辆逗留)）+ 蒙特卡洛搜索泊位数，给"上车点非越多越好"。
- **收益均衡/短途优先权**：用价值函数/双目标加权（空载率+单位时间收益差）给短途再次返回的出租车插队位置，使收益尽量均衡。
- **同解可行、路径可异**：三篇在"决策"上用 0-1 选择/收益函数+蒙特卡洛、生灭过程+净收益+sgn、单位时间收益+平衡曲线；在"效率"上用 交通流+一元优化、上车点排队论+蒙特卡洛；在"优先权"上用 收益均衡临界值、优先插队模型、双目标加权。

## 建模决策链
- 为什么先"货币化/量纲归一"：排队与空返时长不同，只有拉平到"单位时间净收益"才可比、可判号。
- 为什么用模拟而非纯解析：机场队列有长度上限/拒绝/分批放行/错位离开等复杂规则，解析排队论难封闭表达，模拟可显式化。

## 结果呈现
- 决策分界时段（高峰等待/低谷空返）、各时段单位时间/总收益、上车点与泊位数/效率、短途优先权插队位置；用"高峰等待低谷空返、上车点非越多越好、短途应更靠前、收益均衡"支撑。

- **口径/数值冲突**：车流量均值 65.23 vs 46.29 vs 65（等待时间 16.3 vs 23.8 不可复现）、距离临界 21 vs 30km、车速临界 50 vs 65、Q4 项 31 位 vs 摘要 15 位、π1=λ45.9 却用 44.3、π2 硬编码 0.1。
