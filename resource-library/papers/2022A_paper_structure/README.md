## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述 → 受力分析/假设 → 符号表 → 逐问"建模（ODE）→ 求解（解析/数值）→ 目标优化 → 结果表 → 检验" → 评价/推广 → 附录（参数 + 代码）**。
- **每问在上一问基础上扩展自由度**（垂荡→垂荡+纵摇、单阻尼→双阻尼），体现"场景递进、内核复用"。
- **每问给"时程表 + 最优参数表 + 模型检验"**，并附物理参数/几何参数附录。

### 局部结构
- **符号表先定且唯一**：区分浮子/振子下标、直线/旋转阻尼、功率口径（复振幅 vs 瞬时速度）、频率/单位。
- **公式-代码-表一致**：正文 ODE、求解方程、代码实现、结果表口径对齐；非线性阻尼（$eta|v|^alpha v$）与功率（$eta|v|^{2+alpha}$）的 $alpha$ 含义一致。
- **假设回验**：用"最大位移<安全高度、角位移<小角阈值、FFT 峰=激励频率"验证假设成立。
- **最优性说明**：说明最优是否落在边界/局部、是否需放宽区间；解析-数值交叉验证给误差。

## 建模决策链（结构层面）
- 说明为何用"方程结构定路线"、为何用"小量/解耦"、为何取"稳态平均"，并给收敛/最优性说明。

- 位移/速度/角位移/角速度时程 + 最优阻尼/功率表；用 Q2 vs Q4 对比说明"多通道增益"。

## 局限与反例（本地结构/证据差错即失可信）
- A001：频率/单位/符号口径与赛题不一致、阻尼力与功率 α 口径不一致、忽略纵摇对垂荡假设与三/四问矛盾。
- A022：正文与代码 D/A 公式不一致、跨问参数不衔接、解耦近似不自洽（角位移近8°）、功率口径漂移致系统差 0.16W。
- A171：摘要 mm 与正文 m、sin/cos、α/β 语义相反、ω 与 mc/fmax 跨处不一致、约束 x1≤2 vs 2.8；Q4 目标式排版错乱。
- 教训：**符号/单位/频率/功率口径必须唯一；公式-代码-表一致；假设用数据回验并给边界**。
