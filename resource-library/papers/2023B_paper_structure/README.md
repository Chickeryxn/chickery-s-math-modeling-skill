## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述 → 符号/假设 → 逐问"几何建模（Q1/Q2）→ 布设优化（Q3/Q4）→ 结果表 → 评价" → 附录代码/数据**。
- **场景递进**：从"给位置算覆盖"到"三维方向"到"真实地形布线"，每问在上一问基础上最小扩展。
- **每问给"计算表 + 布设结果表"**，并用临界/漏测/超重叠段体现口径与边界。

### 局部结构
- **单位与口径一致**：m / 海里（1海里=1852m）、总长单位、覆盖率与漏测率互补（漏测 2.3% ⇔ 覆盖 97.7%）。
- **展示公式 = 计算模型**：正文推导式与代码/表值一致，否则读者无法复现。
- **重叠率定义口径一致**：d 取水平间距或坡面投影、由平坡公式切换到含 D 的口径都要交代。
- **误差量化**：分块拟合残差、启发式 vs 贪心 的差异给具体值。

## 局限与反例（本地结构/证据差错即失可信）
- B226：4海里=6814m（算错）、"东西向 vs 平行等深线"矛盾、表2 中心核对缺失。
- B311：式(5)与代码不一致（127 vs 243m）、总长 466394m vs 336.7 海里矛盾、覆盖 100% 与漏测 2.3% 矛盾、双模型仅凭"CAD 作图"选型无定量依据。
- B477：总长/覆盖率口径与摘要不一致、符号乱码、贪心/飞蛾火焰仅局部最优未证。
- 教训：**单位与覆盖率/漏测率互补关系、公式=计算、双模型选择要有定量依据**。
