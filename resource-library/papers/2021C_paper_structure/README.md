## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述/数据说明 → 假设 → 符号 → 逐问"评价(Q1)→最少家数+订购+转运(Q2)→结构优化(Q3)→产能(Q4)" → 结果表(入选/方案/指标) → 效果分析 → 评价 → 附录(数据 + 代码)**。
- **"评价→规划"为主脉**，Q3/Q4 在 Q2 基础上加结构约束/改边界。

### 局部结构
- **口径/单位唯一**：万 m³ 与 m³、成本（元/m³ vs 万元/千m³）、α（损耗率）、供货量/订货量/接收量/库存；三类原料统一换算成"可产产品"。
- **参数有来源与敏感性**：λ、α、权重、发电机/回归超参给取值与为何，并做敏感性。
- **随机性给稳健性**：随机分布给多实现/置信区间；"模拟值/近似解"如实标注。
- **公式-正文-代码一致**：评价指标、约束、目标、实现对齐；"至少几家/产能提高多少"给出明确可核结果。

## 局限与反例（本地结构/证据差错即失可信）
- C066：单位/符号混乱、剔 33 家武断、代码与正文冲突（402×24×2 vs 369、α=0.05 vs 1.34%）、随机性缺稳健性量化。
- C169：摘要成本 1.0925 与表 1.52-1.65 矛盾、订供偏差 e^-r-1 vs 代码 exp(-2DR)、问题4 公式留空、"一家尽量一家转运商"弱化、α=0.8 缺出处。
- C085：Q4 B类 66777.3 量级笔误、完成率区间型口径矛盾、损耗率当常数违背随机规划框架。
- C283：Δw 一除一乘方向矛盾、正文"选公式C"与代码乘法 Gmean×(1.3+…) 不一致、Q2"至少几家"答成随机模拟区间、Q4 仿真值存疑。
- 教训：**口径/单位唯一、公式-正文-代码一致、参数有来源与敏感性、随机性给稳健性、问题口径（至少/提高多少）给确定可核结果**。
