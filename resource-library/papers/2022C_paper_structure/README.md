## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述/数据说明（成分性、有效度 85~105%、缺失=未检出）→ 预处理（剔除无效、缺失替换、clr 变换）→ 假设 → 符号 → 逐问"关联(Q1)→分类(Q2)→鉴别(Q3)→关联差异(Q4)" → 结果表 → 评价/敏感性 → 附录（代码 + 数据）**。
- **"数据特殊性→预处理→方法"作为开篇主线**，先讲清"定和/缺失/风化"如何驱动方法选型。

### 局部结构
- **符号表先定且唯一**：成分名、浓度/对数比值、定类编码、检验量；避免 x̃ 双义、颜色 0-7 与名称 7 不符。
- **预处理口径一致**：剔除有效度外样本、缺失替换值（检出下限 vs 0）、clr 补值与代码一致。
- **分类结果给阈值/边界 + 交叉检验**：决策树阈值、SVM 边界、PLS 主成分；不给"正确率 100%"这类未经交叉验证的表述夸饰。
- **外推/估计如实标注**：风化前预测是估计，说明样本与误差；样本不平衡如实说明。

## 建模决策链（结构层面）
- 说明为何用 clr、为何弃黑箱、为何"缺失即信息、与风化分离"、为何取某分类特征。

## 结果呈现（结构层面）
- 关联检验值（卡方/Fisher p、秩相关、关联度）、分类/亚类阈值与结果、未知鉴别、关联差异；用敏感性（扰动/阈值）支撑稳健性。

## 局限与反例（本地结构/证据差错即失可信）
- C065：风化前还原实为组内平移（仅1件配对）、缺失统一填 0.04、计数口径矛盾（34/24 vs 37）、正文系数与 R 代码不一致、亚类标签逐点手调。
- C155：符号 x̃ 双义、颜色 0-7 与名称 7、表头误标、决策树四指标全=1 近退化、回归 R² 低却"不变"、d'=√d 无依据、灰关联敏感性未分析。
- C229：符号 c/e_j 矛盾、Pearson/Spearman 口径混用、几何均值按百分比展示但口径在单形、"正确率100%"仅一次划分无留出、Q4 配对 Wilcoxon 样本小且相关不独立。
- 教训：**符号与预处理口径唯一、分类/相关性给交叉验证与敏感性、外推与不平衡如实标注**。
