## 亮点（为什么优秀）
- **"尺度折减"建模**：用数量级论证（压力波速~800m/s、流口流速仅20mm/ms、每毫秒进出<容器体积0.05%）把非定常可压缩 PDE 安全退化为 **0D 集总参数**（质量守恒→密度/压强差分）——"当空间非均匀对目标贡献可忽略、特征尺度差≥2~3 量级时，用集总参数替代分布参数，并给出量级证明报告而不是只声明假设"。
- **对象-结构建模（耦合块）**：把不可解析周期系统拆成"质量守恒 + 孔口节流律（Q=CA√(2ΔP/ρ)）+ 本构（dP=(E/ρ)dρ）"的耦合块，逐层加子系统（柱塞腔、双喷油嘴、减压阀）。
- **稳态控制 = 周期内偏差平方和**：把"稳定在期望值附近"写成 $\int(P-P_e)^2 dt$ 最小（周期边界、喷油 100ms/凸轮 2π/ω/腔压周期复位）；"稳定在 Pe"变成偏差平方和最小。
- **求解降维**：利用"稳态压力-决策变量一一对应 + 目标下凸"，用差分 + 参数遍历（粗-细/坐标下降）把多变量无约束优化降成一串单变量扫描；仅当目标非凸/无唯一对应才换全局/随机算法。
- **模型迁移复用**：问题1核心守恒模型被问题2/3 复用扩展（加子系统、改参数）。
- **同解可行、路径可异**：三篇在"控制方案"上用 开阀时长遍历、凸轮角速度 + 针阀、双喷 + 减压阀（阈值式 vs 电磁式）；在"求解"上 遍历+多项式拟合、粗-细两段搜索、坐标下降；都遵循"守恒+节流+本构→周期边界→偏差平方和→搜索"。

## 建模决策链
- 为什么用集总/0D：目标只是"稳定工作点"，题给集总参数；用数量级证明可降维。
- 为什么把"稳定"写成偏差平方和：周期激励系统，稳定=周期内偏离期望最小，可离散求。

## 结果呈现
- 最优开阀时长/凸轮角速度/喷油时差/减压阀参数、压力波动幅值与判稳（偏差和/方差）、是否满足稳态；用"稳定 100→150MPa 开阀 0.29→0.72~0.9ms、能贴阈值泄压的减压阀优于电磁阀"支撑结论。

## 局限与反例
- **口径/单位混乱**：ω rad/s vs rad/ms（差1000倍、摘要比正文差一量级、图题注"rad/s"）、"27-29S"应为 rad/s、开阀 0.75 vs 0.76、泄压阀阈值 100 vs 100.5、喷油时差 45/50、代码 ω=110 vs 正文 440。
- **证据弱**：判稳仅"偏差和 Ze→0"且只截最后 1 秒/周期，无波动幅值与方差，未做 dt/P_R/步长敏感性，作者自称"难以检验"。
- **强假设削弱物理**：假设"腔内压力处处相等、忽略传播时间"，恰好消掉长管（500mm）的核心压力波效应；改进段才用 u=√(E/ρ) 补救（与题意"压力波动"相悖）；把拟合 E(P) 直接对 ρ 积分是简化。
- **搜索/拟合粗糙**：遍历+阈值给网格次优而非全局；未稳定段 t0(t) 仅凭"曲线最平滑"盲选线性；针阀面积用圆台母线近似、查表精度依赖 dt/插值。
