## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述（两决策/变量/约束）→ 假设 → 符号 → 逐问"决策模型(Q1)→真实数据方案(Q2)→上车点效率(Q3)→优先权均衡(Q4) → 结果表 → 敏感性/鲁棒 → 评价 → 附录（数据 + 代码）"**。
- **"决策→数据→效率→均衡"递进**，每问复用决策/收益框架。

### 局部结构
- **口径/单位唯一**：单位时间收益（元/h）、等待/排队（min）、车流量（辆/h）、距离（km）、泊位；成本与收益同一口径。
- **数据来源明确 + 可复现**：用真实机场数据或标明借用；关键参数（k1/k2/L/D/S/τ）给值；分布给来源或说明主观并给敏感性。
- **数值落地**：问题3/4 给具体数值（泊位数、上车点数、效率、插队位置），不只给符号解。
- **敏感性/鲁棒**：单因素扫参 + 高斯/扰动噪声鲁棒；截止时间/权重单点扰动；"优先/效率"给定量比对（有无基准/误差带）。

## 建模决策链（结构层面）
- 说明为何用单位时间净收益/生灭/模拟/排队论，为何"高峰等待低谷空返""上车点非越多越好""收益均衡"。

## 结果呈现（结构层面）
- 决策分界时段、各时段收益、上车点/泊位数/效率、优先权插队位置；用"高峰等待低谷空返、上车点非越多越好（效率 0.0465→0.135 等）、短途更靠前、收益均衡"支撑。

## 局限与反例（本地结构/证据差错即失可信）
- C044：车流量 65.23 vs 46.29 vs 65（等待时间 16.3 vs 23.8）、π1=λ45.9 用 44.3、π2 硬编码 0.1、关键参数未给、问题3 只给符号解、假设"仅经济因素"冲突、问题4 n=2。
- C137：距离临界 21 vs 30、车速 50 vs 65、Q4 31 位 vs 摘要 15 位、式号图号重复、方案二恒负"收益最大化"实为损失最小化、附件"8-9L/km"笔误、α2 无实质作用。
- C308：K(t) 0.15/0.45 vs 代码 0.15/0.2、taxiratio 1.807 vs N_c 1.81、表4 标题误写、附录 D 模板残留（从高压油管论文复制）、生灭用常数 μ/λ 但客流强时变、"准确率"只能是时段长度保持率非预测精度。
- 教训：**口径/单位唯一、数据来源明确与参数给值、数值落地、敏感性/鲁棒定量、避免模板残留与"收益最大化"实为损失最小化**。
