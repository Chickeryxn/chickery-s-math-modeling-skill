## 亮点（为什么优秀）
- **先识别数据数学结构再选方法**：成分占比满足"定和=100%、只含相对（比率）信息、缺失即信息"的强约束，因此先在**单形/闭合几何**内选工具——Aitchison 几何均值、中心对数比变换（clr/ilr）、Dirichlet 回归、PLS-DA/VIP。切忌对原始占比直接算相关/欧氏距离（违反定和）。
- **用可逆坐标变换把"相对含量"对齐到欧氏度量**：\`clr(x)=ln(x/g(x))\` 把单形等距映射到欧氏空间，使相关、聚类、分类、回归合法，并使累加和=100%；用 clr 逆变换外推时保守恒。
- **"缺失即信息"与风化效应分离**：未检出（空白）不是 0，需用检出下限/替换并且与"风化导致成分变化"分开；用 85%~105% 判定有效数据。
- **方法-约束适配**：定类变量→卡方（含 Yates 校正）；小样本+需可解释→弃黑箱，用线性 SVM/决策树/描述统计；守恒外推→回归+clr 逆变换；小样本关联→灰色关联。
- **同解可行、路径可异**：三篇在"分类"上分别用 决策树（PbO 阈值）、线性 SVM 边界、PLS-DA/VIP；在"亚类"上用 层次聚类/R 型→Q 型、kmeans+VIP；在"关联"上用 灰色关联、CLR 协方差 SVD-PCA、配对 Wilcoxon；在"风化前预测"上用 回归+clr 逆变换、组均值平移。

## 建模决策链
- 为什么先做 clr/闭合：成分数据信息全在相对大小，欧氏统计（均值、相关、欧氏距离）会失真且违反定和；clr 是保持信息的可逆映射。
- 为什么用小样本/可解释的工具：样本仅数十件、且要"区分/风化前还原/分类规律"可解释，故弃黑箱，选能给出显式边界/规则的模型。

## 结果呈现
- 风化-类型/纹饰/颜色关联检验（卡方/Fisher p 值）、分类/亚类结果与阈值、未知样品鉴别、两类关联结构差异；用"仅类型与风化相关（p≈0.02）""PbO 阈值为主要分类特征""两类关联结构不同"支撑结论。

## 局限与反例
- **符号/口径混乱**：符号表 x̃ 双义（峰度/中位数）、颜色编码 0-7 但名称 7、表头误标、c/e_j 矛盾、Pearson/Spearman 前后混用。
- **过拟合/退化**：决策树四指标全=1 且仅靠单变量 PbO 阈值——样本近可分，属退化，缺交叉验证；SVM 边界/决策树阈值依赖具体划分与参数。
- **风化前预测是估计**：回归+clr 逆变换、组均值平移均为外推；仅 1 件配对样本、回归 R² 低至 0.24 却"不变"处理、d'=√d 无依据。
- **缺失/依赖**：未检出统一填 0.04 混淆"未检出"与 0；clr 对 0 无定义，补值处理与代码不统一；灰色关联对补值、量纲预处理的敏感性未分析；样本不平衡（18 vs 49）。
