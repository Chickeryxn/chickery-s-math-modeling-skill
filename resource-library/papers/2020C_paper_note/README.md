## 亮点（为什么优秀）
- **"评分→组合优化"两段式解耦**：先用可解释评分/模型把"风险"压成 $[0,1]$ 概率（违约概率/守约率），把它作为**下游优化模型的已知系数**，再做"收益-风险+资源约束"的信贷组合优化——逐段可检、可解释。
- **特征工程 → 业务语义指标**：从发票/交易/纳税/上下游/失信数据提取"实力、信誉、供求稳定性、供应链粘性、作废票比、利润/增值税"等可解释指标（先清洗：剔作废发票、去异常、补缺失），再进评分。
- **按"样本量/是否可解释/是否黑箱"选风险模型**：样本百级+需可解释 → Logistic/评分卡/PCA 综合指数；样本偏多且想提准 → 集成软投票（Logistic+AdaBoost+GBDT+SVM+RF）给连续概率；已知 4 类评级 → XGBoost 多分类；缺标签 → 最近邻/两级网络/聚类插补（伪标签/迁移），并给评估（准确率/AUC）与基线对比。
- **外部冲击 = 输入扰动/风险乘数，而非重建模**：按行业/规模折价、疫情风险乘数 β（聚类分层×评级交叉）、FTP 利率、信贷偏向——只改输入或加乘数，不改模型结构，且做稳健性。
- **风险-收益-流失多目标 + 约束**：额度/利率区间、总预算、期限、流失率上限；用单目标加权/多目标（GA/非线性规划/fmincon/LINGO），含违约损失率与客户流失折减。
- **同解可行、路径可异**：五篇在"评分"上用 Logistic、PCA 综合指数、熵权+TOPSIS、GBDT、Soft Voting、XGBoost 多分类、两级 BP；在"决策"上 多目标非线性规划、GA、LINGO、fmincon；在外部冲击上用 折价、风险乘数、FTP、情景。

## 建模决策链
- 为什么先评分再优化：违约概率/评级是"风险度量"，先参数化，再作为优化目标/约束的已知系数。
- 为什么用可解释模型：样本小+银行需可解释+要连续额度利率，故弃黑箱/分类收尾，用可解释回归/评分卡。

## 结果呈现
- 特征/评分权重、违约概率与评级分布、信贷策略（额度/利率/拒贷）、组合收益/风险、外部冲击后调整；用"高信用→额度大利率低、D 级拒贷、评分-评级交叉差异化"支撑结论。

## 局限与反例
- **口径/单位混乱**：金额"元"与约束"万元"、利率 %、额度区间；同一损失率前后矛盾（0.22 全损 vs 只损利息 (1-2R)）；"供货量/额度/资金"复用。
- **公式-代码-结果冲突**：正文 [r-(1-p)]x vs LINGO (r-p)x、总额 ≤30200 vs ≤10000、系数（γ3 -0.1042 vs -0.1142）、交易处理数留"xxx"占位、结果未满足自身约束（表各行加总 ≠ 总额）。
- **候选过拟合/无验证**：训练 1.0 vs 测试 0.806-0.871 明显过拟合却评价"完美"；无训练/测试划分、无 AUC/回测、无树/集成基线；测试样本少（13 家）正确率 61.5-76.9% 不代表；级联误差（用预测值当输入）。
- **假设过强/主观**：总体风险=最大单笔风险、同等级违约率相同（忽略相关性）；β、流失率、FTP、风险乘数主观无敏感性；违约概率>50% 硬截断；d(I) 人工未校准；熵权"客观"却与 0.5×信用得分加权、部分权重不均衡（税项 0.37 vs 利润 0.001）。
