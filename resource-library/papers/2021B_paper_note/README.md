## 亮点（为什么优秀）
- **先在候选模型上用同一可度指标实测权衡再定型**：对"温度→转化率/选择性"用 线性/二次/S 型/Logistic/三次多项式 同场比 R²/MSE 后定（二次 R²≈0.98、Logistic 用于 S 型），避免先验偏好；凭"n 点对 n 参必 R²=1"拒用四次多项式（防过拟合）。
- **多因变量诊断**：用偏最小二乘（PLS）判断多因变量是否真相关，若与多元回归（MLR）差异很小，就退回更简单、可解释的 MLR。
- **多因素工作流递进**：控制变量定性 → 正交试验+极差降维排序 → 标准化多元二次响应面+逐步回归（含交互）→ 盒约束二次优化求收率峰值；并把"标准化回归系数"作为影响度（可比、无量大�rd），避免普通系数误导。
- **业务定义目标**：收率=转化率×选择性（$\omega=\eta\cdot z$），先把业务口径定死再建模。
- **实验设计**：补空白温度点/验证非偶然/均匀设计（次数少信息多）/加权欧氏距离广度模型（最大化与已有组合的最小距离）——有明确设计原则与理由。
- **同解可行、路径可异**：四篇在"关系建模"上用 二次/三次拟合、BP 神经网络、响应面+逐步回归、Logistic/一元二次+ANOVA；在"收率优化"上用 fmincon/quadprog/LINGO/NN；在"实验设计"上用 均匀设计、补空白、加权欧氏距离广度。

## 建模决策链
- 为什么先定型再优化：关系未定时目标（收率）不能可靠外推；先用简单可解释模型拟合且避免过拟合。
- 为什么用标准化系数/响应面：多因素+含交互+非单调时，需正交/逐步回归提取主效应与交互、标准化消除量纲、再加盒约束优化。

## 结果呈现
- 各组合"温度-转化率/选择性/收率"关系、最优催化剂组合与温度（含<350℃）、因素显著性（双因素 ANOVA/逐步回归）、5 次补充实验表；用"温度对转化率/选择性影响均最大、Co负载×装料比的交互、收率峰值在 407~450℃"支撑结论。

## 局限与反例
- **口径/符号混乱**：正文回归系数与附录/代码/目标函数不符（−3619.647… vs −6314.470…、β 系数错位、−27.7 vs −25.3）、"转化率/选择性"口径混用、同一 R² 正文与附录对不上。
- **结果矛盾/互斥**：两版 Q3 并存且数值冲突（33.86% vs 56.3%）；摘要"Co负载对选择性影响最大"与正文"温度影响最大"相反；Q3 只搜 21 组合却断言全局峰高于局部。
- **统计/设计缺陷**：正交表重复且 K/k 自相矛盾；ANOVA 显著却称"方差齐"；符号表水平数与表不符；均值差之和非标准未校正；Logistic x_m 远>100% 作代理判据；优化区间外推（250-450 vs 250-500）、目标含交叉项非凸使 quadprog 未必全局；样本少（组合 4-6 点拟合 3 参）过拟合；"10%→18%"误判为"较稳定"实为敏感。
