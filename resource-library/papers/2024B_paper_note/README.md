## 亮点（为什么优秀）
- **抽样先定性再定量**：先明确"信度/置信度"属于**检验决策**而非区间估计，把 95%/90% 翻译成第一/二类错误（α,β）与 OC 函数约束，再用正态近似 / t 分布 / 功效函数定最小样本量。
- **期望值决策**：把生产流程（检测/装配/拆解/调换/回流）抽象成"决策向量（0/1：是否检测/拆解）+ 价值函数（收益−各类成本）"。两个关键工程抽象是**检测后次品率更新** $P^*=P(1-x)/(1-xP)$ 与**成品次品率连乘合成** $1-prod(1-P^*_i)(1-P_{proc})$。
- **规模定范式**：小规模（2⁴=16）可闭式期望全枚举；多工序/决策爆炸用**状态-决策 + 动态规划**；更大或无解析才上启发式（退火/ACO/GA），并说明为何弃用精确法。
- **不确定回灌**：次品率由抽样测得，用**贝叶斯共轭后验（Beta×二项）**给后验均值与置信区间，端点重跑做敏度；或用 **3σ 最坏情形**做鲁棒性。
- **同解可行、路径可异**：Q1 三篇分别用功效函数+权重、`(n,c)` 双风险+正态近似、t 分布+工程容差；Q2/Q3 分别用闭式期望+枚举、决策向量+退火、决策树+蒙特卡洛+ACO/GA。选择取决于是否可闭式、规模、是否要精确，而非"越高级越好"。

## 建模决策链
- 为什么先抽象"成分更新/合格率合成"再算期望：质量流的关键是"筛选/剔除后剩余率与成分如何变、下游合格率如何连乘"，写清这两个抽象才能让成本随决策正确耦合。
- 为什么按规模选范式：枚举直观但随决策点指数爆炸；DP 求期望可复用到 m 工序/n 零配件；启发式只在无解析/多峰/大规模时使用。

## 结果呈现
- 决策结论用"0/1 决策表 + 指标值（元/件）+ 决策依据"呈现；多情形对比表须标"参数不同故跨情形不可直接比较"；对次品率扰动给出决策稳定区间。
