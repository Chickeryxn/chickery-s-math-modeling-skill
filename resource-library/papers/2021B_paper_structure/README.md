## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述（变量/指标定义：转化率/选择性/收率）→ 数据预处理 → 假设 → 符号 → 逐问"关系(Q1)→因素(Q2)→优化(Q3)→实验设计(Q4)" → 结果表 → 评价 → 附录（数据 + 代码 + 实验表）**。
- **先定业务口径（收率=转化率×选择性）再建模**，使目标明确。

### 局部结构
- **符号/口径唯一**：转化率 η、选择性 z、收率 ω=η·z；装料比 vs 负载量；组合编号 A/B。
- **模型一致**：正文回归系数与附录/代码一致；"同一 R²/MSE"不前后矛盾；两版结果不并存。
- **统计严谨**：R²/调整 R²、MSE、F、p、显著性；模型选型给同场比较与"为何不用另一范式"；防过拟合说明。
- **实验设计给原则与理由**：补空白/均匀/广度、样本量依据；不把"最优"说成"全局最优"。

## 建模决策链（结构层面）
- 说明为何用某关系模型（同场权衡）、为何用响应面/标准化、为何盒约束外推要谨慎。

## 结果呈现（结构层面）
- 各问"关系系数 + 显著性 + 最优组合/收率 + 补充实验表"；用"温度影响最大、交互显著、收率峰值在中高温"支撑结论。

## 局限与反例（本地结构/证据差错即失可信）
- B007：正文收率系数与附录 LINGO 目标不符、主/次要副产物命名不一、同一 R² 对不上、方差判读矛盾、样本少过拟合、收率阈值筛选带偏、10%→18% 误判稳定。
- B026：选择性/C4转化率口径混用、Logistic x_m>100%、式34 与代码不一致（-27.7 vs -25.3）、HAP 上限 50 vs 200、符号表 14 vs 21 水平、Q4 无功效/样本量依据。
- B050：Q3 只搜 21 组合却断言全局峰高于局部、两最佳家族互斥、Q4 未给全局峰、NN 权重≠严格重要性、197-273min 达平衡仅凭两点。
- B160：表2/3 系数与附录多项式错位、两版 Q3 矛盾、正交表重复且 K/k 矛盾、摘要与正文结论相反、定性 x5/x6 直接回归、优化区间外推。
- 教训：**系数/结果/代码一致、统计严谨（同场权衡/显著性/防过拟合）、"最优/全局/稳定"措辞谨慎**。
