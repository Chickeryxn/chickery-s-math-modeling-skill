## 亮点（为什么优秀）
- **物理抽象连环简化**：把不可控现实降为可算理想链——"鼓=刚体、球=质点、绳手水平、小角度、对称假设"，再逐问放宽（碰撞瞬时→引入 t0/冲量/功/恢复系数、三维）。
- **状态分解 + 空间旋转**：平动与转动分解、时间离散化递推；空间旋转用**四元数**（避欧拉角奇异）或小角度解耦（小角度可交换性把三自由度降为二自由度 α/β）。
- **先反演、再控制**：当只能观察到末端结果、缺中间状态/输入（如缺水平分量速度、差异发力）时，先建一个**反演重现模型**（最小二乘）把缺失量逆推出来，再做正向控制——可用于任何"给定结果反推初因"的诊断/控制问题。
- **多目标→无量纲化→启发式全局优化**：当优化关系无法线性/凸表达时，不硬套 LP，改用抗多峰非凸的**模拟退火**，并把工程偏好（用力均匀性、同时性、突变小）**编码成无量纲化因子**做单目标加权，再用相对误差做软约束。
- **约束化降维搜索**："全员同时发力 + 至多 2 人加额外力"等压缩搜索空间；用对称性/引理（小角度、全同步）减少自由变量。
- **同解可行、路径可异**：三篇在"理想策略"上用 最小总力/单位功率、一维碰撞对称解；在"倾斜模型"上用 小角度刚体旋转+方向余弦、四元数+时间离散、转动定律+几何力矩；在"调整策略"上用 定性规则+几何、反演重现+正控、沿轴零力矩。

## 建模决策链
- 为什么先理想后现实：理想情形无实测，只能从质点-刚体力学正向推导；再在理想基础上放松假设（误差/三维/噪声）。
- 为什么用刚体+质点/小角度/对称：先做可算近似，用误差量级与物理合理性论证，再逐步放宽。

## 结果呈现
- 理想最优（力/时机/颠高）、各工况 0.1s 倾角、调整策略（力/时机、颠高、倾角）、精确控制下各队员力/时机与误差下的实施效果；用"小角度解耦可行、全同步+对称补偿、先反演再正控"支撑。
