## 亮点（为什么优秀）
- **忠实的大规模指派建模**：用"决策张量（地块×季节×作物×年份）= 连续面积 + 0-1 开关 + 大 M 衔接"；约束（地块面积、地块-作物适配、不重茬、三年豆类、最小面积、分散度）写成**集合分块 + 求和限维**；"超量滞销/五折"用 `min(·)+α(·)₊` 分段收益并线性化。这是把业务规则翻成可解模型的标准动作。
- **按规模与精度选求解器**：规模可控用精确全局求解器（Gurobi/LINGO）保证最优；更大/强非线性用启发式（DEGA/GA）；理想做法是**主方法 vs 基线（贪心/启发式）互证**。
- **不确定性先定风险态度**：情景抽样+期望（可利用作物增长/涨价的正向信息）、CVaR/VaR（厌恶尾部）、三准则（悲观/乐观/期望）、鲁棒最坏（保守）——按"分布可得性 + 是否厌恶尾部 + 是否有可利用趋势"选，别把期望当风险。
- **关系显式建模**：替代系数 α（需求转移）、互补系数（×1.01/×0.99、豆类固氮轮作）、相关性（Spearman / 回归 / 供需缺口传导），转成可解释系数 + 组合敏感性。
- **同解可行、路径可异**：C063/C094 精确 MILP（LINGO/Gurobi），C038/C234 启发式（DEGA/GA）；Q2 有期望随机、CVaR、三准则、情景四种处理；Q3 有系数修正、比例约束、Spearman+回归、供需传导四种刻画。

## 建模决策链
- 为什么先列索引与决策张量再写约束：指派类问题先定"地块/季节/作物/年份"四维与"是否/多少"两类变量，才能把每条业务规则写成 0-1 + 线性 + 分段。
- 为什么选精确或启发式：规模可控约束线性→用全局求解器得可验证的最优；更大/强非线性/难线性化→用启发式并说明无全局最优保证。
