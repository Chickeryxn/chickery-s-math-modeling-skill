## 亮点（为什么优秀）
- **把"定位/排布"写成角度几何**：纯方位（仅方向夹角）定位用**正弦定理/三角形角关系**解析求接收机极坐标；三发射机位置无偏且编号已知时是确定性几何问题，直接闭式解，无需数值估计。
- **化归法 + 引理证明**：问题二"最少发射机数"用**正九边形等比角关系**（圆周角 m×10°、圆心角 n×40°）+ **方位角集合唯一性**化归并证"只需 3 架发射"，避免枚举；用集合不交判定编号唯一。
- **局部视角 + 独立只读全局度量**：各机信息不共享，用**局部目标** f=‖α−α*‖² 逼近，再用**独立的全局检验**（E=Σf、平面化检验）判断是否达到整体优——"预处理降阶→局部算法→全局检验"三步。
- **对称性/几何引理分解**：问题三锥形编队按对称性拆成子结构（同心圆/等边三角网格），用几何引理+贪心逐步落位，免全局耦合。
- **同解可行、路径可异**：三篇在"定位模型"上用 纯几何解析（角向位形分类枚举）、正弦定理极坐标法+计算几何两圆/两优弧求交；在"最少发射数"上用 表格映射+对称破缺、角量化分类+无交集判定、化归+引理；在"调整方案"上用 三步迭代（固定参照三元组分层）、阈值启发式搜索（有界前瞻+L2 loss）、预处理+局部优化+全局检验。

## 建模决策链
- 为什么先几何解析再优化：接收/发射共面、编号/无偏坐标已知时几何关系确定，解析最直接；只需"方向唯一性"再考虑最少发射与调整。
- 为什么用局部模型：信息不共享（各机只收方向），全局目标违反"仅方向/不共享"约束，故局部逼近 + 独立只读全局检验。

## 结果呈现
- 初始/调整后极坐标表、误差收敛、发射机数与次数、平面化检验值；用"只需 3 架发射""误差收敛到 e-6""平面化 3.893→0.206（降94.7%）=局部可达全局优"支撑结论。

## 局限与反例
- **公式自洽问题**：某些公式分子分母相同致 $hoequiv 1$、$Delta	heta$ 两项相消为 0 与表值矛盾、$	heta_k$ 相消为常数——公式错误，证据链不可靠。
- **证据缺口**：公式/图/坐标表在文本版缺失（仅"略/占位"）、编号断档、表依赖数值穷举而非解析证明。
- **口径不一致**：摘要"极角≤1°、极径15m"与正文"0.5°、1%"、与"15%→5%"量级不符；随机数未设种子不可复现。
