## 亮点（为什么优秀）
- **先证结构性质、再建模搜索**：含固定倍率/价格结构（行走耗 2 倍、挖矿耗 3 倍 + 收益、村庄 2 倍价、终点退半价）时，先证"某行动恒优/恒劣"（如"挖矿必赚、他处停留必亏"）压缩状态空间/剪枝，再决定是否值得上升到期望或博弈——别一上来堆范式。
- **状态压缩 + 图上 DP**：把无差异中间节点压缩成"位置转移+路径长度"（Floyd 只留功能点），状态压成（天/位置/水/食物/资金），DP 递推；状态空间大、村庄购买经凸性优化降低复杂度。
- **同一框架复用于"确定/随机/多主体"**：确定天气→确定性 DP；仅知当天天气→MDP（马尔可夫决策过程）+ 转移矩阵极限概率；多玩家→博弈纳什；先"确定性数值最优"内层，外层做期望/概率/博弈。
- **随机性处理**：小规模穷举天气→统计规律/天气等效→随机模拟验证，并用"期望收益+失败率"双指标评价；把幸存者偏差显式标注。
- **先锁唯一利润源与关键节点**（本题=矿山挖矿、起点基准价/村 2 倍价/终点退半价构成套利-损耗结构），据此设计决策。
- **同解可行、路径可异**：四篇在"解法"上分别用 图DP、引理+贪心/DFS+剪枝、禁地剪枝+DFS、马尔可夫+博弈、状态压缩+DP；在"多主体"上用 静态博弈混合/纯纳什、支付矩阵+Lingo、加和期望、综合因素；都遵循"状态压缩→DP/搜索→期望/博弈"。

## 建模决策链
- 为什么先压缩状态：状态（天/位置/水/食物/资金）易爆炸，先证明"只值得去功能点"并在其间用最短路，再 DP。
- 为什么按信息量选范式：全部天气已知→确定 DP；仅当前天→MDP；多玩家相互影响→博弈；不知对方策略/不可概率化→退化为期望，并保留兜底分支。

## 结果呈现
- 各关最优策略（路线/是否挖矿/买量）、剩余资金、是否到期、期望收益+失败率、多人决策概率；用"确定性→期望→博弈"逐级结果支撑结论。

- **口径/符号矛盾**："2k 倍 vs 2^k 倍"（k>2 模糊）、"事件 C=沙暴 vs 高温"、water/food 标签反串、购买公式水/食共用 RHS 量纲乱、摘要"净收益 −10000" vs "失败收益 10000" 正负号矛盾、E2=115<0 与真值约 −56.4 矛盾、E4/E5 同式但水/食基础消耗不同。
