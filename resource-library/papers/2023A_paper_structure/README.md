## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述/符号 → 物理机理建模 → 设计优化（分问递进）→ 结果（表1/2/3）→ 评价/推广 → 附录代码**。
- **每问一个"机理（Q1）→ 优化（Q2/Q3）"闭环**，Q3 在 Q2 基础上放开尺度/高度，明确"自由度增加但指标折中"。
- **用"主损失在哪→布局如何改善"的因果链**串联机理与优化，而非罗列公式。

### 局部结构
- **符号表先定且唯一**：区分镜高 H / 海拔 H、E_field 单位（kW/m² vs MW）、每处参数含义唯一。
- **公式-代码-表一致**：展示公式与计算口径一致；月均=每月21日5时点，年均口径明确（等权 vs 按日照积分）。
- **结论与约束一致**：若未达额定/非全局最优，如实标注，不写"满足额定"。

## 建模决策链（结构层面）
- 说明为何用"降维+分层+单峰/变步长"而非直接全局优化；给出收敛/局优说明。

## 结果呈现（结构层面）
- 月均/年均效率与功率表 + 设计参数表，并给出 Q1/Q2/Q3 对比与"效率提升来自余弦"的归因。

## 局限与反例（本地结构/证据差错即失可信）
- A165：结论"满足额定"与结果 43.73MW 冲突；E_field 单位、符号 H 复用。
- A127：表1 残留模板（N=100/L=6m 与真实 N=1745 矛盾）、摘要/正文数值不一致、E_field 与截断效率符号冲突。
- A092：式(21) 平均口径与代码"各效率均值相乘"不一致；GA 适应度实为平均余弦效率而非单位面积输出；表3/6 为空表。
- A175：年均为 60 时刻等权平均，未按日照积分；余弦效率式自相矛盾、塔径简化为与集热器同径。
- 教训：**结论必须与约束/结果一致；符号与单位唯一；"展示模型=计算模型"**。
