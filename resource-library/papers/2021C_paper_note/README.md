## 亮点（为什么优秀）
- **评价用数据驱动客观定权**：多个相关指标（供货次数/量/稳定性/连续性/合理比例）先做正负向性与量纲处理，再用 熵权法（EWM）/投影寻踪（PPCE）/TOPSIS 客观定权，或叠加 AHP 在合理范围做"人因校准"——避免主观 AHP 带来的武断。指标权重可由"销售/供货特征"驱动（稳定性/能力主导重要性）。
- **"评价→规划"两阶段串接**：先用稳健评价收敛供应商（如 top50），再在小子集上做 0-1 整数规划（最少家数）+ 逐周订购（LP/GA/动态规划）+ 转运分配，压缩组合爆炸。
- **统一换算量纲**：多类原料（A0.6/B0.66/C0.72 耗料）先统一换算成"可产产品量"，并使损耗/供货偏差折算成产物——不同原料可比、目标可加。
- **库存跨期迭代**：$I_k=I_{k-1}+$ 供货(1−损耗) − 消耗，且 ≥ 两周产能；用真实可辨识的跨期迭代约束替代拍脑袋硬上限，过量订货自动回落。
- **多目标处理**：成本/损耗/结构（多 A 少 C）/最大化重要性——按优先级分层（贪心/主要目标法）或多目标优化（GA/NSGA-II/MOPSO）给 Pareto。
- **同解可行、路径可异**：评价用 EWM+TOPSIS、投影寻踪(PECE)、熵权+AHP 校准；订货/转运用 0-1 整数规划+LP、多目标 GA、双层/随机规划、双目标贪心；都遵循"评价→选→订→运→产能"链。

## 建模决策链
- 为什么先评价再规划：供应商重要性（稳定性/能力）决定入选与订购优先级，先收敛再规划。
- 为什么统一换算量纲：三类原料消耗与价格不同，不统一则目标不可比、结论失真。

## 结果呈现
- 供应商重要性排名/入选、最少家数、24 周订购与转运方案（成本/损耗）、结构优化（多 A 少 C）、产能提升；用"成本/损耗/占比"与"方案实施效果"支撑结论。
