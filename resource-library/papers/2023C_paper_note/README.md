## 亮点（为什么优秀）
- **先清洗再建模**：剔异常（箱线图/去负值）、统一口径（退货、未补货 0 价、损耗率）、删低效单品，再做统计/建模。
- **数据形态→方法类别→算法 的链式映射**：非正态/含极端值 → Spearman（弃 Pearson）或偏相关（剔除总量/混淆）；长尾 → 直方图/累计；类别关联 → K-means++/CURE/FP-Growth；序列有周期/趋势/节假日 → 时序分解（乘法/Prophet/ARIMA/温特斯）；小样本 → 灰色关联。
- **先剥离混淆因素再估主效应**：把季节/节假日/趋势从销量中分解剔除，再在局部区间回归价格对销量的**偏效应/弹性**，否则会把季节性误当价格效应。
- **预测与优化解耦 + 弹性闭环**：先（用 RNN/Prophet/ARIMA）预测未来需求，再把"价格弹性"嵌入使"定价→销量→收益"耦合，最后在满足约束下优化（补货量+定价/选品+补货量）。
- **决策是混合 0-1+连续、单/多目标**：用 SA/GA/NSGA-II/PSO 等；需求度用 VIKOR 融合"销量+销售次数"；多目标（收益 vs 需求满足度）给 Pareto。
- **同解可行、路径可异**：四篇在"分析→预测→优化"上分别用 ACF+乘性分解+偏相关+FP-Growth 与 LSTM+GBest-PSO+NSGA-II、Shapiro+VAR+Bayesian+Lingo、描述统计+Spearman+K-means+++SA+温特斯、K-S+Pearson+Prophet+MIQP+GA——都在"先分析关系、再预测、再优化"链上，工具各异。

## 建模决策链
- 为什么先分析关系再优化：需求、替代/互补、品类结构先摸清，定价/补货才有依据。
- 为什么解耦预测与优化并嵌入弹性：直接联合建模复杂且难收敛；先预测基线再按弹性修正，可解释、可控。

## 结果呈现
- 品类/单品补货量与定价、需求满足度、一周收益、单品利润率；用"相关性/弹性""最优方案 vs 基准"对比支撑结论。

## 局限与反例
- **统计方法前后矛盾**：C050/C126 因厚尾/非正态弃 Pearson 用 Spearman，却在 Q2 用 Pearson 宣称显著；检验方向（H0）、置信度（90% vs 0.05）、p 值（全 0.001）设置可疑。
- **口径/符号混用**：损耗率/损失率、"最大补货量/最大销量"、某符号重复定义、正文 2.5kg 与代码 25 不一致。
- **价格弹性内生性**：价格由商超内生决定，OLS 未处理联立内生（VIF 不能证外生）；用辅助变量把硬约束放宽导致需求满足度 308% 或 0.6-1 倍违规、负利润单品仍入选。
- **预测拟合差/结论夸大**：Prophet R²≈0.45-0.55；摘要称"已解决"但 Bayesian/部分分析未完成；SA 定价恒为边界值未真优化。
