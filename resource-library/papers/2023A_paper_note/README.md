## 亮点（为什么优秀）
- **多损耗相乘的效率链**：光学效率 = 阴影遮挡 × 余弦 × 大气透射 × 截断 × 反射，场功率 $E=mathrm{DNI}sum A_ieta_i$。余弦效率是最大杠杆与主要损失，优化布局主要通过提升余弦效率（塔偏南、镜布近似抛物面内低外高、同心圆/蜂窝排布）实现。
- **便宜解析子块 + 昂贵仿真子块的流水线**：余弦/大气/反射是解析式（便宜），阴影遮挡/截断是非线性几何投影/蒙特卡洛（昂贵）。把优化留给便宜子块、MC 只作抽头估计，并用物理对称性（同心圆、各向同性、东西对称）压缩高维决策空间。
- **昂贵黑箱目标的降维求解**：一次全镜场光线追迹评估极贵，且变量混有离散量。先固定其余变量，把目标看成少数连续量的单峰函数（如塔南移 D、镜宽 W）用**三分查找**；或用**粗-精变步长枚举**、GA、MC 抽样。
- **场景递进、内核复用**：Q1 正向求值（给定布局算指标）→ Q2 统一尺寸找最优布局 → Q3 尺寸/高可变（对称性约简：每圈同尺寸同高）。几何机理内核不变，只放开自由度。
- **同解可行、路径可异**：四篇在"如何找最优布局"上分别用 分层+GA+遍历、粗-精变步长枚举+二分、三分查找、蜂窝排布+采样寻优；但都遵循"机理建模 → 少量决策变量 → 分层/降维搜索"。

## 建模决策链
- 为什么先固接"主光线过集热器中心"这一最优点：使镜面法向唯一确定；再以锥形光束+取点近似覆盖真实镜面。
- 为什么用对称性/降维而非直接全局优化：决策变量庞大（塔位/尺寸/高/数目/每镜位置），且每次评估是全镜场光线追迹；降维+变步长+单峰三分可控精度、可解释。

## 局限与反例
- **额定 60MW 未达标**：A165 的 Q2=43.73、Q3=44.25MW 远低于约束却称"满足额定"——结论与约束冲突的典型反例。
- **自由度高但指标反降**：A127/A175 的 Q3（尺寸/高可变）单位面积功率反而低于 Q2，说明"额定≥60MW"与"单位面积最大"是折中而非纯最大化，且非真全局最优。
