## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述/数据 → 假设 → 符号表（先行）→ 逐问"建模→求解→结果→对比→小结"→ 评价/推广 → 附录（代码 + 数据表 + 结果文件）**。
- **口径唯一**：地块数（34/54）、亩数（1201/1213）、年份（7）在摘要、正文、代码、附录四处一致。
- **每问产出"一个可核结论"**：用方案表 + 对比表 + 敏感性表，而非纯文字结论。

### 局部结构
- **符号表真正被正文使用**：先定符号再写公式；避免约定前后矛盾（下标 i/j/k/t 统一）。
- **参数来源与敏感性**：λ、M、α、系数（1.01/0.99）、管理参数 p,q 要给取值依据并做敏感性（p,q 矩阵、波动幅度影响）。
- **对比实验**：主方法 vs 基线（贪心/启发式）、有无某因素（考虑/不考虑），并给出归因。
- **表-图-代码-正文四方一致**：数值口径、命名、约束表达式、图注对齐。

## 建模决策链（结构层面）
- 先写"问题分析（含为什么用精确/启发式、为什么用期望/CVaR）"，再进入建模；把**范式切换判据**讲清。

## 结果呈现（结构层面）
- 逐问带数值（七年总收益、各情形对比、敏感性 最大/最小 影响因素）；用表支撑，避免大段文字。
