## 亮点（为什么优秀）
- **机理建模 + 证据化降阶选型**：先建完整机理（一维热传导 PDE / 集总参数 Newton 冷却），再以**物性与拟合误差为证据**（RMSE/MAE、板厚 0.15mm→厚度温度趋一致）做有理有据的模型降阶与选型——"简单但不失物理"是主动设计而非权宜。升/降温机理不同，常分模型、参数分段（τ/k 分段辨识）。
- **把工艺约束封装成布尔 check(参数) 当"可行性筛子"**：制程界限（升/降温斜率、150–190℃时长、>217℃时长、峰值 240–250℃）作为一个可行性函数，优化器只管在可行域内寻优；约束变化只改 check、不改主流程。
- **按自由度/目标形态选求解器**：单变量（max v）→ 二分+遍历；5 变量、目标由仿真给出且非光滑/带可行性带 → 模拟退火/遗传（配合"多次独立运行+二次筛选"）；多目标 → 归一化+动态/线性加权标量化（分层序列）。
- **把"时间/温度"约束转成集合指标函数**（>217℃ 的时间、150–190℃ 的时间、峰值），便于离散化与优化。
- **先粗后细两阶段搜索**（步长 1→0.001 / 粗网格→精网格）降计算量；稳态快、瞬态慢解耦（炉内温度分布解析 + 板内升温差分）。
- **同解可行、路径可异**：运动模型用 一维热传导差分、集总参数牛顿冷却、有限差分+PDE；辨识用 最小二乘/分段拟合；求解用 二分+遍历、模拟退火、遗传、爬山+A*；都遵循"机理→辨识→约束→寻优"。

## 建模决策链
- 为什么先做机理并选型：炉温曲线是"一维热平衡"，须从物理反推；不同物性/几何决定哪个模型合适，用拟合误差+物性论证取舍。
- 为什么用可行性筛子+启发式：目标经仿真得到、不可导、带硬约束，优化器只在可行域搜索最稳。

## 结果呈现
- 参数辨识值（τ/k/h/α）与拟合误差、关键点温度（小温区/峰值）、最优温区温度与带速、面积/对称度、约束满足情况（是否贴近峰值 240 下限/带速上限）。

## 局限与反例
- **口径/符号混乱**：℃ 与 K 混用、面积 ℃·s 与"℃"标签互换、式(33)"u≥270"应为">217℃时长"、"150≤u≤190"把时间/温度混写、式(44) 用 T1-T6 而模型只有 T1-T4。
- **数值/版本冲突**：摘要范数 vs 正文/检验值（55.87 vs 35.87℃、403 vs 312/298）、两版互斥终解（拼接残留）、定值 k=0.193 与分段 k(0.017-0.029) 差近一数量级（量纲可疑）。
- **证据/收敛**：模拟退火/遗传无最优性证明、权重（加权系数/归一化参数）只出现在代码无推导与敏感性、面积用离散矩形而非梯形/解析（dt 网格误差）、差分格式未讨论 Courant 稳定。
- **鲁棒性**：最优解常把峰值压到 240℃ 下限、带速逼近上限，鲁棒性偏弱；未量化拟合残留/传感器误差、忽略热辐射。
