## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述（几何/约束）→ 符号与坐标系 → 逐问"理想面(Q1)→调节(Q2)→接收比(Q3)" → 结果表(参数/节点/伸缩量/接收比) → 评价 → 附录（参数 + 源码）**。
- **每问复用上一问的几何内核**，只改方位/约束。
- **把"能否满足硬约束"作为明确判断**（0.07%、±0.6m、索长定长）。

### 局部结构
- **符号/口径唯一**：R 取 300 还是 300.4、工作态口径、α/β 与 θ/φ、焦径比 0.466R 的对象。
- **理想面→调节→接收比 各给参数与数值**，并说明约束满足情况。
- **正文与附录/代码一致**：算法叙述（BFGS/minimax/变步长）与实现一致；数值（l_sum、顶点、蒙特卡洛 n）一致。
- **证据完整性**：关键公式/图不缺失；对采样与判定误差做敏感度。

## 建模决策链（结构层面）
- 说明为何用坐标变换/对称性降维、为何用贴近度量、为何用某算法、为何"放宽/妥协"。

## 结果呈现（结构层面）
- 理想面参数、调节后节点/伸缩量、接收比（前/后/相对提升）；用"是否满足约束 + 提升是否可归因"支撑结论。

- **证据素养**：结果可复算、诚实标妥协解/增益来源、敏感度。

## 局限与反例（本地结构/证据差错即失可信）
- A028：正文"LSUM2>LSUM1"与数值 141.00/114.85 相反、顶点正文与代码不符、蒙特卡洛 n 不一致、未纳入 0.07% 与索长约束（纯几何无力学）。
- A115：R 用 300.4、Q2 顶点为对侧点、0.07% 未满足、η 比值≈2.899 人为修正、n 被约去。
- A217：文本公式/图大量占位缺失、算法叙述（拉格朗日+BFGS）与实现（fmincon 内点）不符、α/β 与 θ/φ 混用、接收比绝对值低、附录坐标表 10^6 量级不符。
- 教训：**口径（R/焦距/方位）唯一、正文-附录-代码一致、约束满足与提升归因诚实、关键表与图齐全**。
