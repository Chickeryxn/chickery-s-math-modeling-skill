## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述（规则/参数：消耗倍率、价格、负重、收益）→ 假设 → 符号 → 逐问"Q1 确定 →Q2 随机 →Q3 多主体" → 结果表（路线/买量/剩余资金/期望）→ 评价 → 附录（代码 + 状态表）**。
- **用"状态压缩+DP/搜索"为主线**，随问题加"期望/博弈"层，体现"分层升级"。

### 局部结构
- **符号/口径一致**：消耗倍率（行走 2/沙暴停留 1/挖矿 3）、天气消耗（水/食）、价格（起点/村 2 倍/终点退半）、收益、买量单位。
- **方法-实现一致**：正文用 DP/MDP/博弈求解，附录代码也确实由这些搜索/递推得出（而非读预设状态+人工给定），并保留兜底分支（无占优→期望）。
- **随机性给稳健性**：多实现/置信、天气等效与沙暴概率有来源、把幸存者偏差与主观假设如实标注。
- **证据完整**：关键表/图不缺、不出现 Inf/NaN 被粗暴置零、占优系数/临界给来源与敏感性。

## 建模决策链（结构层面）
- 说明为何先压缩状态、为何按信息量选范式、为何多层期望/博弈、为何保留兜底。

## 结果呈现（结构层面）
- 各关路线/买量/剩余资金/是否到期 + 期望收益/失败率 + 多人决策；用"确定→随机→多主体"逐级结果支撑。

## 局限与反例（本地结构/证据差错即失可信）
- B078"事件 C=沙暴"误写"高温"、E2=115 自相矛盾、E4/E5 同式、蒙特卡洛单次无种子、博弈模型退化为 DFS。
- B108 摘要净收益 −10000 与 §7.1.3 失败收益 10000 正负矛盾、"平均收益 5260.2"与数百级成本冲突、幸存者偏差未量化、天气等效主观、第六关"三人"实为"两人局部"、rand 用 time(0)。
- B125"2k vs 2^k"模糊、势函数当概率表4/5 出现 Inf/NaN、占优系数任意、问题2/3"细化"虚构天气表再模拟验证属循环论证、未给完整博弈解。
- B175 water/food 标签反串、第五关 9400 vs 9290/9510 矛盾、正文"用 DP/MDP 求解"但附录读预设 state*.mat 且决策人工给定、判据右侧 165/405/450 未定义口径。
- 教训：**口径与倍率唯一、方法-实现一致、随机性给稳健性与幸存者偏差、数据/表不缺、系数与等价有来源**。
