## 亮点（为什么优秀）
- **同一个几何内核、场景递进**：覆盖宽度 $W=f(D,	heta,alpha,delta)$ 由正弦定理/解三角形导出；四个问题只是几何环境在变（平面坡→三维方向 β→分块真实地形），内核复用、逐层推广。这是"内核不变、由简到繁"的典型。
- **用特殊情形作锚点**：β=90°/270° 时 W 恒为常数（沿等深线/等高线），退化为 Q1，因此可把新情形"变量替换+类比"映射进既有闭式模型，避免重推导。
- **布设优化的主要目标法**：覆盖/漏测/重叠率/总长多目标且主次明显时，定主目标（如漏测率）其余转约束，避开权重随意性；沿等深线（使重叠可控）做临界重叠率（η=10%）递推排线。
- **分治 + 复用内核**：真实地形起伏大、非单一坡面，先按等深线/等高线分区、拟合每块坡面，每子域复用已成立的局部最优点；"贪心构造 + 启发式验证（模拟退火/PSO）"形成交叉验证闭环。
- **同解可行、路径可异**：Q4 有 分治+最小二乘/粒子群拟合坡面+贪心、随机森林拟合+改进飞蛾火焰+分区、主要目标法+递推+贪心 等多种实现，但都遵循"几何内核+分治+布设优化"。

## 建模决策链
- 为什么先解析几何而非数值拟合：Q1/Q2 是确定性几何关系，无随机数据，封闭解可直接验证；Q3/Q4 因真实地形/布线自由度才用优化/启发式。
- 为什么用分治而非一次全局优化：非线性、非凸、目标含离散（条数）且单次评估可能是全区域，先分解成可解子域再复用内核更可控、可解释。

## 结果呈现
- 覆盖宽度/重叠率计算表（不同位置/β/距离）、布设结果表（条数/总长/漏测/超重叠段），用"深水重叠偏大、浅水漏测"等体现口径与临界判断。

- **数学素养**：解三角形/向量/线面角几何建模；重叠率定义口径一致；场景递进。

- **表达素养**：结论带具体值与时点口径；单位一致。

## 局限与反例
- **口径矛盾**：B226 把 4海里=6814m（应 7408m）且"34 条东西向"与"平行等深线南北向"矛盾；B477 总长"434662（米？）"与摘要"669.3 海里"差近 3 倍、覆盖率 99.956%vs 99.5%。
- **展示模型≠计算模型**：B311 正文式(5) 给 W≈127m、代码/表为 243m，读者无法按展示公式复现。
- **重叠率定义歧义**：坡面上 d 取水平间距还是坡面投影须一贯；由平坡 η=1−d/W 切换到含 D 的多项式口径要交代。
- **覆盖 100% 与漏测 2.3% 矛盾**；误差/残差未量化、分区拟合仅为定性描述。
