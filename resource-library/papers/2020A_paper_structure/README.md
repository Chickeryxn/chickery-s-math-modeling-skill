## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述（工艺约束/参数）→ 机理建模+模型选型（给证据）→ 参数辨识 → 逐问"Q1 正演(Q2/Q3/Q4 约束寻优)" → 结果表（参数/关键温度/最优温区带速/指标）→ 检验/评价 → 附录（参数 + 代码）**。
- **每问在上一问模型基础上复用**，只在"目标/变量/约束"上变化。

### 局部结构
- **符号/单位唯一**：温度（℃ vs K）、面积指标（℃·s）、时间（s）、带速（cm/min vs cm/s）、温区编号一致。
- **模型-代码-结果一致**：拟合参数/温区温度、目标与约束、算法叙述（模拟退火/遗传/二分）与实现一致；不出现"两版终解拼接"。
- **约束满足明确**：制程界限逐条判，不漏">217℃时长""150–190℃时长"。
- **收敛/最优性说明**：给出多次独立运行、权重量纲归一化、面积积分方式（梯形/解析 vs 矩形）与网格误差。

## 建模决策链（结构层面）
- 说明为何选某运动模型（物性+误差证据）、为何用可行性筛子、为何用某求解器（按自由度/形态）、如何标量化多目标。

## 结果呈现（结构层面）
- 参数辨识值+误差、关键点温度、最优温区与带速、面积/对称度、约束满足情况；用"是否贴界（峰值 240 下限/带速上限）、Q3 vs Q4 差异"支撑结论。

## 素养对照（可迁移规则）
- **表达素养**：符号/单位/口径一致、模型-代码-结果一致、先结论后展开。
- **完整素养**：Q1-Q4 全覆盖、评价/局限/推广、附参数与代码。
- **证据素养**：拟合误差、约束满足、多次独立运行、诚实标"贴界/近似/无最优性证明"。

## 局限与反例（本地结构/证据差错即失可信）
- A070：摘要范数 55.87 vs 正文/检验 35.87℃、式(33)"u≥270"与"150≤u≤190"把时间/温度混写、式(44) T1-T6 而模型只有 T1-T4、定值 k 与分段 k 差一量级、归一化权重只出现在代码。
- A147：两版互斥终解（面积 312/298 vs 403、温区映射不同）、差分格式索引疑错/未讨论 Courant、厚度 0.15mm vs 0.075cm、A* 无最优性证明、1:1 权重主观。
- A195：℃ 与 K 混用、表4 把 E 标 K·s/S 标 ℃ 颠倒、附录第二套 modelsolve 参数与正文完全不同（版本错乱）、"敏感"与"影响<1%"口径矛盾。
- A212：斜率约束正文"升温只查上界 0~3、冷却查绝对值≤3"未区分、v cm/min vs cm/s 与 h 量纲未校核、magic number 硬编码、l=21.7℃ 却称"近似对称"、加权 0.1 经验取值。
- 教训：**符号/单位/口径唯一、模型-代码-结果一致、约束逐条判、收敛与最优性诚实**。
