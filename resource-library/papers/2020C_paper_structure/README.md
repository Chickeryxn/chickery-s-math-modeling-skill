## 亮点（结构层面，为什么值得学）
### 整体结构
- **数据说明/清洗 → 特征工程 → 假设 → 符号 → 逐问"评分（违约/评级）→ 信贷决策（额度/利率）→ 外部冲击调整 → 结果表 → 评估/评价 → 附录（代码 + 数据）"**。
- **"评分→决策→冲击→稳健"为主脉**，Q3 在 Q2 基础上只改输入/乘数。

### 局部结构
- **符号/单位/口径唯一**：利率（%）、额度（万元）、金额（元）、违约损失率、额度/利率/期限区间；同一损失率不前后矛盾。
- **模型-代码-结果一致**：目标式、约束（总额）、系数与附录一致；结果以满足自身约束（表各行加总=总额）。
- **模型评估完整**：训练/测试划分、准确率/AUC/混淆矩阵、基线与集成对比、交叉验证；避免"训练 1.0 却称完美"式夸大；不过拟合。
- **外部冲击/参数有来源与稳健性**：β、风险乘数、FTP、流失率、情景给取值与敏感性；"违约概率>50% 拒贷"给依据。
- **样本与假设如实**：样本小、信用不平衡、相关性与组合风险被忽略要说明。

## 建模决策链（结构层面）
- 说明为何用某评分模型（样本+可解释+精度）、为何两段解耦、为何用某优化、外部冲击为何乘数化/折价。

## 结果呈现（结构层面）
- 特征/评分权重、违约与评级分布、信贷策略（额度/利率/拒贷）、组合收益/风险、冲击后调整；用"高信用→额度大利率低、D 级拒贷"等支撑结论。

## 局限与反例（本地结构/证据差错即失可信）
- C109：目标 [r-(1-p)]x vs LINGO (r-p)x、总额 ≤30200 vs ≤10000、无 AUC/回测/基线、假设总体风险=最大单笔+同等级违约率相同、P/R 符号矛盾、未建模供应链特征。
- C142：正文(16) R=3 应为5、d(I)人工未校准、PCA 符号翻转/维度错配、级联误差、仅 13 家测试正确率 61.5/76.9%。
- C170：§6.2 自相矛盾（阈值0.75/239/27档 vs 0.7192/210/29档、表同名不同数）、符号脏、宣称 RAROC/违约金字塔未实例化、熵权"客观"却与 0.5×信用得分加权、税项权重 0.37 vs 利润≈0.001。
- C227：结果金额"元"与约束"万元"混、问题三各行额度加总≈5140万 vs 约束1亿（未满足自身约束）、基分类器训练1.0 vs 测试0.806/0.871 过拟合却评"完美"、β 无敏感性、概率>50% 硬截断。
- C305：正文与 LINGO 目标/总额冲突、γ3 -0.1042 vs -0.1142、无训练/测试/AUC/基线、假设总体风险=最大单笔。
- 教训：**单位/口径唯一、模型-代码-结果一致且满足自身约束、给评估与基线、避免过拟合/无验证、参数有来源与稳健性**。
