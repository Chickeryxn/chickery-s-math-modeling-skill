## 亮点（为什么优秀）
- **坐标系变换规范化**：把斜入射轴线旋转对齐坐标轴，使主关系（如"轴向抛物面"）规范化，其余量做同一变换，即可在新系沿用旧结论（省推导、降出错）。
- **曲面逼近 = 定理想面 + 带约束贴近 + 量化增益**：先由"以 SC 为轴、P 为焦点"确定理想抛物面，再用"节点径向偏差平方（积分/离散求和）"作为可积可微的贴近度量，在"下拉索定长、节点距变≤0.07%、促动器±0.6m"约束下最小化；最后用几何/蒙特卡洛算接收比相对提升。
- **对称性/几何降维**：轴对称问题先取 2D 截面（含焦距 f 一个自由度）做一维最小化；用**廉价代理指标**（如 l_sum/总伸缩量）初筛候选，再用精确计算验证——"廉价代理→精确验证"闭环，避免对数千离散变量盲目优化。
- **高维带光滑凸约束的优化**：用 BFGS/内点/变步长/minimax 等超线性方法，而非纯梯度下降；硬约束不可满足时诚实说明是否为"放宽约束的妥协解"。
- **同解可行、路径可异**：三篇在"理想面/调节"上用 一维 f 最小化+BFGS、minimax+变步长遍历、几何映射+样条+迭代；在"接收比"上用 蒙特卡洛逐三角形、几何面积比、轴对称 2D 解析；都遵循"几何建模→拟合→约束调整→增益量化"。

## 建模决策链
- 为什么先坐标变换：让主对称轴对齐坐标轴，问题降为"简单情形"，避免整面复杂推导。
- 为什么用贴近度量而非精确共形/解析：需保留离散索网/面板约束，用最小二乘贴近更可解、更贴合可控变量（节点坐标）。

## 结果呈现
- 理想面参数（焦距/顶点）、调节后节点/促动器伸缩量、接收比（调节前 vs 后、相对提升）；诚实标注"是否满足 0.07%、是否为妥协解、提升是否由构造产生"。

## 局限与反例
- **口径/符号混用**：R=300 vs 300.4、0.466R（球面焦径比）与工作态口径、α/β vs θ/φ；方向符号（顶点落在天体对侧）。
- **约束与结论冲突**："理想抛物面"实为放宽 0.07% 后的妥协解；接收比提升可能恰等于人为修正系数（由构造产生、前后处理不一致不可比）；n 被约去致 η≈盘面积/面板面积、与几何几乎无关。
- **证据缺口**：文本公式/图大量占位缺失、正文数值与附录/代码不一致（l_sum、顶点坐标、蒙特卡洛 n 1000 vs 1e5）、算法叙述（拉格朗日+BFGS）与实现（fmincon 内点）不符。
- **模型假设**：未纳入 0.07% 与"下拉索长度不变"的力学约束、面板刚性/纯几何、边缘面板忽略。
