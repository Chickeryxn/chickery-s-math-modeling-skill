## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述（参数/约束）→ 假设（理想/小角度/对称）→ 符号 → 逐问"理想策略(Q1)→误差→倾角模型(Q2)→是否调整(Q3)→精确控制+效果(Q4) → 结果表 → 评价 → 附录（代码）"**。
- **"理想→现实误差→调整→精确控制+效果分析"递进**，每问在上一问基础上放宽/加因子。
- **物理抽象连环简化 + 先反演再控制**是主线，"多目标→无量纲化→启发式"收尾。

### 局部结构
- **符号/单位唯一**：弧度 vs 度、恢复系数 e、质量（球 0.27/鼓 3.6）、惯量（正确公式）、R（鼓半径/球半径区分）。
- **数值一致**：摘要/正文/e/代码一致；不出现两套数字或内部矛盾。
- **物理正确**：惯量公式、能量/动量守恒、v2 数量级；强假设（小角度/对称/碰撞瞬时）明确并给合理性。
- **证据完整**：多次运行/方差/敏感性、图真实；不嵌与赛题不符的"问题五"。

## 建模决策链（结构层面）
- 说明为何先理想后现实、为何用刚体+质点/小角度/对称、为何"先反演再控制"、为何多目标无量纲化+模拟退火。

## 结果呈现（结构层面）
- 理想最优（力/时机/颠高）、各工况 0.1s 倾角、调整策略、精确控制下各队员力/时机与误差效果；用"小角度解耦可行、全同步+对称补偿、先反演再正控"支撑。

## 局限与反例（本地结构/证据差错即失可信）
- B047：摘要/正文两套数字、转动惯量用 H0=0.11（应鼓高）、球质量 0.24 vs 0.27、R 复用、嵌入"问题五"疑为拼贴、问3 内部矛盾。
- B057：Q1 解 sin/cos 与 t1 差 √2 因子、第8组 0.146° vs 表 0.186°、13 条 y(t) 未标注组别、Q1 与 Q3 碰撞假设互斥。
- B136：摘要/正文 9 角对不上（0.3885 vs 0.3855 等）、正文 e=0.95 代码 0.90、弧度/度混用、问3 v2=0.2872 应为≈2.80、依赖"鼓恰在 v 最大时碰撞"强假设、问4 仅单次最优无方差。
- 教训：**符号/单位唯一、数值/假设一致、物理正确（惯量/能量/量级）、证据完整、避免拼贴**。
