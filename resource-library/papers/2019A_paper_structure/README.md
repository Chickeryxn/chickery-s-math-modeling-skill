## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述（参数/附件）→ 假设（含尺度折减的量级证明）→ 符号 → 逐问"守恒模型(Q1)→加柱塞腔(Q2)→加双喷+减压阀(Q3) → 控制方案/参数表 → 判稳/评价 → 附录（参数 + 代码）"**。
- **每问在守恒模型上加子系统**，体现"对象-结构、逐层扩展"。

### 局部结构
- **符号/单位唯一**：ω（rad/s vs rad/ms）、开阀时长(ms)、喷油周期(100ms)、凸轮周期(2π/ω)、压力(MPa)、密度(mg/mm³)；避免"27-29S"、图题注与实现单位不一致。
- **模型-代码-结果一致**：拟合参数、阈值（泄压阀/电磁阀）、时差、ω 与代码一致；不出现"代码 110 vs 正文 440"。
- **判稳明确**：给"稳态"的判据（偏差和/方差/波动幅值），不只用"偏差和→0"。
- **证据完整**：给波动幅值与敏感性（dt/步长/参数）、收敛与是否为全局/网格次优；图真实呈现。

## 建模决策链（结构层面）
- 说明为何用集总/0D（量级证明）、为何把"稳定"写成偏差平方和、为何用遍历/坐标下降、为何假设忽略传播时间（并说明其被压强波效应削弱的局限）。

## 结果呈现（结构层面）
- 最优开阀/角速度/减压阀参数 + 压力波动（幅值/方差/判稳）+ Q3 对比（阈值 vs 电磁式）；用"稳定 100→150、减压阀更优"支撑。

## 局限与反例（本地结构/证据差错即失可信）
- A023：单位混乱（"27-29S"、泄压阀 100.5 vs 100、时差 45/50、代码 110 vs 440）、判稳仅"偏差和→0"无波动/方差、强假设"腔内处处相等"消掉压力波、针阀面积/查表粗糙。
- A190：ω rad/s vs rad/ms（摘要比正文差量级、125.6 rad/ms 偏离域）、Q1 开阀 0.75 vs 0.76、目标在 |min| 与 min∫ 之间切换、公倍数 T 近似、遍历为网格次优、减压对比仅单扰动定性、图全占位。
- A240：ω 图题注"rad/s"、时间尺度矛盾（代码 1s vs 正文 100s/1000s）、集总假设漏掉压力波、E(P) 对 ρ 积分简化、未稳定段 t0(t) 盲选线性、式(10) 漏减 kT。
- 教训：**符号/单位/口径唯一、模型-代码-结果一致、判稳给波动与敏感性、诚实标"忽略压力波/网格次优/版本错乱"**。
