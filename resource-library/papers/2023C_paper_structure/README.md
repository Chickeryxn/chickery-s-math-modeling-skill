## 亮点（结构层面，为什么值得学）
### 整体结构
- **问题重述 → 数据预处理/清洗说明 → 假设 → 符号表 → 逐问"分析(Q1)→决策(Q2/Q3)→建议(Q4)" → 评价/推广 → 附录代码与数据表**。
- **形成"数据→关系→预测→优化"链**，Q1 的关系/分布为 Q2/Q3 提供依据，Q4 回提数据。

### 局部结构
- **符号表先定且唯一**：损耗率、进货量/销量、价格、加成率各用一个符号。
- **每个统计结论带检验/置信度/显著性**，但方向与置信度要一致（H0/H1、0.05/0.90）。
- **优化模型目标与约束自洽**：不出现"负利润单品仍入选、需求满足度超 1（违规）、用辅助变量放宽硬约束"。
- **对比基准公平**：最优 vs 平均加成/无优化/往年，而非"平时 1000、优化 1800"式经验估计。

## 建模决策链（结构层面）
- 说明为何先分析关系、为何解耦预测与优化、为何用某类算法（按变量连续/混合、目标单/多、数据特征）。

## 结果呈现（结构层面）
- 补货量与定价、需求满足度、收益、利润率；用"方案 vs 基准/不同方案"对比支撑，避免只给一个"最优"数字。

## 局限与反例（本地结构/证据差错即失可信）
- C050：表14 列名"损失率"当损耗率、检验方向与置信度矛盾、Q1 用 Spearman 却 Q2 用 Pearson。
- C126：正文 2.5kg 与 Lingo 代码 25 不一致、表9 全部 f=100% 退化、摘要称已解决但仅部分品类完成。
- C228：符号 w_i/z·B 矛盾、缺"z=0⇒B=0"、弹性 OLS 内生、对照是经验估计。
- C235：符号 a 重复（损耗率/最大量/库存）、表9 含负利润单品、表10 需求满足度 308% 违规。
- 教训：**统计口径与检验一致、优化目标-约束自洽、对比基准公平**。
