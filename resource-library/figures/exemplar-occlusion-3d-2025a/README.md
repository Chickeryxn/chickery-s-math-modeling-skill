## 图型与用途

- **图型**：① 3D 烟幕干扰几何遮蔽（侧向视角）；② 二维正视图(x–z 铅垂剖面)与侧视图(y–z 平面，横向偏置)；③ 有效遮蔽时长 vs 起爆延迟；④ 遮蔽时长 vs 速度×横向偏移（等高线）
- **用途**：直观表达"烟幕云团须落在 导弹 M(t)→真目标 的视线上（真目标偏 y=+200m，故云团须偏 +y）"这一**几何遮蔽条件**；以及"单发遮蔽峰值约 4s、对速度不敏感、对横向偏移极敏感"的结论（结论由**图直白表达**，不写文字）。

## 为什么优秀（可迁移的绘图规则）

- **配色**：主色 #1A6FC4（云团）、灰基线 #767676（导弹）、方向/阈值 #B91C1C（真目标/视线）、辅助 #4C9A2A/#E08214/#8E44AD/#0F9D58（无人机/投放/起爆）——**饱和深色、不透明、不滥用红绿**。
