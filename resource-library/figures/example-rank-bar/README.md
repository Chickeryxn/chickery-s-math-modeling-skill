- **图型**：排序横向条形图 + 均值参考线
- **用途**：展示多方案综合得分排名，支撑"方案 A 总体最优"的主结论

## 为什么优秀（可迁移的绘图规则）

- **配色**：Top-1 用主色 `#1A6FC4`，其余 `#767676` 灰基线；均值参考线 `#B91C1C` 虚线——不滥用红绿，差异由位置与长度表达
- **版式**：按得分降序（最靠上的最优）；条端标注数值；均值虚线作参考；`figsize 6.4x3.4 @200dpi`
- **字号**：刻度与标注 ≥7pt；最终放置尺寸下最小字号 ≥5pt（投稿级要求，用 `figure_render_audit` 复核）
- **标注**：x 轴含单位（分）；图例置右下；标题点明"演示模板"
- **可迁移规则**：排名图"排序 + 参考线 + 数值标注"三件套；差异不显著时不要用颜色制造错觉（改灰色分层 + 显著星标）
