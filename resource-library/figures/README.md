# figures/ —— 优秀图

放**优秀图**（PNG/SVG/PDF）。每条 = 图文件 + 同名前缀说明（供训练对照"绘图素养"）。

## 说明模板（`figures/example.md` 可参考）

```markdown
# <图名> 说明

- **图型**：排名条/分布对比/相关矩阵/时间序列/森林图/机制图/…
- **用途**：<支撑哪个结论>
- **为什么优秀**：
  - 配色：<主色/灰基线/方向色>
  - 版式：<多面板顺序/留白/字号>
  - 标注：<单位/图例/显著性/来源>
- **可迁移要点**：<绘此图的审美规则>
```

> 示例说明 `example.md` 为自写演示；图文件请自行放入有权使用的素材。
