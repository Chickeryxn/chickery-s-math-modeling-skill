## 图型与用途

- **图型**：① Y 染色体浓度 vs 检测孕周(按 BMI 分组 + 4% 阈值线)【关系/趋势】；② 期望风险 R(t)(按 BMI 分组 + 各组合优时点)【优化/决策】；③ 女胎非整倍体判别(ROC + 判别得分分布)【分类/判定】。
- **用途**：支撑"BMI 越高越迟达到 4%""各 BMI 组最优 NIPT 时点(与风险水平)""女胎判别力集中在 X 染色体浓度、Z 值无经典升高"——**结论由曲线/阈值线/最优点/ROC 直白表达**，不写文字。
- **数据来源**：code/make_nipt_final.py(读附件 xlsx；孕周"13w+5"正则解析；Y 浓度=分数×100 换算成 %)。

## 为什么优秀（可迁移的绘图规则）

- **配色**：主色 #1A6FC4 + 分组色 #4C9A2A/#E08214(SiC 类)、阈值/异常 #B91C1C、基线灰 #767676——**饱和深色、不透明**。
- **版式**：C1 散点+分组幂律拟合+4% 阈值线+≤12w 早窗口；C2 各 BMI 组风险曲线+最优点(▲)+12/27w 阈值线；C3 左 ROC+右得分分布(step 轮廓、类不均衡标注)——多面板、bbox_inches='tight'、去网格、内容不越框。
- **字号**：中文宋体、西文/数字 Times 衬线(SimSun 回退)、数学 STIX；**物理符号(Y、w、BMI、R(t)、t、AUC 等)全局加粗**；普通文字常规字重；刻度/轴标签达标(坐标轴文字放大贴轴如 3D 图所演示)。
- **标注**：图例黑边不透明、置于坐标区内；4% 阈值线、≤12w/≥28w 区间、最优点标注(t*/R)、ROC 对角参考线、AUC 在图例；得分分布各用不透明 step 轮廓(避免半透明遮盖)；轴带单位。
- **可迁移规则**：统计/决策题"**按分组着色 + 阈值线/最优点/ROC 来直白表达结论，不写文字**"；类不平衡用 step 轮廓 + 标注；风险目标给"人工权重"说明；矢量PDF 保证放大不糊。

## 本次我们做过的全部工作（审美规范与迭代修正，均已强调到位）

- 审美规范：中文宋体+西文 Times 衬线+数学 STIX；物理符号全局加粗(mathtext.default='bf')、普通文字常规字重且字号按图紧凑度调；数据不透明；无网格；黑边不透明图例；内容不超图片框；结论由图直白表达(阈值线/分组/最优点/ROC)，不写文字结论。
- 迭代修正：Y 浓度由"分数被误当整数"改×100 成百分比；删除盖在散点上的白色统计框、并入标题；类不均衡用不透明 step 轮廓；\mathcal{R} 缺字→改 R(并走统一加粗)；去网格、图例移入坐标区；字体粗细多次校准(描边加粗过粗回退)；矢量PDF+PNG@300dpi 双导出。
- 诚实降级：①C2 期望"最优时点随 BMI 变化"不成立(λ=0.25、L=1/3/5 下最优恒落 ≤12周 窗口末端，BMI 只抬风险水平)②C3 期望"综合>单指标"不成立(女胎 Z 值失效≈0.5，X 浓度才是主导 AUC≈0.76 且≈综合)——均如实呈现并作"待加强项/人判项"记录，未伪造。
