## 图型与用途

- **图型**：① SiC 反射光谱 + 干涉条纹(10°/15° 两面板，标注 Δν̃)；② 外延层厚度反演(两入射角对照，级次-波数线性回归 + 误差棒点图)；③ 多光束判据：Si vs SiC(左：相对调制深度曲线；右：可见度/2次谐波比柱状图)。
- **用途**：支撑"条纹间距蕴含厚度、可用两入射角互检""两角度给出一致厚度(差值<1%)""Si 高折射率差→强多光束需修正，SiC 近似两光束"等结论——均由**图(条纹/回归/柱高差)直白表达**，不写文字结论。
- **数据来源**：code/render_figures_2025B.py（读附件 xlsx；第1列波数 cm-1、第2列反射率 %）。

## 为什么优秀（可迁移的绘图规则）

- **配色**：主色 #1A6FC4(SiC)、方向色 #B91C1C(Si/阈值)、辅助 #E08214(15°)、灰基线 #767676(参考)——**饱和深色、不透明**、不滥用红绿。
- **版式**：两面板共享 x(波数)；左大右小(width_ratios)突出回归/对比；figsize 约 6.6x4.0–4.2 @dpi=300；bbox_inches='tight' 内容不越框；**去网格**、白底细轴。
- **字号**：中文宋体、西文/数字 Times 衬线(SimSun 回退)、数学 STIX；**物理符号(Δν̃、d、m、θ′、V、A₁/A₂)全局加粗**；普通文字常规字重；轴标签 fontsize 10.5、刻度 9，图例≥7.5。
- **标注**：图例黑边不透明、置于坐标区内；干涉谷标记(v)、Δν̃ 双向箭头标注；两角厚度点+误差棒；柱图**hatch 与图例一致**(Si=//、SiC=..，颜色 Si 红/SiC 蓝)；轴带单位(波数 cm^-1、厚度 μm)。
- **可迁移规则**：光谱/信号题"**两角度/两条件对照 + 周期/厚度定量标注回归 + 二级特征(谐波比)柱状对照**"；对比柱用 hatch 区分且与图例一致；矢量PDF 保证放大不糊。

## 素养对照（逐维）

- **绘图素养**：两面板共享轴+定量标注；回归+误差棒；柱状 hatch 与图例一致；无网格黑边图例；矢量PDF。

- **表达素养**：结论由条纹/回归/柱高差直白表达；标题中性(如"外延层厚度反演(两入射角对照)")。

- **创新素养**：用"两角一致性+残差/谐波比"把"是否多光束"量化，而非只定性地想。
- **完整素养**：从光谱→厚度→多光束判据一条链，覆盖题目信息。
