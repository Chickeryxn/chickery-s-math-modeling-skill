# 顶刊论文绘图风格规范（Top-Journal Figure Style Guide）

> 类别：figures · 类型：绘图规范（自写，MIT）· 来源：用户提供的 3 张顶刊示例图（Figure 3 分组柱状、Figure 6 折线、Figure 7 八面板柱状）+ 用户明确要求。仅记录规范，不复用/不拷贝任何第三方图片。
> 用途：作为训练模式与真实论文的**审美与可读性基准**；绘图技能（math-figure-generator）与复盘对照均遵循此规范。

## 一、识图总结：三张示例图共有的风格

| 维度 | 观察到的顶刊风格 | 本项目执行 |
|---|---|---|
| 字体 | 全正文衬线（Times 类）；轴标签/标题**加粗**；刻度数衬线 | 中文=**宋体(SimSun)**；西文/数字=经 SimSun 衬线回退（Times 类）或纯 Times；数学=STIX（Times 类）；标题加粗 |
| 图例 | **黑色边框 + 不透明白底**方框，置于右上/上中，直排 | 黑边、framealpha=1.0、不透明，one-per-series |
| 数据主体 | **完全不透明**（线条、柱、散点、填充均实心、高饱和深色）；用线型/标记/颜色区分而非透明 | 数据 alpha=1.0；仅文字可带透明度 |
| 颜色 | 黑、深红、蓝、洋红/紫、绿等**饱和深色**，绝不清一色浅色 | 使用饱和深色板（黑/深红/藏青/深绿/橙/紫/品红/青） |
| 背景 | **白底、细黑轴**（左/下轴）、**无网格**（数据密时不加网格以免冗杂） | 去网格；白背景；数据密（散点/多面板）时尤其不加网格 |
| 标记 | 每个序列用**语义化标记**（方/圆/上三角/下三角/菱形/对勾），区分清晰 | 轨迹/对象用贴合实际的标记（如导弹“>”、无人机“s”、烟幕“*”） |
| 信息密度 | 一图一个清晰结论；多面板用 (a)/(b) 副题；无装饰性 3D、无误导截断 | 结论先行标题；面板标注；无假 3D；轴带单位 |

## 二、硬性规则（对本项目所有图）

1. **字体**：中文全部宋体（SimSun）；英文与阿拉伯数字用 Times New Roman（不可实现时用类似衬线，如 SimSun 自带西文衬线；数学用 STIX）。轴标签/标题加粗（用加粗变体，不可用时回退常规字重）。
2. **不透明**：除文字外，数据（线条/柱/散点/面/误差带）一律 alpha=1.0；不用半透明遮盖数据、不用透明渐变区分序列。
3. **颜色**：用饱和深色板；不同序列用颜色+线型+标记三重区分，避免同色系浅色。
4. **背景**：白底、左/下细黑轴；**默认去网格**；数据稠密（散点堆叠、多面板）时绝不加网格，防止观感冗杂；图例黑边不透明盒子。
5. **标记贴合实际**：模型/对象轨迹图例标记尽量匹配问题实体（如导弹、无人机、烟幕云团用不同语义标记），不混用。
6. **可信呈现**：不在图内造假数值；不误导性截断（纵轴从 0 或合理起点）；不做装饰 3D；图注/结论与证据一致。
7. **渲染证据**：进论文/入库的 Type 2–4 图须带 <name>.render.json（status=PASS, rendered_at, checks, source）。

## 三、可复用规则（绘制/自查清单）

- [ ] 中文宋体、西文与数字 Times/类 Times、数学 STIX；无“方框”缺字
- [ ] 数据不透明（alpha=1.0），颜色饱和非浅色序列
- [ ] 无网格、白底、左/下轴；图例黑边不透明
- [ ] 标记语义化、与实体对应；线型/颜色区分清晰
- [ ] 标题=结论；轴带单位；纵轴不误导截断；无装饰 3D
- [ ] 每张 Type2–4 图有 <name>.render.json（PASS + rendered_at + checks + source）
