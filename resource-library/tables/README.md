# tables/ —— 优秀表格

放**优秀表格**（三线表/数据表/对比表）+ 说明，训练对照"证据/表达素养"。每条目二选一：

- **条目目录**（推荐）：`tables/<entry_id>/{README.md, content/(表格 .tex/.csv), code/(生成脚本可选), data/(原始数据可选)}`
- **扁平条目**（兼容）：`tables/<name>.md`（或 `.tex` 表格 + 同名说明）

`content/`、`code/`、`data/` 为支持目录，由 `scripts/resource_index.py` 归入 `supporting`。

## 模板（按此填，必填/选填标明）

```markdown
- **category**：tables
- **entry_id**：<唯一 id>
- **source**：<出处/数据来源>                  （必填）
- **tags**：<表格用途关键词>

## 用途
- <参数表 / 结果对比 / 灵敏度 / 符号表 / ……支撑哪个结论>     （必填）

## 结构与语义
- **列**：<指标 | 主方法 | 基线 | 差值 | 不确定性(±) 等，说明每列含义>
- **行**：<每行代表什么，排序按什么优先>
- **显著性**：<如何标注显著性/置信区间/来源>

## 格式
- **命令**：`booktabs` 三线表（`\toprule \midrule \bottomrule`）；数值列右对齐；单位入表头
- **对齐/单位**：<数值右对齐、单位在表头或行首>

## 可迁移做表规则
- <一张表只讲一个结论；对比表"指标—双方—差—不确定性—来源"五列是通用骨架>   （必填）

## 复现
- 生成脚本：`code/xxx.py`（可选）；原始数据：`data/`（可选）。

## 素养对照（可迁移规则）
- **证据素养**：<每格可溯源；差值带不确定性/显著性>
- **表达素养**：<表头自解释、只讲一个结论、单位规范>
- **完整素养**：<覆盖所有需对比的方案/指标>

## 训练对照锚点（training-reflector 用时）
> <拿你的表格与这条对比：是否三线表？列是否自解释？是否带差值/不确定性/来源？>

## 完整性自检清单
- [ ] 含"用途"与"每列含义"
- [ ] 含显著性/不确定性/来源标注
- [ ] 用 booktabs 三线表
- [ ] 引用的 code/data 路径真实存在
- [ ] 已登记：`python scripts/resource_index.py .`
```
