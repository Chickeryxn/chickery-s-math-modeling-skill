- **tags**：结果表、理想面参数、调节量、接收比、三线表、口径

## 用途
- 支撑"定理想面（焦距/顶点）""调节后反射面贴近理想面（节点/伸缩量、RMS 或距变）""接收比提升（调节前 vs 后）"三个结论；用约束满足情况与增益归因支撑可靠性。

## 结构与语义
- **列**：理想面表——焦距、顶点坐标、口径/口径半径；调节表——促动器伸缩量、节点距变（相对 0.07%）、RMS 或最大误差；接收比表——调节前/后接收比、相对提升、口径（有效圆盘半径）、是否归因。
- **行**：理想面每问一行；调节表每节点/每问一行；接收比表每问一行。
- **显著性**：标注单位（m、rad、%）、口径（R 300 vs 300.4、工作态口径）、约束满足（≤0.07%、±0.6m）、是否妥协解、蒙特卡洛/加权口径。

## 格式
- **命令**：booktabs 三线表（\`\\toprule \\midrule \\bottomrule\`）；数值右对齐；单位入表头。
- **对齐/单位**：长度 m、距变/接收比 %、角度 rad；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：理想面表讲"调成什么样"，调节表讲"怎么调/误差多少"，接收比表讲"增益多少/是否可信"。
- 必带"口径、约束满足、是否妥协解/增益归因"，否则"提升 36%"或"RMS 3mm"无法核实、且易夸大。
