# 表格：信用评分 / 信贷决策 / 模型评估 / 外部冲击表

- **category**：tables
- **entry_id**：2020C_table_result_credit
- **source**：自写提炼（2020 CUMCM C 题 C109/C142/C170/C227/C305 的共性）。
- **year/contest**：2020 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：评分表、信贷决策、评估指标、外部冲击、三线表、口径

## 用途
- 支撑"企业信用评分/违约概率与评级""信贷策略（额度/利率/拒贷）""模型评估（AUC/准确率/基线）""外部冲击后调整"四个结论；用评分权重、决策表、评估指标、冲击对比支撑。

## 结构与语义
- **列**：评分表——企业、特征、评分/违约概率、评级；信贷表——评级/企业、额度（万元）、利率、是否放贷、期望收益/风险；评估表——模型、AUC、准确率、训练/测试、基线/交叉验证；冲击表——情形、乘数/折价、调整后额度/利率、收益。
- **行**：每企业/每评级/每模型/每情形一行。
- **显著性**：标注单位（额度万元、利率%、金额元）、评估口径（AUC/准确率/KS/测试集）、基线、是否满足自身约束（各行加总=总额）、模型-代码-结果一致、外部冲击参数与敏感性。

## 格式
- **命令**：booktabs 三线表（\`\\toprule \\midrule \\bottomrule\`）；数值右对齐；单位入表头。
- **对齐/单位**：额度万元、利率%、金额元、概率无量纲；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：评分表讲"风险/评级"，信贷表讲"贷多少/什么价/拒不拒"，评估表讲"模型可不可靠"，冲击表讲"外部扰动后怎样"。
- 必带"单位、评估口径（AUC/测试/基线/交叉验证）、是否满足自身约束、模型-代码-结果一致、参数来源与敏感性"，否则"最优/准确率/可靠"无法核实、也可能夸大或过拟合。

## 复现
