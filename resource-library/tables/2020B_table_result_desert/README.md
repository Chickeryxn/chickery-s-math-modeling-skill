# 表格：各关最优策略 / 剩余资金 / 买量 / 期望收益表

- **category**：tables
- **entry_id**：2020B_table_result_desert
- **source**：自写提炼（2020 CUMCM B 题 B078/B108/B125/B175 的共性）。
- **year/contest**：2020 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：策略表、剩余资金、买量、期望收益、三线表、口径

## 用途
- 支撑"各关最优策略（路线/是否挖矿/买量）""到终点剩余资金""是否到期""期望收益+失败率""多人决策"五个结论；用确定性→随机→多主体逐步结果 + 保留兜底支撑。

## 结构与语义
- **列**：策略表——关卡、路线、是否挖矿、购买水/食物量、消耗、剩余资金、是否到期；期望表——关卡、期望收益、失败率、天气/随机口径、多方策略概率。
- **行**：每关/每方案一行。
- **显著性**：标注口径（消耗倍率、价格、负重、收益、天气等效、沙暴概率）、是否到期、期望+失败率、随机性（多实现/置信/种子）、是否"幸存者偏差/主观假设/退化"。

## 格式
- **命令**：booktabs 三线表（\`\\toprule \\midrule \\bottomrule\`）；数值右对齐；单位入表头。
- **对齐/单位**：水/食 箱或 kg、资金 元、期望/失败率 无量纲/%、负重 kg；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：策略表讲"怎么走/挖不挖/买多少/剩多少/到没到"，期望表讲"随机/多人下预期与风险"。
- 必带"口径（倍率/价格/负重/天气等效）、是否到期、期望+失败率、随机性（多实现/置信/种子）"，否则"最优/剩余 X"无法核实、也可能因幸存者偏差偏乐观。

## 复现
- 生成脚本：无（本条目为做表规则）；2020B 具体数值见题目与论文。

## 素养对照（可迁移规则）
- **证据素养**：每格可溯源、带口径/是否到期/期望+失败率/随机性、诚实标幸存者偏差与主观假设。
- **表达素养**：表头自解释、只讲一个结论、单位规范。
