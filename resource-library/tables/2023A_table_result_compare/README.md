# 表格：镜场效率/功率结果与设计参数表

- **category**：tables
- **entry_id**：2023A_table_result_compare
- **source**：自写提炼（2023 CUMCM A 题 A092/A127/A165/A175 的共性）。
- **year/contest**：2023 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：结果表、设计参数、月均/年均、三线表、口径

## 用途
- 支撑"给布局算指标"（月均/年均光学效率与功率、单位面积功率）与"设计最优布局"（塔位/尺寸/安装高/数目/面积）两个结论；用 Q1/Q2/Q3 对比说明"效率提升来自余弦、自由度增加但指标折中"。

## 结构与语义
- **列**：月均/年均——日期（12 月）、平均光学效率、平均余弦/阴影遮挡/截断效率、单位面积热功率；设计参数——塔位坐标、镜尺寸（宽×高）、安装高、总面数、总面积。
- **行**：月均表每月 21 日一行；设计参数表每问（Q1/Q2/Q3）一行或一列。
- **显著性**：标注年均口径（每月21日5时点等权 vs 按日照积分）、是否达到额定（60MW）、是否全局最优；单位（kW/m²、MW、m、m²）入表头。

## 格式
- **命令**：booktabs 三线表（`\toprule \midrule \bottomrule`）；数值右对齐；单位入表头。
- **对齐/单位**：效率无量纲、功率 kW/m² 或 MW、面积 m²、长度 m，全部入表头。

## 可迁移做表规则
- 一张表只讲一个结论：月均/年均表讲"指标是什么"，设计参数表讲"怎么布局"，对比表讲"哪个更好/差在哪"。
- 结论表必须带"口径（时刻/加权）、达标标志、最优性"列，否则"0.6 vs 0.7"无意义。

## 复现
- 生成脚本：无（本条目为做表规则）；2023A 具体数值见题目与论文。

## 素养对照（可迁移规则）
- **证据素养**：每格可溯源、带口径（时刻/加权/单位）、诚实标注未达额定/非全局最优。
