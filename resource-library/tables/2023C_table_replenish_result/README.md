# 表格：补货/定价结果与品类对比表

- **category**：tables
- **entry_id**：2023C_table_replenish_result
- **source**：自写提炼（2023 CUMCM C 题 C050/C126/C228/C235 的共性）。
- **year/contest**：2023 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：补货定价表、品类/单品对比、需求满足度、三线表、口径

## 用途
- 支撑"各品类/单品补货量与定价策略"（未来一周/单日）与"收益最大/需求满足度"结论；用"品类相关性/弹性""最优 vs 基准/不同方案"对比支撑定价逻辑。

## 结构与语义
- **列**：品类/单品、单位成本、定价、加成率、补货量、销量、需求满足度、损耗率；对比表——品类相关性/弹性、收益（目标 vs 基准），单品利润率。
- **行**：每个品类/单品一行；每个方案/每问一行（对比）。
- **显著性**：标价格弹性/显著性、需求满足度（0~1，不应超 1）、口径（周/日、单位 kg/元）、对比基准。

## 格式
- **命令**：booktabs 三线表（`\toprule \midrule \bottomrule`）；数值右对齐；单位入表头。
- **对齐/单位**：价格元/kg、量 kg、损耗/加成率 %、需求满足度 0~1；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：补货定价表讲"怎么定/补多少"，对比表讲"哪个品类弹性大/哪个方案更优、为什么"。
- 带"弹性/显著性、需求满足度、口径、基准"，否则"最优"无参照、满足度>1 或负贡献单品会暴露目标-约束不自洽。

## 复现

- **证据素养**：每格可溯源、带弹性/显著性/需求满足度/口径/基准。
