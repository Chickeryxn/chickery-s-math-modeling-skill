# 表格：定位/调整结果表（初始→调整后、误差、发射数）

- **category**：tables
- **entry_id**：2022B_table_result_localization
- **source**：自写提炼（2022 CUMCM B 题 B030/B035/B086 的共性）。
- **year/contest**：2022 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：定位/调整结果表、误差、发射数、三线表、口径

## 用途
- 支撑"定位是否正确（闭式解/误差收敛）""最少发射机数""调整后是否均匀分布"三个结论；用初始极坐标→调整后极坐标、误差收敛、平面化检验值支撑。

## 结构与语义
- **列**：无人机编号、初始极坐标（m/°）、调整后极坐标、与前/理想角差、径向/切向调整量；另外最少发射机数、误差收敛值、平面化检验值。
- **行**：每架无人机一行；每方案/每轮一行（误差、发射数）。
- **显著性**：标注单位（m、°）、误差口径（±0.5°/1°/1%）、理想值、是否收敛到目标精度、是否全局检验通过。

## 格式
- **命令**：booktabs 三线表（`\toprule \midrule \bottomrule`）；数值右对齐；单位/角度入表头。
- **对齐/单位**：极径 m、极角 °、误差 ° 或无量纲；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：定位表讲"由观测到坐标"，调整表讲"如何一步步到理想位置"，误差/发射数表讲"最少资源与精度"。
- 带"误差口径、理想值、收敛目标、全局检验"，否则"0.3°"与"15%"无意义、也无法证明整体合格。
