- **category**：tables
- **entry_id**：2020A_table_result_reflow
- **source**：自写提炼（2020 CUMCM A 题 A070/A147/A195/A212 的共性）。
- **year/contest**：2020 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：参数表、关键温度、最优解、指标表、三线表、口径

## 用途
- 支撑"机理参数辨识（α/k/h/τ）与拟合误差""给布局/温区算关键点温度""最优温区温度与带速（满足制程）""面积/对称度指标"四个结论；用约束满足与贴界情况支撑可靠性。

## 结构与语义
- **列**：参数表——符号、值、单位、拟合误差(RMSE/MAE)；关键温度表——位置/时刻、温度；最优解表——温区温度、带速、面积、对称度、是否满足制程；指标表——S/E、归一化权重、约束满足。
- **行**：每参数/每位置/每问一行。
- **显著性**：标注单位（℃ vs K、℃·s、cm/min）、误差、约束满足（升降温斜率/150-190时长/>217时长/峰值）、是否贴界（峰值 240 下限/带速上限）、积分方式（梯形 vs 矩形）。

## 格式
- **命令**：booktabs 三线表（\`\\toprule \\midrule \\bottomrule\`）；数值右对齐；单位入表头。
- **对齐/单位**：温度 ℃、时间 s、面积 ℃·s、带速 cm/min、α/h/k/τ 单位入表头；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：参数表讲"物性/辨识+误差"，关键温度表讲"复现/正演结果"，最优表讲"满足制程的最优解"，指标表讲"多目标权衡"。
- 必带"单位、误差、约束逐条满足、是否贴界、积分方式"，否则"最优/满足"与"0.02℃ 误差"无法核实、也可能夸大。
