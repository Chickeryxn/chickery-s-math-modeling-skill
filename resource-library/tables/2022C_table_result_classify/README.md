## 用途
- 支撑"风化与类型/纹饰/颜色是否相关""高钾/铅钡分类规律""亚类划分""未知样品鉴别"四个结论；用检验 p 值、判别阈值/边界、鉴别结果 + 敏感性支撑。

## 结构与语义
- **列**：关联表——变量对、检验量（x² / Fisher / 秩相关 p）、关联度、结论；分类/亚类表——类别、判别特征/阈值、样本数、亚类数、边界/重要性；鉴别表——样品号、判别得分/类别、敏感性；关联差异表——类别、母序列、关联度范围。
- **行**：关联表每变量对一行；分类/亚类表每类别/每亚类一行；鉴别表每样品一行。
- **显著性**：标注 p 值、阈值、交叉验证/敏感性（扰动/阈值）、样本非平衡、口径（含量 vs 对数比值、Pearson vs Spearman）。

## 格式
- **命令**：booktabs 三线表（\`\\toprule \\midrule \\bottomrule\`）；数值右对齐；单位入表头（% 或无量纲）。
- **对齐/单位**：占比 %、检验量无量纲、p 值小数；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：关联表讲"相关/不相关"，分类表讲"怎么分/以何特征分"，鉴别表讲"未知样品归哪类"，差异表讲"两类关联结构是否不同"。
- 带"检验 p 值、阈值、交叉验证、敏感性、非平衡/口径"，否则"显著/正确率"无法核实、也可能夸大。
