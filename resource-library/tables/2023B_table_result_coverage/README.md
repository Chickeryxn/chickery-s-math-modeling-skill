# 表格：覆盖宽度/重叠率与布设结果表

- **category**：tables
- **entry_id**：2023B_table_result_coverage
- **source**：自写提炼（2023 CUMCM B 题 B226/B311/B477 的共性）。
- **year/contest**：2023 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：计算表、布设结果表、三线表、单位、漏测/重叠

## 用途
- 支撑"给位置算覆盖/重叠"（不同位置/β/距离）与"布设是否达成 10%~20% 重叠、覆盖全区域"两个结论；用"深水重叠偏大、浅水漏测""沿等深线覆盖最宽"体现口径与边界判断。

## 结构与语义
- **列**：计算表——测线距中心距离（m/海里）、海水深度、覆盖宽度、与前一条重叠率；布设结果表——条数、总长、漏测海区占比、重叠率>20% 段总长。
- **行**：计算表每位置/每 (β,距离) 一行；布设结果表每问/每方案一行。
- **显著性**：标注单位（m/海里）、重叠率正负（负=漏测）、覆盖率与漏测率互补关系（漏测 2.3%⇔覆盖 97.7%）。

## 格式
- **命令**：booktabs 三线表（`\toprule \midrule \bottomrule`）；数值右对齐；单位入表头。
- **对齐/单位**：长度 m（或海里，1海里=1852m）入表头；覆盖/重叠率用 %；角度 °。

## 可迁移做表规则
- 一张表只讲一个结论：计算表讲"覆盖/重叠随位置变"，布设表讲"是否达标/漏测多少"。
- 带单位与"互补/临界"标注（漏测率+覆盖率=1、重叠率负=漏测），否则"2.3%"与"97.7%"看似矛盾。
