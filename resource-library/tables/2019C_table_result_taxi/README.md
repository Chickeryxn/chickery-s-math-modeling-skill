# 表格：决策时段 / 收益 / 敏感性 / 上车点 / 优先权表

- **category**：tables
- **entry_id**：2019C_table_result_taxi
- **source**：自写提炼（2019 CUMCM C 题 C044/C137/C308 的共性）。
- **year/contest**：2019 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：决策时段、收益、敏感性、上车点、优先权、三线表、口径

## 用途
- 支撑"司机什么时段排队/空返（决策分界）""各时段收益""对相关因素的依赖性（敏感性/鲁棒）""上车点/泊位数与效率""短途优先权插队位置"五个结论；用收益、敏感性、效率、插队位置支撑。

## 结构与语义
- **列**：决策表——时段、策略（排队/空返）、单位时间/总收益；敏感性——参数、变动幅度、收益/时段变化；上车点表——泊位数/上车点、乘客/车辆逗留、效率、是否最优；优先权表——短途距离、空载率、单位时间收益、插队位置。
- **行**：每时段/每参数/每方案一行。
- **显著性**：标注口径（元/h、min、辆/h、km、泊位）、决策分界、敏感性（单因素扫参/噪声/截止时间/权重）、是否落地数值、数据来源（真实/借用）与参数来源。

## 格式
- **命令**：booktabs 三线表（\`\\toprule \\midrule \\bottomrule\`）；数值右对齐；单位入表头。
- **对齐/单位**：收益元/h、时间 min、率辆/h、距离 km、效率无量纲；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：决策表讲"何时做/收益多高"，敏感性表讲"依赖哪些因素/多敏感"，上车点表讲"几点/效率如何"，优先权表讲"短途多靠前/收益均衡"。
- 必带"口径、决策分界、敏感性/鲁棒、是否数值落地、数据/参数来源"，否则"最优/依赖/均衡"无法核实、也可能夸大。
