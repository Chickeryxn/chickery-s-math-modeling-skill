## 用途
- 支撑"温度/组合→转化率/选择性/收率关系""哪个因素影响大""最优组合与收率（含<350℃）""5 次补充实验"四个结论；用 R²/显著性/系数/最优值支撑。

## 结构与语义
- **列**：关系表——组合、温度、转化率、选择性、收率、拟合度；显著性表——因素、SS/F/p（ANOVA/逐步）、标准化系数、影响度；最优表——最优组合（各因素）、温度、收率（/限温<350℃）；实验设计表——新增实验点、设计原则、目的。
- **行**：关系表每组合/每温度一行；显著性表每因素一行；最优表每问一行；实验表每次实验一行。
- **显著性**：标注 R²/调整 R²、MSE、F、p、显著性水平、口径（转化率/选择性/收率）、是否"最优/全局/外推"。

## 格式
- **命令**：booktabs 三线表（\`\\toprule \\midrule \\bottomrule\`）；数值右对齐；单位入表头。
- **对齐/单位**：温度 ℃、质量 mg、浓度、收率 %；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：关系表讲"怎么变"，显著性表讲"谁影响大/是否显著"，最优表讲"最优在哪/收率多少"，实验表讲"补哪些实验、为何"。
- 必带"口径、R²/显著性、是否局部/外推"，否则"更优/显著/5次实验"无法核实，也可能夸大。
