- **category**：tables

- **tags**：方案表、对比表、敏感性、三线表、口径

## 用途
- 交付"逐地块-季节-作物-年份-面积"最优方案；跨问题/情景的收益对比；参数敏感性（管理便利 vs 收益、最大影响因素）。支撑"哪个因素影响最大、是否值得牺牲收益换管理便利"。

## 结构与语义
- **列**：方案表——地块、季节、作物、年份、面积；对比表——问题/情景、总收益、相对基准变化率、方法（精确/启发式/蒙特卡洛）、口径说明；敏感性表——参数（p,q、λ、波动幅度）× 收益，找出最大/最小影响。
- **行**：方案表每"地块-季-作物-年"一行；对比表每"问题/情景"一行；敏感性表每参数一行或每参数×取值一格。
- **显著性**：标注口径（地块数 34/54、亩数 1201/1213、年 7/8、单位元）；标注是否全局最优/近似；跨情形口径不同则不作直接比较。

## 格式
- **命令**：booktabs 三线表（`\toprule \midrule \bottomrule`）；数值列右对齐；单位入表头。
- **对齐/单位**：面积单位亩、收益元入表头；数值保留一致有效位；0-1/口径用一致符号。

## 可迁移做表规则
- 一张表只讲一个结论：方案表讲"怎么种"，对比表讲"哪个更好/差多少/为什么"，敏感性表讲"哪个因素影响最大"。三表分工，避免混在一张。
- 对比表通用骨架"指标—方案—差—不确定性/口径—来源"；必带方法与基线，否则"更好"无参照。
