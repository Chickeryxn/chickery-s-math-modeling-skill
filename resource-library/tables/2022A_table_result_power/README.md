# 表格：运动时程 / 最优阻尼与功率结果表

- **category**：tables
- **entry_id**：2022A_table_result_power
- **source**：自写提炼（2022 CUMCM A 题 A001/A022/A171 的共性）。
- **year/contest**：2022 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：时程表、最优参数、模型检验、三线表、口径

## 用途
- 支撑"给定参数算运动"（各时刻位移/速度/角位移/角速度）与"最优阻尼下最大功率"两个结论；用 Q2 vs Q4 对比说明"引入纵摇/旋转通道增益"，用模型检验（误差、扰动敏感度）支撑可靠性。

## 结构与语义
- **列**：时程表——时刻（10/20/40/60/100s）、浮子/振子位移、速度（及角位移/角速度）；最优参数表——问、最优阻尼（直线/旋转/幂）、幂指数、最大输出功率、是否边界；检验表——误差%、扰动敏感度。
- **行**：时程表每时刻/每对象一行；最优参数表每问一行；检验表每检验项一行。
- **显著性**：标注单位（m、m/s、rad、rad/s、W）、频率/参数口径、是否边界/局部最优、解析-数值差异。

## 格式
- **命令**：booktabs 三线表（`\toprule \midrule \bottomrule`）；数值右对齐；单位入表头。
- **对齐/单位**：位移/速度/角度/功率单位入表头；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：时程表讲"运动响应"，最优表讲"最优参数与功率"，检验表讲"可靠性"；三表分工。
- 最优参数表必带"单位、频率口径、是否边界/局部、是否交叉验证"，否则"最优"无依据。
