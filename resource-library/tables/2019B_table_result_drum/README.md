# 表格：理想策略 / 各工况倾角 / 调整策略 / 精确控制表

- **category**：tables
- **entry_id**：2019B_table_result_drum
- **source**：自写提炼（2019 CUMCM B 题 B047/B057/B136 的共性）。
- **year/contest**：2019 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：策略表、倾角表、调整方案、三线表、口径

## 用途
- 支撑"理想最优策略（力/时机/颠高）""现实中各工况 0.1s 倾角""是否需要调整及方案""精确控制下各队员力/时机与实施效果"四个结论；用小角度解耦、全同步、反演正控支撑。

## 结构与语义
- **列**：策略表——人数、绳长、力、时机、颠高、目标；倾角表——工况（力/时机组合）、0.1s 倾角；调整表——初始/调整后 倾角、颠高、策略；精确控制表——队员、力、时机、倾角/颠高、误差下效果。
- **行**：每策略/每工况/每方案一行。
- **显著性**：标注单位（N、s、m、°）、口径（e、H0、L、R、质量）、假设（小角度/对称/碰撞瞬时）、是否满足下限（颠高≥40cm）、摘要/正文数值一致性。

## 格式
- **命令**：booktabs 三线表（\`\\toprule \\midrule \\bottomrule\`）；数值右对齐；单位入表头。
- **对齐/单位**：力 N、时机 s、高度 m、倾角 °；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：策略表讲"最优怎么用力/多高"，倾角表讲"误差→倾斜"，调整表讲"要不要/怎么调"，精确控制表讲"能否调回竖直/现实效果"。
- 必带"单位、口径（e/H0/L/R）、假设、是否满足下限、摘要/正文一致性"，否则"最优/可行性"无法核实、也可能夸大。
