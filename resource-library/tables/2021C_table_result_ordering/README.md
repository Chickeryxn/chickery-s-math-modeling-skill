- **category**：tables
- **entry_id**：2021C_table_result_ordering
- **source**：自写提炼（2021 CUMCM C 题 C066/C085/C169/C283 的共性）。

- **tags**：评价排名、订购方案、转运方案、结构优化、产能、三线表、口径

## 用途
- 支撑"哪些供应商最重要/选多少家""24 周最经济订购+损耗最少转运""多 A 少 C 结构优化""产能提高多少"四个结论；用排名/家数/成本/损耗/占比/产能 + 方案效果支撑。

## 结构与语义
- **列**：评价表——供应商、综合得分/排名、各指标、权重；方案表——周、类别、订购量、供货量、接收量、库存、产能、损耗率、成本；结构表——A/B/C 占比、成本节省；产能表——区间、每周产能提升、瓶颈。
- **行**：评价表每供应商一行；方案表每周一行；结构/产能每方案/每问一行。
- **显著性**：标注口径（单位、损耗率 α、成本口径、换算系数 0.6/0.66/0.72）、参数来源与敏感性、"至少/最大/模拟"标注、随机性稳健性。

## 格式
- **命令**：booktabs 三线表（\`\\toprule \\midrule \\bottomrule\`）；数值右对齐；单位入表头。
- **对齐/单位**：量 m³、成本 元/m³、损耗率/占比 %、产能 m³/周；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：评价表讲"谁重要/前50"，方案表讲"订多少/运多少/成本损耗",结构表讲"多 A 少 C 效果"，产能表讲"能提多少/瓶颈"。
- 必带"口径（单位/损耗率/换算系数）、参数来源与敏感性、是否模拟/近似、随机性稳健性"，否则"更经济/更省/提高 X"无法核实、也可能夸大。
