# 表格：决策方案 × 指标结果表

- **category**：tables
- **entry_id**：2024B_table_decision_result
- **source**：自写提炼（2024 CUMCM B 题 B159/B195/B196 的表结构共性）。
- **year/contest**：2024 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：决策表、指标表、三线表、跨情形比较、决策依据

## 用途
- 支撑"各阶段是否检测/是否拆解"的决策方案与对应指标（期望利润/单位成本），让每问的结论可查、可核、可比较；也用于"多方案对比（如枚举 16 方案）"。

## 结构与语义
- **列**：决策节点（是否检零件 1/2、是否检成品、是否拆解…）× 情形/方案；值为 0/1 或"是/否"；另附指标列（期望利润、单位成本，单位元/件）。
- **行**：决策表中"每个情形/方案一行"；指标表中"每个情形一行×各指标列"。
- **显著性**：标注口径（单位、基数、元/件）、是否可跨情形比较；给"决策依据"（为何检/为何不检）；给"决策稳定区间"（次品率扰动下是否变）。

## 格式
- **命令**：booktabs 三线表（`\toprule \midrule \bottomrule`）；数值列右对齐；单位入表头。
- **对齐/单位**：成本/收益单位（元/件）入表头；0/1 与"是/否"用一致符号；指标保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：决策表讲"每条情形怎么决策"，指标表讲"每条情形的指标"。
- 对比表通用骨架"指标—方案—差—不确定性/口径—来源"：跨情形比较须说明是否可比（参数不同则只作展示不作比较）。

## 复现
- 生成脚本：无（本条目为做表规则，非具体数据）；2024B 具体决策/指标见原题与论文。

## 素养对照（可迁移规则）
- **证据素养**：每格可溯源、带参数/单位/口径、诚实标注跨情形不可比；给决策稳定区间。
- **表达素养**：表头自解释、只讲一个结论、单位规范。
- **完整素养**：覆盖所有需决策的节点与需展示的情形/方案。
