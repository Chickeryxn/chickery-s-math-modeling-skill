# 表格：最优控制参数 / 压力波动 / 方案对比表

- **category**：tables
- **entry_id**：2019A_table_result_pressure
- **source**：自写提炼（2019 CUMCM A 题 A023/A190/A240 的共性）。
- **year/contest**：2019 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：控制参数表、压力波动、方案对比、三线表、口径

## 用途
- 支撑"最优开阀/角速度/时差/减压阀参数""压力是否稳定在期望值（波动幅值/方差/判稳）""控制方案对比（阈值泄压 vs 电磁阀）"三个结论；用判稳与敏感性支撑可靠性。

## 结构与语义
- **列**：参数表——问、控制参数（开阀时长/ω/时差/减压阈值/开关时长）、值、单位；波动表——目标压力、波动幅值/方差、判稳（偏差和）、是否满足；方案表——方案（泄压/电磁）、ω、波动、评价。
- **行**：每问/每参数/每方案一行。
- **显著性**：标注单位（ms、rad/s、MPa）、判稳（幅值/方差/判据）、口径（周期公共窗口、是否仅末段）、是否全局/网格次优、敏感性（dt/步长/参数）、是否忽略压力波。

## 格式
- **命令**：booktabs 三线表（\`\\toprule \\midrule \\bottomrule\`）；数值右对齐；单位入表头。
- **对齐/单位**：开阀 ms、角速度 rad/s、压力 MPa、密度 mg/mm³；保留一致有效位。

## 可迁移做表规则
- 一张表只讲一个结论：参数表讲"控制参数"，波动表讲"稳不稳定/波动多大"，方案表讲"哪种控制更好"。
- 必带"单位、判稳（幅值/方差）、周期口径、是否全局/网格次优、敏感性、是否忽略压力波"，否则"稳定/最优"无法核实、也可能夸大。
