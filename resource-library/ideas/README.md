# ideas/ —— 优秀创新解题思路

放**优秀创新解题思路卡片**（MD），训练对照"创新/数学"素养。每条目一个文件；若含可复现演示，用条目目录：

- **条目目录**（推荐）：`ideas/<entry_id>/{README.md, code/(演示/求解脚本可选)}`
- **扁平条目**（兼容）：`ideas/<name>.md`

`code/` 为支持目录，由 `scripts/resource_index.py` 归入 `supporting`。

## 卡片模板（按此填，必填/选填标明）

```markdown

- **tags**：<题型/方法关键词>                 （选填）
```
