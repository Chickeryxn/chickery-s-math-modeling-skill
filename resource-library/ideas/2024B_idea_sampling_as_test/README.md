# 思路：把"最小检测次数"当成检验决策

- **category**：ideas
- **entry_id**：2024B_idea_sampling_as_test
- **source**：自写提炼（2024 CUMCM B 题 B159/B195/B196 的共性）。
- **year/contest**：2024 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：抽样检验、假设检验、OC 函数、功效、样本量、序贯抽样

## 一句话
- 题目给的是"信度/置信度"，它对应的是**检验的第一/二类错误**，而不是参数区间估计；所以先把"最小检测次数"落成检验决策，再求满足风险约束的最小样本量。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=一批零配件的次品率 p（被检验总体参数）；变量=样本量 n、检出次品数 k、拒绝阈值 c；关系=k~B(n,p)，接受概率 L(p,n,c) 随 p 单调（OC 函数）；约束=接纳/拒收方向上的风险（α,β）；目标=min n 且同时满足两侧风险。

## 创新点
- 把"95% 信度认定超标则拒收 / 90% 信度认定不超标则接收"分别对应到**第一类/第二类错误**，用双风险不等式反解最小 n；并可加工程容差（如均值误差≤某%）。
- 用**功效函数**权衡检测成本与漏检损失（n 越大小，漏检概率小但成本高）。

## 主要风险
- p₀、p₁（可拒次品率）常是**建模自设**，须说明取值依据；n 的解不一定唯一/最小，要用"最小可行"而非"一对可行"；固定样本量假设检验只是**序贯抽样（期望样本量最小）**的次优近似。

## 教训
- 先判断"这题要的是检验还是估计"；方向（单侧/双侧、接收/拒收）要分开；"尽可能少"优先想到序贯/自适应抽样。

## 可迁移到
- 同类题（同法）：验收抽样、A/B 检验、质控合格判定。
- 同思想异解法：方向/风险约束可用精确二项、正态近似、t 统计量、功效函数、泊松近似，按是否已知方差、样本规模、精度要求换。

## 素养对照（可迁移规则）
- **数学素养**：把信度规范成 α/β 与 OC/功效约束；先证单调再反解 n。
- **创新素养**：用"检验视角"而非"估计视角"看待信度；想到序贯抽样。

## 训练对照锚点（training-reflector 用时）
> 拿你的抽样方案与这条对比：是否先区分检验/估计与单双侧？α/β 与 p₀/p₁ 是否说明依据？n 是否为最小可行、是否想到序贯抽样？把最弱一条写进 reflection.md。
