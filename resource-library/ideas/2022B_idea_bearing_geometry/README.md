## 一句话
- 纯方位（仅方向夹角）定位先写成**角度几何**（正弦定理/三角形角关系）解析求坐标；"最少发射机数/编号唯一"用**对称性与不变角关系 + 化归 + 引理**（而非枚举/估计），给出"足够且必要"的结论。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=发射/接收机（编队相对位置固定）；变量=各机极坐标与接收方位角；关系=三角形（圆心-两发射-接收）中的正弦定理与角关系（$ho_k=ho_jsin(	heta_j+alpha_j-	heta_k)/sinalpha_j$）；约束=仅方向、相对位置不变、编号已知/未知；目标=唯一确定接收机坐标（/最少发射机数）。

## 创新点
- 用"正多边形"角量化（圆周角= m×10°、圆心角= n×40°）建立方位角与编号的**唯一映射**；用集合不交判定"未知编号"可唯一反推，从而化归到已知编号问题。
- 对共面/共圆退化情形（共线、圆心）做特判，避免联立无解/多解。

## 主要风险
- 唯一性依赖角间隔不被误差抹平，须界定 ε 临界；对称位形（镜像）会多解，需破坏对称（如锚定某台已知编号机）；退化/完全对称时需特判。

## 教训
- 先找"对称性与不变角关系"把未知化归为已知，再证"足够且必要"，胜过穷举编号。
