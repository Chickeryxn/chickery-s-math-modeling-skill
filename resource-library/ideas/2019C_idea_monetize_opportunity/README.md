# 思路：把隐性成本/时间货币化 + 量纲归一（单位时间净收益）比较与分界

- **category**：ideas

- **year/contest**：2019 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：机会成本、量纲归一、单位时间净收益、决策分界、阈值

## 一句话
- 比较两个方案（排队 vs 空返、等待 vs 行动）时，先把等待/空跑/潜在收益损失统一折算成**机会成本**，并拉平到"单位时间净收益"再判号——切勿直接用总量。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=在"等待/空返"间选择的主体；变量=等待时间、收益、成本；关系=净收益=收入−直接成本−时间成本（机会成本）；约束=队列/时间/风险；目标=单位时间净收益最大（sgn 判号给分界）。

## 创新点
- 把未被计价的等待、空跑、潜在载客收益损失统一折为同一货币（时间×小时收益）；用"收益相等"平衡点给决策分界/时段；把经验判断翻译成可比量。

## 主要风险
- 小时收益/机会成本参数主观（无来源）；把"损失最小化"误写成"收益最大化"（负收益方案）；忽略个人偏好/风险/经验/季节；把收益率阈值当唯一信号。

## 教训
- 两方案比较先归一化为单位收益再判号；机会成本参数要可辩护；收益方向（正/负）要诚实。

## 可迁移到
- 同类题（同法）：排队/等待决策、资源占用/取舍、机会成本评估、调度/路线选择。
- 同思想异解法：成本换（时间/能耗/风险），统一换（单位时间/单位边际收益/净现值），分界换（收益相等/阈值/敏感性带）。
