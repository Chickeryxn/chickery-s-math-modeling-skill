## 一句话
- 先建完整机理（多个候选），再用**物性与拟合误差为证据**做有理有据的模型降阶与选型；参数不可直接测得时，以控制/边界方程作正演、观测数据作最小二乘反演，并用"分段常数"刻画性能分区。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=受热/传热/反应系统；变量=温度/时间/空间/物性参数；关系=传热/反应微分方程（PDE 或 ODE）+ 边界条件；约束=工艺/物理界限；目标=复现观测/满足工艺/最优化。

## 创新点
- "简单但不失物理"是主动设计：用物性论证+拟合误差决定"一维 PDE vs 集总参数"；升/降温机理不同则分模型；参数（k/τ/α/h）分段辨识——物理可解释、可外推、可约束校验。

## 主要风险
- 选型只靠 RMSE 会过拟合/忽略物理；分段/分模型的边界与参数可能受版本错乱/数值冲突影响；差分格式稳定性（Courant）与网格误差；"忽略热辐射/对流"假设。

## 教训
- 先建机理、再以证据降阶选型，不要"先拍一个简单模型"或"堆复杂度"；把"物性+误差"作为模型取舍的正当理由。

## 可迁移到
- 同类题（同法）：传热/传质/反应/电路等物理过程建模。
- 同思想异解法：机理换 PDE/ODE/集总，辨识换最小二乘/滤波/机器学习，分段换分区/变系数。
