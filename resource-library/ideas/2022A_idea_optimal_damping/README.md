## 一句话
- "能量转化效率最优"先转成"阻尼参数上的标量功率函数极值"；可用解析（稳态频域/力电类比阻抗匹配）则闭式，否则用"ODE 作等式约束 + 数值积分目标 + 稳态平均"的嵌套优化；并用物理不变量/假设回验。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=PTO 阻尼/弹簧参数；变量=阻尼系数（及幂指数）；关系=系统受迫振动稳态响应下，平均输出功率是阻尼参数的标量函数（由 ODE 隐式决定）；目标=max 时均功率；约束=参数区间、几何安全、非负。

## 创新点
- 用**力电比拟**（m-k-k3 ↔ L-R-C）把力学极值变电路阻抗匹配极值，给闭式最优阻尼；对非线性（幂律）用**嵌套优化**（ODE 约束 + 梯形积分 + 稳态平均）。
- 辨别"最优是否落在边界/上界"（如幂律比例系数取上界），并说明是否可放宽；用稳态频响降维。

## 主要风险
- 功率口径（复振幅 vs 瞬时速度）不一致会系统偏差；目标由 ODE 隐式决定、单次评估贵（20万次积分）；最优可能落在边界（边界解）而非内点；双参数近似退化（如旋转阻尼几乎无增益）。

## 教训
- 先看能否闭式（解析/类比），再退到嵌套优化；取稳态平均；诚实区分"边界最优/局部最优/内点最优"，并回验假设。
