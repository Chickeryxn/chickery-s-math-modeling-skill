- **category**：ideas

- **tags**：排队、系统模拟、分状态、蒙特卡洛、上车点、优先权、收益均衡

## 一句话
- 复杂、随机、规则驱动的资源分配/排队系统：机理可解析用排队论/生灭过程，否则用**离散事件系统模拟**（到达分布→放行机制→状态机→截止时间→多次取均值）+ 分状态实验设计，再用单点扰动一个"人为设定参数"检验稳定性；上车点/优先权用目标优化/价值函数给数。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=队列/资源分配系统；变量=泊位数/上车点/放行批次/插队位置；关系=到达/服务/放行/状态转移；约束=安全/车道/批次；目标=效率（1/(乘客逗留+车辆逗留)）最大、收益均衡、总乘车效率最高。

## 创新点
- 显式化复杂规则（分批放行、错位离开、状态机）；分状态（旺季/闲、工作日/假日）实验设计；蒙特卡洛搜索泊位数；用价值函数（空载率+单位时间收益差）做短途优先权均衡。

## 主要风险
- 分布主观未拟合、参数未给值；目标不可封闭解析；"上车点非越多越好"需定量验证；优先权/权重主观；方案二恒负"收益最大化"实为损失最小化；无解析基准/误差带。

## 教训
- 目标无法封闭写出时"固化规则+终止条件→仿真+重复平均逼近"；单点扰动人为参数检验稳定；为"均衡/效率"给定量比对与基准。
