# 思路：预测-决策两段解耦（先评分定风险参数，再组合优化）+ 可解释选型

- **category**：ideas

## 一句话
- 把"风险"先用可解释评分/模型压成 [0,1] 概率（违约概率/守约率），作为下游优化的**已知系数**；并按"样本量/是否可解释/是否要精度"选风险模型，且给评估（准确率/AUC/基线/剪枝）避免过拟合与黑箱。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=企业/个体；变量=特征与额度/利率；关系=特征→评分→违约概率；约束=额度/利率/总预算/期限/流失率；目标=收益最大+风险最小。

## 创新点
- 两段解耦：特征工程（发票/交易/纳税/上下游 → 实力/信誉/供求/供应链粘性等可解释指标）→ 评分（Logistic/评分卡/PCA 指数/Trees/集成给连续概率，XGBoost 多分类评级）→ 组合优化（把概率当系数）。
- 外部冲击=输入扰动/风险乘数，不改模型结构。

## 主要风险
- 样本小、类不平衡 → 过拟合/不可靠（须训练/测试划分、AUC、基线对比、剪枝）；级联误差（用预测值当输入会叠加）；"黑箱/复杂模型"缺可解释；违约概率>某阈值硬截断脱离风险-收益权衡。

## 教训
- 先评估"样本量/是否可解释/是否要精度"，再选评分模型并给基线/交叉验证；把预测结果当"决策系数"而非终点，预测口径与决策口径冲突时显式、可辩护地放宽假设。

## 可迁移到
- 同类题（同法）：信用/风控/评级、保险/医疗风险、违约/流失预测+决策。
- 同思想异解法：评分换（Logistic/评分卡/树/集成/GBDT/XGBoost/神经网络），决策换（单/多目标规划/GA/LINGO/fmincon），外部冲击换（折价/乘数/情景/鲁棒）；评估换（准确率/AUC/KS/混淆矩阵/回测）。
