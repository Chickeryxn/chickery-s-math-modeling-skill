# 思路：状态压缩 + 图上 DP，且按信息量选范式（确定/马尔可夫/多主体）

- **category**：ideas
- **entry_id**：2020B_idea_state_compression

- **year/contest**：2020 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：状态压缩、动态规划、马尔可夫、范式选择、状态空间、图搜索

## 一句话
- 状态（位置/资源/时间）易爆炸时，先用结构性质（"只值得去功能点/某行动恒优恒劣"）压缩为"位置转移+路径长度"，再做图上 DP；并**按信息量/交互**选范式：全部确定→DP、仅当前态→MDP、多玩家→博弈，外层取期望。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=在图上移动、带资源与时间窗的决策主体；变量=状态（天数、位置、资源、资金）与动作；关系=DP/MDP 递推（消耗/获得/转移）；约束=负重上限、资源>0、截止日；目标=终态剩余资产最大（/期望）。

## 创新点
- 压缩状态（Floyd 只留功能点、资源按箱/凸性优化降维、证明"朝功能点最短路缩小"），避免指数爆炸；把同一 DP 框架复用为"确定性最优（内层）+ 期望/博弈（外层）"。

## 主要风险
- 压缩依赖"结构性质"须先证明；资源/时间离散化步长影响精度；状态空间仍大时用剪枝/凸性优化；范式选择错（把随机当确定）会偏乐观（幸存者偏差）。

## 教训
- 先证结构性质压缩状态、再按"信息/交互"选范式，别一上来就上高级范式或全局搜索。

## 可迁移到
- 同类题（同法）：路线/路径决策、资源/任务调度、背包/资金链、无人机/物流配送。
- 同思想异解法：压缩换（图化简/特征聚合/先验剪枝），求解换（DP/最短/分支定界/启发式），范式换（DP/MDP/鲁棒/博弈）。
