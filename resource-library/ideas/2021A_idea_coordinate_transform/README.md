## 一句话
- 对象在某参考系下难描述时，先选一个使主关系"规范化"的坐标系（把轴线旋转到坐标轴），其余量做同一变换，即可在新系沿用旧结论；再用对称性取低维截面，先以廉价代理筛选、后以精确计算验证。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=几何/结构（曲面、编队、反射面）；变量=形状/位置参数；关系=旋转/反射/几何关系；约束=工程（长度、间距、范围）；目标=贴近目标形状/最大化某度量。

## 创新点
- 用坐标旋转把斜入射/任意方位"规范化"为简单情形（轴向对齐），避免整面复杂推导；用轴对称取 2D 截面把已知的问题降为少数参数；用"廉价代理（如总伸缩量/简单积分）→ 精确验证"两步走，避免对数千离散变量盲目优化。

## 主要风险
- 坐标变换要选对"规范化"方向；对称性/代理指标只在特定条件下成立，须用精确计算验证；"廉价代理"若与真实目标不一致会误导筛选。

## 教训
- 遇到复杂几何先问"能否换坐标系/找对称性把它化为简单情形"，再决定用"代理初筛 + 精确验证"省算力。

## 可迁移到
- 同类题（同法）：光学/反射/编队/结构拟合、任意方位几何。
- 同思想异解法：坐标系/基变换、对称群约简、降维投影；代理指标可换成简单积分/范数/粗采样，精确验证用全量计算。

## 素养对照（可迁移规则）

- **创新素养**：廉价代理→精确验证、少算省力。
