# 思路：曲面逼近（定理想面 + 带约束贴近 + 量化增益）与诚实标解

## 一句话
- 把"形状可调系统调到目标曲面"分成三步：先由物理/几何定**理想面**，再用"可测的贴近度量"在**工程约束**下求最优调节，最后**量化增益**（如接收比）——并诚实说明约束是否真满足、增益是否可归因。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=可调曲面/结构；变量=各节点位移/调节量；关系=节点到理想面的贴近度量（径向偏差平方和/面积分）；约束=长度/间距/伸缩范围；目标=min 贴近（/max 增益）。

## 创新点
- 用"径向贴近"这一可积可微度量替代整面解析共形（后者破坏离散约束）；把硬约束不可满足的情形如实说成"放宽/妥协解"，而不是声称满足。

## 主要风险
- 贴近度量与"实际想让其小"的目标可能不一致（如忽略面板刚性/力学）；增益（接收比）提升可能由"人为修正系数/口径不一致/变量被约去"产生而非真实改善——须做归因与敏感性。

## 教训
- 形状优化要讲"目标是什么（贴合/增益/成本）+ 约束是否真满足 + 提升从哪来"；先用简单/对称情形验证指标与方向，再上全量。

## 可迁移到
- 同类题（同法）：光学/天线/结构/曲面调节、形变拟合。
- 同思想异解法：贴近度量换（欧氏/L2/切比雪夫），求解换（LS/拟牛顿/内点/minimax/变步长），增益换（接收/覆盖/均匀度）。
