# 思路：同一几何内核的场景递进 + 特殊情形锚点 + 分治复用

- **category**：ideas
- **entry_id**：2023B_idea_geometry_recurrence

- **year/contest**：2023 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：几何建模、场景递进、锚点、变量替换、分治复用

## 一句话
- 覆盖/布线问题先用特殊情形（如对称方向、退化情形）定锚、得到可解析内核，再按"特殊→一般"用变量替换/类比推广；真实复杂地形按等深线/等高线分块、每子域复用已成立的内核。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=条带/测线/覆盖区；变量=深度 D、覆盖宽 W、重叠率 η、间距 d、方向角 β、条数 n；关系=$W=f(D,	heta,alpha,delta)$（解三角形）、$eta=1-$有效覆盖/条带宽；约束=全覆盖 + 10%~20% 重叠；目标=总长最小。

## 创新点
- 用"特殊情形作校验锚点"（如 β=90° 时 W 恒为常数），再用"变量替换+类比"把新情形映射进既有闭式模型；用"分而治之、复用内核"处理复杂非线性地形，而非一次全局优化。

## 主要风险
- 锚点/对称假设只在特定位形成立；重叠率定义在坡面上有歧义（d 取水平间距还是投影）须一贯；分块拟合会产生误差（漏测率）须量化。

## 教训
- 先建"小/特殊/对称"可解析内核并验证，再推广；不要一上来就全局优化非线性目标。

## 可迁移到
- 同类题（同法）：无人机/建筑扫描、路线覆盖、雷达/声呐探测覆盖。
- 同思想异解法："分治复用内核"可换成"网格分解+局部最优""分层规划+递推"；锚点校验可换成"退化情形/极限/数值对照"。

## 素养对照（可迁移规则）
- **数学素养**：几何（解三角形/向量/线面角）建模、口径一致、特殊化验证。
- **创新素养**：由特殊到一般、分治复用、锚点校验。
