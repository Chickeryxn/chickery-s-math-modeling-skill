# 思路：遇动态先解析化、递推化

- **category**：ideas
- **entry_id**：2024A_idea_analytic_decomposition
- **source**：自写提炼（2024 CUMCM A 题 A016/A053/A163/A242 的共性）。
- **year/contest**：2024 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：几何递推、曲线运动、链式机构、降维

## 一句话
- 当对象是"定长连接的链 + 已知曲线/约束"时，先把动态问题离散成"单点约束 → 迭代"的递推，而不是直接建全系统动力学方程。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=串行定长连接的点（链式机构）；变量=曲线参数(θ)、时间、坐标、速度；关系=①点在已知曲线上（参数化），②相邻点间距离固定（弦约束），③同一杆两端沿杆向速度投影相等；目标/约束=碰撞、边界、速度上限等。

## 创新点
- 用"几何+约束"把连续微分方程降为离散递推：可解析、可复查、物理清楚，节省大量求解成本；不必为高级方法而用高级方法。

## 主要风险
- 多解需按"相邻只转小角/物理序"选支；曲率大时"点严格在曲线上"假设会漂移；链越长递推误差越易累积。

## 教训
- 先在"能否解析化/递推化"上做判断，胜过直接堆高阶方法；能一步步单点推进的问题不必写全系统方程。

## 可迁移到
- 同类题（同法）：机器人操作臂、传送链、车辆编队、受约束刚体链。
- 同思想异解法：把"链式依赖"换成别的实现——如把弦约束换成投影、把弧长反参换成隐式求导或数值求根、按题面换成状态转移/递推/迭代；思想是"离散化递推"，工具可因题而异。

## 素养对照（可迁移规则）
- **数学素养**：先抽象（对象/变量/关系/约束）再选实现；依赖单调性/物理序做唯一解约定。
- **创新素养**：把 ODE 换成递推的视角；"查问题结构 → 选范式"。
