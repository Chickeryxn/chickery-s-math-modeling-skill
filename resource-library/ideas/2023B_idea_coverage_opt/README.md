## 一句话
- 覆盖/布线类多目标（覆盖、漏测、重叠率、总长）主次明显时，用主要目标法：定主目标其余转约束，避开权重随意性；用"沿等深线/最有利方向 + 临界重叠率"做递推/贪心构造，再用启发式（退火/PSO）交叉验证。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=测线/条带/覆盖区；变量=条数、间距、方向、条带位置；关系=逐线覆盖宽度/重叠率递推；约束=全覆盖、10%~20% 重叠（软硬）、几何边界；目标=总长最小（主目标）、漏测为辅。

## 创新点
- 把布设化为"逐线几何宽度 + 相邻重叠约束 + 航向与梯度关系"，"沿等高线（⊥梯度）走最宽"把三维曲面优化降到一维递推；用主要目标法定优先级、避免拍脑袋权重；用临界重叠率（η=10%）递推直接得最短覆盖。

## 主要风险
- 需先证"沿等深线最宽/最稳"再排线（否则重叠失控）；贪心/启发式仅局部/近似最优；重叠率口径（水平/投影）不一致会导致约束失真。

## 教训
- 多目标先定主次（主要目标法），再沿有利方向降维递推；"贪心构造 + 启发式验证"比单靠全局优化更可解释、更易复现。

## 可迁移到
- 同类题（同法）：航线/路线覆盖、巡检、扫描、传感器布点。
- 同思想异解法：主目标换（漏测/总长/重叠），约束换，启发式换（贪心/退火/粒子群/整数规划）。
