## 一句话
- 补货定价决策先"预测未来需求（解耦）"，再把价格弹性嵌入使"定价→销量→收益"耦合，在满足数量/陈列/损耗约束下用混合 0-1+连续（选品+补货量+定价）的启发式求解；多目标（收益 vs 需求满足度）给 Pareto。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=品类/单品；变量=加成率 w、补货量 B、定价 P=(1+w)C、选品 0-1 z；关系=价格弹性（双对数/线性）修正销量 $ln Q=ln Q_{pred}+E_plnrac{P}{P_{pred}}$；约束=Q≤B、27≤Σz≤33、陈列量、损耗上限；目标=max 毛利−损耗（/需求满足度）。

## 创新点
- 用"弹性"把定价反作用销量，形成"定价→销量→收益"闭环；用"预测（RNN/Prophet/ARIMA）提供基线 + 弹性修正"解耦预测与优化；用混合 0-1+连续（选品+补货+定价）与多目标（收益+需求满足度）+Pareto；需求度用 VIKOR 融合销量+销售次数。

## 主要风险
- 价格内生：价格由商超定，OLS 估计弹性未处理联立内生；解耦预测（无价格）再乘弹性是近似；目标-约束要自洽（不得为满足约束用辅助变量放宽到"需求满足度 308%"或"含负利润单品"）；弹性/系数要有来源与敏感性。

## 教训
- 先判变量类型（连续/混合）与目标（单/多）再选算法；预测与优化解耦但要用弹性闭环；成本导向定价只考虑内部，需补需求/竞争导向（Q4 建议采集竞争/消费者预期/收入）。
