# 思路：物理抽象连环简化 + 状态分解（平动/转动）+ 空间旋转（四元数/小角度解耦）

- **category**：ideas
- **entry_id**：2019B_idea_physics_simplify
- **source**：自写提炼（2019 CUMCM B 题 B047/B057/B136 的共性）。
- **year/contest**：2019 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：物理抽象、刚体+质点、简化链、状态分解、四元数、小角度

## 一句话
- 把不可控现实降为可算理想链（刚体+质点、绳手水平、小角度、对称），再逐问放宽；把运动分解为平动/转动，空间旋转用四元数（避欧拉角奇异）或小角度交换性把三自由度降为二自由度。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=鼓（刚体）+球（质点）+多绳力；变量=位移/速度/角位移/法向量/力/时机；关系=牛顿/欧拉旋转 + 碰撞动量/能量守恒 + 几何力矩；约束=颠高、间距、同步同力；目标=最省力且最水平。

## 创新点
- 层级简化链（理想→小角度→碰撞瞬时→三维→误差）分步放宽；状态分解（平动+转动）与离散递推；四元数避开奇异、小角度解耦降维；用"力矩合成+转动定律"把时机→倾角参数化。

## 主要风险
- 小角度/对称只在小量级成立；惯量公式/能量/量级物理正确性；强假设（鼓恰在 v 最大时碰撞、碰撞瞬时）有适用范围；简化错误会整体错位。

## 教训
- 先"理想假设→分解→离散"做出可算链，再用误差量级与合理性论证逐步放宽；并核对物理正确性（惯量、能量、量级）。

## 可迁移到
- 同类题（同法）：机械/多体/碰撞/姿态控制、刚体动力学、多绳/多连杆系统。
- 同思想异解法：旋转换（欧拉角/四元数/方向余弦/旋转矩阵），简化换（小角度/对称/平面），碰撞换（恢复系数/冲量/有限接触）。

## 素养对照（可迁移规则）
- **数学素养**：牛顿/欧拉、碰撞守恒、刚体惯量、旋转表示、状态分解。
- **创新素养**：连环简化、状态分解、小角度解耦、变量参数化。
