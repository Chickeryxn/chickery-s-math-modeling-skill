# 思路：先证不变量/齐次性，再谈优化

- **category**：ideas
- **entry_id**：2024A_idea_invariant_first
- **source**：自写提炼（2024 CUMCM A 题 A242 为主，A163/A016 佐证）。
- **year/contest**：2024 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：优化、不变量、齐次性、降维、搜索

## 一句话
- 面对"最优路径/最优参数/上限速度"，先做几何或物理的"不变量/定值/齐次性"论证；若成立，就把"寻优"降成"一次求解/一次比值"。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=路径/参数/被约束量；变量=可调参数（圆弧半径、螺距、驱动源速度等）；关系=目标量随变量的单调/齐次/不变关系；目标=最小/最大；约束=不碰、不越界、上限。

## 创新点
- 用"不变量/齐次性"做**降维**：路径长度与某参数无关 → 优化变几何求解；速度对驱动源齐次 → 全局搜索变一次比值。先把可证明的性质挖出来，再决定要不要上全局优化。

## 主要风险
- 不变量/齐次性只在特定假设下成立（如"半径比恒定、路径唯一"）；若假设不满足（改多段弧/改相切角度/非齐次），结论失效；"峰值把手恒定"等观察需跨参数再验证，否则以偏概全。

## 教训
- 不先证不变量就盲目上 PSO/遗传是浪费；通用链条"**证明 → 缩小搜索域 → 精确搜索**"（单峰用三分，不可导/多峰才转启发式，并写明为何弃用另一算法）。

## 可迁移到
- 同类题：成本优化、路径规划、上限/极限值类。
- 同思想异解法："先锁定最敏感维/先证定值再外推"可迁移到灵敏度、参数辨识、资源调度（各自用不同的数值手段，思想是"先降维再取值"）。

## 素养对照（可迁移规则）
- **创新素养**：把"优化"转成"求解/比值"的视角；证明→缩小→精搜。
- **数学素养**：对可证明的性质（单调/齐次/不变）先严格化，避免无谓搜索。
