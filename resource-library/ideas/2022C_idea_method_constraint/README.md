# 思路：方法-约束适配（小样本 + 需可解释 + 定类/守恒/小样本关联）

- **category**：ideas
- **entry_id**：2022C_idea_method_constraint
- **source**：自写提炼（2022 CUMCM C 题 C065/C155/C229 的共性）。
- **year/contest**：2022 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：方法适配、可解释、定类检验、守恒外推、灰色关联、样本小

## 一句话
- 按"数据形态 + 样本量 + 是否需可解释 + 是否守恒"适配方法：定类→卡方（含 Yates 校正）、小样本+需可解释→弃黑箱用线性 SVM/决策树、守恒外推→回归+clr 逆变换、小样本关联→灰色关联；而不是堆模型。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=样品/变量；变量=定类属性（类型/纹饰/颜色/风化）、成分、类别；关系=变量关联、成分↔类别映射、风化→成分；约束=定和、守恒、小样本；目标=给出可解释的分类/关联/还原规则。

## 创新点
- 凡"样本小且需可解释"，主动弃神经网络/随机森林/过拟合逻辑回归，选能给出显式边界/规则的模型（线性 SVM、决策树、描述统计）；定类变量用列联表检验（含 Yates 校正）；守恒外推用"回归+可逆变换"保持总量。

## 主要风险
- 小样本易过拟合/退化（决策树指标全=1、正确率 100% 无交叉验证）；"外推"是估计（仅 1 件配对、R² 低却"不变"）；类别非平衡（18 vs 49）、类别编码/口径要一致。

## 教训
- 先问"要回答什么（区分/还原/关联）+ 样本是否够 + 是否要可解释"，再选能给出可解释、稳健结论的方法；别为高级算法而用。

## 可迁移到
- 同类题（同法）：医学/文物/成分/评级分类。
- 同思想异解法：分类用决策树/SVM/逻辑回归/聚类+VIP，关联用卡方/秩相关/灰色关联，守恒用回归+逆变换；核心是"约束+可解释"驱动选型。
