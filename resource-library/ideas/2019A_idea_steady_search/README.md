# 思路：稳态控制 = 周期内偏差平方和 + 差分/遍历/坐标下降降维

- **category**：ideas
- **entry_id**：2019A_idea_steady_search
- **source**：自写提炼（2019 CUMCM A 题 A023/A190/A240 的共性）。
- **year/contest**：2019 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：稳态控制、周期边界、偏差平方和、差分、遍历、坐标下降、降维

## 一句话
- 周期性脉冲输入的稳态控制：先确定输入/输出周期的**最小公共周期**作求解窗口，在窗口上差分离散，把"稳定在期望值"写成**周期内偏差平方和**最小；利用"稳态-决策一一对应+目标下凸"用差分+遍历/坐标下降把多变量优化降成一串单变量扫描。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=周期激励稳态系统；变量=控制参数（开阀时长/角速度/相位）；关系=守恒 ODE+周期边界；约束=初值/阀门逻辑/可行域；目标=min∫(P−P_e)²dt（周期内偏差平方和）。

## 创新点
- 把"稳定"量化为偏差平方和；用周期公共窗口差分；用"稳态-决策一一对应+下凸"做降维扫描；目标非凸/无唯一对应才换全局/随机算法。

## 主要风险
- 周期公倍数近似、目标不唯一对应；遍历+阈值给网格次优而非全局；判稳只用"偏差和→0"且只截末段，缺波动幅值/方差/敏感性。

## 教训
- 周期稳态控制先写守恒+周期边界+偏差平方和，再按"是否一一对应/是否下凸"选"差分+遍历/坐标下降"或"全局/启发式"，并给判稳的幅值/方差/敏感性。

## 可迁移到
- 同类题（同法）：受迫振动/脉动系统稳态控制、参数寻优。
- 同思想异解法：目标换（偏差平方/波动幅值/CVaR），求解换（遍历/坐标下降/黄金分割/启发式/梯度），边界换（周期/稳态/平均）。
