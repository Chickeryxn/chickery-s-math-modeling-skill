# 思路：不确定性——先定风险态度与数据可得性，再选范式

- **category**：ideas
- **entry_id**：2024C_idea_uncertainty_paradigm

- **year/contest**：2024 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：不确定性、风险度量、期望、CVaR、决策准则、鲁棒

## 一句话
- 不确定元素（销量/亩产/成本/价格常带区间）先问"能否严格量化分布？要不要规避尾部？是否有可利用的有利趋势？"，再选**情景抽样+期望**、**CVaR/VaR 风险度量**、**三准则决策**、**鲁棒最坏**之一，别把"期望"当成"风险可控"。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=被不确定参数扰动的问题；变量=决策（种植/购买/分配）；关系=参数按区间/分布演算（$Y'=Y(1pm r)$、$C'=C,1.05^{t-2023}$、麦玉销量 $D(1+alpha)^{t-2023}$）；目标=期望收益、或 $mathbb E-lambda,mathrm{CVaR}$（厌恶尾部）、或 悲观 $max_imin_s a_{is}$/乐观 $max_imax_s a_{is}$/期望 $max_imathbb E_s a_{is}$；约束=各情景下可行/风险上限。

## 创新点
- 先定"风险态度+数据可得性"再选范式，避免"一刀切用期望"或"一刀切用鲁棒"；能利用有利趋势（增长/涨价）用期望，怕极端损失用 CVaR/鲁棒，分布粗无概率用三准则决策。

## 主要风险
- 参数化情景 ≠ 真正随机规划（"采样+候选择优" vs 两阶段最优）；风险权重 λ 需赋值+敏感性；"最坏"因子/系数要有来源或灵敏度曲线；风险度量方向要自洽（如 $eta=Z_{norm}/Z_{risk}$ 与"越大越稳"矛盾应为 $Z_{risk}/Z_{norm}$）。

## 教训
- 不确定性建模的核心是"先定风险态度"，而不是"先选算法"；期望与风险是两回事；参数与情景要有依据并做敏感性。

## 可迁移到
- 同类题（同法）：投资/库存/能源/农作/供应链。
- 同思想异解法：分布可得用随机规划/CVaR；分布粗可用区间情景+鲁棒；无法量化可退化到三准则决策表（益损矩阵）。
