# 思路：多目标订购运输（统一换算 + 库存递推 + 优先级/Pareto + 瓶颈定位）

- **category**：ideas
- **entry_id**：2021C_idea_multiobjective_ordering
- **source**：自写提炼（2021 CUMCM C 题 C066/C085/C169/C283 的共性）。
- **year/contest**：2021 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：多目标、统一换算、库存递推、整数/线性规划、Pareto、瓶颈

## 一句话
- 混合多种物料/汇率/换算率的优化，先统一换算成"可产产品"量纲；用**真实可辨识的跨期库存递推**约束替代拍脑袋硬上限；多目标（成本/损耗/结构/重要性）按优先级分层或做 Pareto；并定位瓶颈（供给端 vs 转运端）。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=供应商/转运商/物料/周；变量=选否 y、订货 x、供货、转运分配、库存 I、产能；关系=供货=订货+偏差、$I_k=I_{k-1}+$供货(1−损耗)−消耗、损耗率、消耗系数；约束=产能/两周库存/单转运 6000/单供应商单转运；目标=最小化(购+运+储)成本、损耗、最大化重要性/产能。

## 创新点
- "统一换算量纲"（0.6/0.66/0.72 折算成产品）使不同物料可比；"库存递推"让相邻周耦合、过量订货自动回落；"多目标"按优先级分层（贪心/主要目标法）或多目标优化（GA/NSGA-II/MOPSO）给 Pareto；"瓶颈定位"（供给端 vs 转运端）决定"能提高多少"。

## 主要风险
- 多目标硬化会主观；统一换算/损耗率口径不一致会失真；随机性（订供偏差/损耗）未建模会高估；"至少/最大"给确定可核而非随机区间；瓶颈端（8 家转运难满载）要说明。

## 教训
- 先把不同物料/汇率/换算统一为可比量纲，再用真实库存递推约束，再按优先级/Pareto 处理多目标，最后定位瓶颈给"可核"结论。

## 可迁移到
- 同类题（同法）：供应链/库存/生产计划、选址-分配、多目标排产。
- 同思想异解法：目标换（成本/损耗/服务/覆盖），求解换（LP/整数/GA/NSGA-II/MOPSO/贪心），随机换（随机规划/鲁棒/情景）。
