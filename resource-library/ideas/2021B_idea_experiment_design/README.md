## 一句话
- 多因素+非单调+需主次排序的问题，拆成"控制变量定性 → 正交/极差降维排序 → 标准化响应面+逐步回归（含交互）→ 盒约束优化"的分层链；补充实验用 均匀设计/补空白/最大化与已有组合最小距离（广度）并给理由。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=多因素实验；变量=因素水平（连续/离散）；关系=带交互的响应面/二次回归；约束=因素区间、实验次数、可售/可检范围；目标=max 业务指标（如收率，=转化率×选择性）。

## 创新点
- 用正交试验降维排主次（不考虑交互先排）；再含交互 响应面 量化；用标准化系数解量纲；目标由业务定义（收率=转化率×选择性）；盒约束优化给"可行域内峰值"。

## 主要风险
- 正交表不重复/错列/K-k 矛盾；目标含交叉项非凸 → 求解器未必全局；定性因素直接回归、优化区间外推；实验设计无统计功效/样本量依据；"5 次实验"理由要可辩护。

## 教训
- 先把因素按"是否连续/是否交互/是否定性"分类，再选正交/响应面/优化；给"实验设计原则"（补空白/验证/均匀/广度）而非只给 5 个点。

## 可迁移到
- 同类题（同法）：工艺/配方/参数优化、DOE、调优。
- 同思想异解法：设计用 正交/均匀/Box-Behnken/响应面法；优化用 fmincon/quadprog/LINGO/NN；影响度用 方差分解/标准化系数。
