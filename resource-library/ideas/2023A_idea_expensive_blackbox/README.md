# 思路：昂贵黑箱目标的"降维 + 单峰利用 + 分层搜索"

- **category**：ideas

- **year/contest**：2023 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：昂贵黑箱、降维、单峰、变步长、分层搜索、MINLP

## 一句话
- 当目标每次评估代价极大（一次全系统仿真）且变量混有离散量时，先固定其余变量、把目标看成少数连续量的单峰/单调函数，用三分查找、粗-精变步长、分层枚举，而不要直接套全局进化算法。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=昂贵黑箱目标（评估=全系统追迹）；变量=连续（规模/高度/位置）+ 离散（数目/层数）；关系=目标对单变量近似单峰/单调；约束=几何/功率可行域；目标=max 单位产出。

## 创新点
- 用"固定其余变量 → 对 1 个变量三分查找"把高维问题降为若干一维单峰问题；用"粗搜定位区间 → 缩步精搜"（步长 1→0.01）控制精度；对近似单峰的塔南移 D、镜宽 W 直接三分。

## 主要风险
- 单峰性须先验证（变量强耦合时单峰切片不再成立）；"固定其余变量"会得到局部最优而非全局；决策变量混离散时分层枚举可能漏解。

## 教训
- 先判"目标是否昂贵/单峰/是否含离散量"，再决定用什么搜索；三分/变步长比进化算法更省评估、更可解释，但需诚实标注"局部最优/未达额定"。

## 可迁移到
- 同类题（同法）：昂贵仿真优化（CFD、物理追迹、调度仿真）。
- 同思想异解法：把"单峰三分"换成"对多个单峰变量分层枚举/二分/黄金分割"，或"先降维再进化"；核心是先让评估次数可控。
