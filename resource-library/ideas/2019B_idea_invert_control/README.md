# 思路：先反演再控制 + 多目标无量纲化→抗多峰启发式

- **category**：ideas
- **entry_id**：2019B_idea_invert_control
- **source**：自写提炼（2019 CUMCM B 题 B047/B057/B136 的共性）。
- **year/contest**：2019 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：反演、控制、最小二乘、多目标、无量纲化、模拟退火、约束降维

## 一句话
- 当只能看到末端结果、缺中间状态/输入时，先建"反演重现"模型（最小二乘）逆推缺失量，再做正向控制——"先反演、再控制"；优化关系无法线性/凸表达时，不硬套 LP，改用抗多峰非凸的模拟退火，并把工程偏好编码成无量纲化因子做单目标加权。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=结果可观测但输入/中间态缺失的系统；变量=输入（力/时机）；关系=正演模型（可反演）；约束=状态/软约束/偏好；目标=多目标（如倾角最小+发力均匀）经无量纲化加权单目标化。

## 创新点
- 反演重现（最小二乘）把缺失量补出；用"全员同步+至多 2 人加额外力"压缩搜索；无量纲化因子承载工程偏好（均匀性/同时性/突变小），用相对误差做软约束。

## 主要风险
- 反演是估计、误差会叠加（无残差/置信）；多目标加权权重主观；启发式无全局保证、单次最优；强假设（同步/对称）限制解空间。

## 教训
- 缺中间态先"反演→正控"；多目标先无量纲化+标量化、用抗多峰启发式，并给多次运行/方差/敏感性。

## 可迁移到

- 同思想异解法：反演换（最小二乘/正则化/贝叶斯），优化换（LP/凸优化/模拟退火/遗传/多目标 Pareto），降维换（同步/对称/先验剪枝）。
