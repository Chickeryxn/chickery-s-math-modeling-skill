## 一句话
- 信贷决策是"在额度/利率/总额/期限/流失率约束下，权衡收益、违约损失、客户流失"的组合优化；外部冲击用"风险乘数/折价/情景"扰动，并关注**组合层面**（相关性/集中度）风险与稳健性。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=企业组合；变量=每户额度/利率（/是否放贷）；关系=违约概率/评级、流失率、损失率；约束=额度区间、总额、期限、流失率上限；目标=max 净收益、min 风险（违约损失/集中度）、min 流失。

## 创新点
- 多目标（收益/风险/流失）用加权单标量或多目标（GA/非线性规划）；外部冲击=乘数/折价（风险乘数 β、信用卡利率基准、行业规模折价），不改结构；组合风险关注相关性/集中度（%）

## 主要风险
- 用"最大单笔风险"或"同等级同违约率"替代会低估组合风险（忽略相关性）；多目标加权/乘数主观无敏感性；结果可能不满足自身约束（各行加总≠总额）；硬截断"违约概率>50% 拒贷"。

## 教训
- 组合优化要"收益-风险-流失"一起权衡并给约束满足与敏感性；外部冲击用乘数/折价+情景并做稳健性；避免"单笔/同质"简化低估组合风险。
