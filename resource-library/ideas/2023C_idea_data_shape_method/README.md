# 思路：数据形态→方法/算法 的链式映射（先清洗、先剥离混淆）

- **category**：ideas
- **entry_id**：2023C_idea_data_shape_method
- **source**：自写提炼（2023 CUMCM C 题 C050/C126/C228/C235 的共性）。
- **year/contest**：2023 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：数据分析、链式映射、先清洗、剥离混淆、统计选型

## 一句话
- 先清洗（剔异常/统一口径/去低效项），再按"数据形态（正态性/长尾/周期/样本量）+ 变量类型（连续/混合）+ 目标个数（单/多）"映射到合适的统计与算法，避免为炫技选复杂度。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=多品类/多单品销售-价格-成本数据；变量=价格、补货量、销量、选品 0-1；关系=分布形态、品类/单品关联、销量-价格-时间关系；约束=数量/陈列/损耗；目标=收益（/需求满足度）。

## 创新点
- 用"形态→工具"映射：非正态/极端值 → Spearman/秩检验/偏相关（剔除总量/混淆）；长尾 → 直方图/累计；类别结构 → K-means++/CURE/关联规则；周期/趋势/节假日 → 时序分解或 RNN/Prophet；小样本 → 灰色关联。
- 先把时间/季节/节假日从销量中**剥离**，再估"价格→销量"的真实偏效应/弹性，避免把季节性误当价格效应。

## 主要风险
- 若数据非正态却用 Pearson（或反向），或未先剥离混淆因素就回归，结论失真；检验方向/置信度设置要自洽；聚类前不标准化会受量纲影响。

## 教训
- 方法选型由"数据形态+问题类型"决定，而不是由"我会哪个"决定；先剥离混淆、再估主效应。

## 可迁移到
- 同类题（同法）：销售/需求/流量/评价类数据洞察。
- 同思想异解法：把"偏相关/时序分解/秩相关"换成更合适的工具（如面板回归、Cox、PCA），思想是"先控制混淆再谈因果/相关"。

## 素养对照（可迁移规则）
- **数学素养**：统计检验/关联/聚类/时序分解选型；数据清洗。
- **创新素养**：形态→工具映射、剥离混淆、非纸面数据洞察。
