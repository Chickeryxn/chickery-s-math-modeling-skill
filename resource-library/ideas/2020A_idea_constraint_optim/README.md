# 思路：把硬约束封装成可行性筛子，再按自由度/形态选求解器 + 多目标标量化

- **category**：ideas
- **entry_id**：2020A_idea_constraint_optim
- **source**：自写提炼（2020 CUMCM A 题 A070/A147/A195/A212 的共性）。
- **year/contest**：2020 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：可行性筛子、约束优化、启发式、多目标标量、灵敏度

## 一句话
- 把全部工艺/硬约束封装成一个布尔 check(参数) 函数当"可行性筛子"，优化器只管在可行域内寻优；再按"维度/目标形态"选求解器（单变量→二分+遍历，多变量非光滑带约束→启发式，多目标→归一化+标量化），并做多次独立运行。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=受工艺/工程约束待优化的系统；变量=参数（温度/速度/系数）；关系=目标由仿真给出且不可导；约束=分段/集合型工艺界限；目标=min/max 某指标（如面积 S、对称度）。

## 创新点
- check(·) 封装：约束变化只改 check、不改主流程；把">217℃时长/150–190℃时长/峰值/斜率"转成集合指标函数；"先粗后细"两阶段搜索；多目标归一化+标量化（分层/加权）。

## 主要风险
- 目标由仿真给出、非光滑，启发式无全局保证；"最优"常贴约束下界（峰值 240 下限/带速上限），鲁棒性弱；加权/归一化参数主观未做敏感性；离散矩形积分引入网格误差。

## 教训
- 先判"确定性/规模/是否光滑/是否含硬约束"，再选可行性筛子+求解器；多目标先归一化再标量化，并做灵敏度与贴界说明。

## 可迁移到
- 同类题（同法）：受工艺/工程约束的参数寻优、黑箱仿真优化。
- 同思想异解法：求解器换（二分/遍历/模拟退火/遗传/爬山/A*），约束换（硬/软/罚），多目标换（Pareto/归一化加权/分层序列）。
