# 思路：物理→方程→数值→优化的流水线 + 方程结构定路线 + 可解析子情形标定

## 一句话
- 物理系统先做受力/动力学分析写成 ODE，再"按方程结构定求解路线"（常系数→解析、非线性→数值），并用一个"可解析的子情形"标定数值工具，最后才外推到不可解析情形。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=多刚体耦合系统（浮子+振子，含转动）；变量=位移/速度/角位移/角速度；关系=Newton+转动定理的二阶（非）线性 ODE（含附加质量/兴波阻尼/静水恢复/弹簧阻尼耦合）；目标=时均输出功率最大；约束=初值零+参数区间+几何安全。

## 创新点
- 用"方程结构定路线"避免盲目：线性常系数用 Laplace/频域闭式，非线性/分段用 RK4/积分；用"可解析子情形标定"验证数值实现（解析 vs 数值差 0.07%→认可再外推）。
- 把"优化"落到"ODE 约束 + 数值积分目标 + 稳态平均"的嵌套问题。

## 主要风险
- 求解路线选错（把非线性强行解析、或把可解析情形上数值）会增误差/成本；标定仅覆盖某个子情形，外推未必可靠；小量/解耦近似要在假设阈值内（否则失效）。

## 教训
- 面向"参数只出现在时均目标/积分、不在 ODE 内"的问题，宜"前向求 ODE + 外接黑箱优化"；先用可解析子情形给数值工具定标，再外推。

## 可迁移到
- 同类题（同法）：机械/电/流体动力学、受迫振动、能量采集。
- 同思想异解法：解析/数值工具（Laplace/频域/RK4/ode45）按方程结构换；类比可得力-电、热-电、流体-电路等对偶。
