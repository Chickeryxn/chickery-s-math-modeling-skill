# 思路：评价定权（数据驱动客观 + 人因校准）与"评价→规划"两阶段

## 一句话
- 多指标"重要性/优劣"评价，先做正负向性与量纲处理，用数据驱动方法（熵权/投影寻踪/TOPSIS）客观定权（并可叠加 AHP 在合理范围做人因校准）；再把"稳健评价"与"后续规划"串成两阶段，避免在指数级组合上直接优化。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=候选（供应商/方案）；变量=各指标值；关系=加权综合/贴近度/投影；约束=指标方向/量纲；目标=得到可排序、可解释的重要性分。

## 创新点
- 用 熵权（信息量）/投影寻踪（局部密集+整体散开）/TOPSIS（贴近度）避免主观 AHP 武断；再用领域判断（AHP/经验）在合理范围校准，并把人为权重写成可复现假设。
- 先"评价收敛"再"小集合规划"，压缩组合爆炸。

## 主要风险
- 指标相关性/冗余需先处理（投影/主成分/PCA 去共线）；熵权对 0/极端值敏感；AHP 主观；剔除/异常无敏感性；评价口径与后续规划口径要一致。

## 教训
- 先处理指标方向与量纲、去冗余，再用"客观定权+校准"，别直接 AHP 打分或堆模型。

## 可迁移到
- 同类题（同法）：供应商/方案/企业/股票评价、绩效排名。
- 同思想异解法：客观定权用 熵权/投影寻踪/主成分/CV；评价用 TOPSIS/优劣解/灰色关联；校准用 AHP/专家；后接规划用整数/多目标。

## 素养对照（可迁移规则）
- **数学素养**：多指标归一/去冗余、客观定权、贴近度/投影。
- **创新素养**：评价-规划串接、客观+人因校准。
