## 一句话
- 对象性能由多个乘性损耗构成时，先拆分"可解析便宜的损耗"与"昂贵非线性需仿真的损耗"，把优化留给便宜子块、MC 只作抽头估计，并用物理对称性压缩高维决策空间。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=多损耗系统（光-镜-接收、多部件串联）；变量=配置参数（布局/尺寸/高/位置）；关系=总效应=各损耗乘（$eta=prod_k eta_k$）；约束=几何/工程可行域；目标=最大化单位资源产出（如单位面积功率）。

## 创新点
- 把总效应拆成"解析核心（余弦/大气/反射）+ 昂贵非线性（遮挡/截断 MC）"；优化只在便宜子块上做，MC 仅抽头估计；用对称性（同心圆/各向同性/关于轴对称）把指数级决策空间降为几圈/几个参数。

## 主要风险
- 效率平均口径：$prod E[eta_k]$ 与 $E[prod_k eta_k]$ 不相等，须明确；对称性假设（各向同性/同圈同尺寸）会牺牲自由度；"便宜子块优化到最优"不等于整体最优。

## 教训
- 复杂系统先找"主损耗/最大杠杆"（本题=余弦效率），把优化目标对准它；不要在昂贵子块上做全局搜索。

## 可迁移到
- 同类题（同法）：光-镜-接收、换热/传热链、供应链多环节损耗。
- 同思想异解法：把"乘性耦合"换成"加成综合/加权、多部件可靠性串联"，本质上都是"拆分-分工-合成"；降维方法可换对称性/启发式/枚举。

## 素养对照（可迁移规则）
- **数学素养**：多损耗乘性耦合口径；解析-仿真子块划分。
- **创新素养**：主杠杆定位、对称性约简、分治。
