# 思路：候选模型同场实测权衡 + 多因变量诊断 + 标准化系数做影响度

- **category**：ideas

- **year/contest**：2021 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：模型权衡、防过拟合、多因变量、PLS、标准化、影响度

## 一句话
- 先在多个候选模型上用同一可度指标（R²/残差 MSE）实测权衡再定型，而非先验偏好；多因变量用 PLS 诊断是否真相关，差异小则退回更简单可解释的模型；用**标准化回归系数**（而非普通系数）比较影响大小。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=输入（因素）与输出（指标）；变量=水平/区间；关系=候选模型族（线性/二次/S 型/Logistic/响应面/神经网络）；约束=因素区间/样本量；目标=找到可解释、不过拟合、误差小的关系模型。

## 创新点
- 用"同场比指标 + 参数数与样本量关系"防过拟合（n 点对 n 参必 R²=1）；用 PLS 诊断多因变量真相关；用标准化系数做跨因素影响度比较；把"拟合优度提升"与"是否过度参数化"并列作为取舍判据。

## 主要风险
- 权衡指标单一（只看 R² 会过拟合）；样本小、参数多；"稳定/最优/显著"措辞夸大；定性变量当数值、优化区间外推。

## 教训
- 先建立"候选模型→同场指标→防过拟合判据"的标准，再定模型；模型只拟合而无约束/外推时，改选能直接学非线性映射的模型。

## 可迁移到
- 同类题（同法）：任何"拟合/响应面/关系建模"题（化学、生物、工程）。
- 同思想异解法：模型族换（多项式/指数/Logistic/神经网络/高斯过程）；诊断换（PCA 共线/方差膨胀/交叉验证）；影响度换（标准化系数/敏感性/方差分解）。
