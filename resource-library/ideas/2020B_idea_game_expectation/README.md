# 思路：多人/随机场景——博弈 + 期望 + 兜底（无占优/不可概率化则退期望）

- **category**：ideas
- **entry_id**：2020B_idea_game_expectation
- **source**：自写提炼（2020 CUMCM B 题 B078/B108/B125/B175 的共性）。
- **year/contest**：2020 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：博弈、纳什、期望、风险、兜底、多主体

## 一句话
- 多主体/随机场景：可建模为博弈（纯/混合/占优、纳什）则用；否则（无占优/资源不可比/依赖不可测）退化为"期望最大化"并**保留兜底分支**；用"期望收益+失败率"双指标评价，并把"幸存者偏差/主观假设"显式标注。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=多决策主体/随机环境；变量=各自策略/决策概率；关系=收益矩阵/转移概率/支付；约束=资源/信息/行为约束；目标=期望收益最大（/均衡）。

## 创新点
- 用"状态→势/概率"把收益转成倾向（注意非负/归一化）；用博弈纳什（含按阶段分解：单日纳什再拼接）处理交互；用"期望+失败率"双指标评价随机方案；对无法概率化/无占优的情况给"退化求期望"兜底。

## 主要风险
- 博弈需信息结构与均衡存在性；"势函数当概率"缺非负/归一化；占优/系数主观（不稳健）；随机模拟单次/无种子；循环论证（用虚构天气/假设再验证）。

## 教训
- 先判"是博弈/是随机/还是确定"再选期望/博弈/DP；多主体先看是否存在占优/均衡，不存在则退期望并说明；随机性用双指标+多实现，避免自证。

## 可迁移到
- 同类题（同法）：竞争/合作/冲突决策、随机环境决策、拍卖/博弈、市场/交通。
- 同思想异解法：博弈换（纯/混合/占优/纳什），期望换（期望/风险/鲁棒），评价换（期望+方差/失败率/Pareto），兜底换（鲁棒→期望→保守）。

## 素养对照（可迁移规则）
