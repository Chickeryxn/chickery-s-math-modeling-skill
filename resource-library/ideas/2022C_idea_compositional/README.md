# 思路：成分/占比数据先识别约束，用对数比变换到欧氏空间再分析

- **category**：ideas
- **entry_id**：2022C_idea_compositional
- **source**：自写提炼（2022 CUMCM C 题 C065/C155/C229 的共性）。
- **year/contest**：2022 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：成分数据、定和、闭合、clr/ilr、几何均值、缺失即信息

## 一句话
- 若变量是"占比/百分比、和为常数、只含相对信息"，先识别其为**成分数据（单形）**，用**对数比变换（clr/ilr）**把它等距映射到欧氏空间，再做相关/聚类/分类/回归；并承认"缺失（未检出）即信息、须与风化等效应分离"。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=样品（成分占比向量 x，Σx=c）；变量=各成分对数比；关系=成分间只含相对（比率）信息；约束=定和、非负、缺失/未检出、有效度 85~105%；目标=在保持"相对含量"信息的前提下做关联/分类/还原。

## 创新点
- 用 Aitchison 几何均值（扰动、闭合 C(x)）与 clr/ilr 把"比率信息"对齐到欧氏度量，避免欧氏均值跳出单形、避免定和导致的伪相关；用 clr 逆变换在外推时保守恒。

## 主要风险
- clr 在 0 处无定义（须用检出下限/替换，且与"未检出≠0"区分）；clr 冗余（和为 0）需注意自由度；对补值、量纲预处理、量纲不一致的敏感性要检验。

## 教训
- 建模前先问"数据是否有强结构约束（定和/只含相对/缺失即信息）"，若有，先做可逆坐标变换（clr/ilr）再谈聚类/回归/相关，切忌对原始占比直接算欧氏距离/皮尔逊相关。

## 可迁移到
- 同类题（同法）：成份/比例/份额数据（地质、化学、市场构成、金融资产权重）。
- 同思想异解法：clr/ilr/ALR 换；"闭合-扰动-几何均值"可迁移到任何"和为常数、只含相对信息"的比例向量；退化问题用零替换/乘性替换。
