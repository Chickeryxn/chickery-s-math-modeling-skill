# 思路：把生产流程写成期望值决策，再按规模选范式

- **category**：ideas
- **entry_id**：2024B_idea_expected_flow_decision
- **source**：自写提炼（2024 CUMCM B 题 B159/B195/B196 的共性）。
- **year/contest**：2024 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：期望值决策、0/1 决策向量、动态规划、启发式、质量流、规模定范式

## 一句话
- 把生产流程（检测/装配/拆解/调换/回流）抽象成"决策向量（0/1：是否检测/拆解）+ 期望价值函数（收益−各类成本）"，然后**按规模与可解析性选范式**（枚举 → 递推/DP → 启发式）。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=零配件/半成品/成品及其质量流；变量=0/1 检验/拆解决策向量、购买量、次品率；关系=①检测/筛选后**成分更新** P*=P(1−x)/(1−xP)，②层层**合格率连乘合成**成品次品率 1−∏(1−P*ᵢ)(1−P_工序)，③成本随决策条件耦合；目标=max 期望利润=收益−各类成本；约束=决策∈{0,1}、数量按瓶颈 min、循环回收收敛。

## 创新点
- **先抽象"成分更新+合格率合成"再算期望**，让成本随决策正确耦合；用**状态-决策+动态规划/记忆化**处理多工序；循环回收用**盈利饱和判据**避免死循环。
- 识别"若已全检则回收件可免检"这类**利用先验压缩二次检测**的结构。

## 主要风险
- 成本项未按"是否检测/拆解"耦合会失真（检成品会拦截次品→调换成本应减小）；"单位/批次"口径要统一；期望法忽略方差（可配蒙特卡洛/敏度）；多目标若只优化单维、其余仅供记录，需明说。

## 教训
- 先判断"可不可闭式/规模多大/要不要全局最优"，再决定枚举 / 枚举验算 / DP / 退火 / ACO/GA；为"多算法结合"而加复杂度是常见误区。

## 可迁移到
- 同类题（同法）：供应链/库存/质检/回收、产线投资、风险决策。
- 同思想异解法：按"是否可闭式/规模/是否要全局最优"换枚举、蒙特卡洛、解析递推、退火、ACO/GA；"成分更新+合格率合成"可外推到任何带筛选/回流的质量流。

## 素养对照（可迁移规则）
- **数学素养**：先抽象质量流（成分更新/合成），再写期望值函数；DP 处理多阶段。
- **创新素养**：规模触发范式升级；循环给收敛判据。
