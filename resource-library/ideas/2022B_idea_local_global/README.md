# 思路：分布式/信息受限的"预处理降阶 → 局部算法 → 独立全局检验"

- **category**：ideas
- **entry_id**：2022B_idea_local_global
- **source**：自写提炼（2022 CUMCM B 题 B030/B035/B086 的共性）。
- **year/contest**：2022 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：分布式、协同、局部模型、全局检验、预处理降阶、调整方案

## 一句话
- 信息受限（各单元只收到部分/方向信息、且相互不共享）时，先做**预处理降阶**（如沿径向修正把误差降为高阶小量），再用**局部目标**逼近，最后用一份**独立的只读全局度量**判断是否达到整体优。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=各单元的局部可观测/可调量；变量=局部位置/方向偏差；关系=局部目标 $f_i=|alpha-alpha^*|^2$；约束=信息不共享、仅方向/局部；目标=把局部最优推向整体（用全局 $E=sum f_i$ 只读检验）。

## 创新点
- "预处理降阶"（径向）把一阶误差变二阶，缩小搜索；"局部算法"（2 或 3 个参照、邻域搜索）避免违背"不共享"；"独立只读全局检验"在事后判是否合格，不进入调整方程。
- 用几何引理/对称性把整体排布分解成可贪心/逐步落位的子结构。

## 主要风险
- 局部最优≠全局最优（需检验确认）；决策次数/搜索范围与收敛需平衡；"只读全局检验"要独立、不参与调整；多解/对称需特判。

## 教训
- 协同/分布式问题勿强行全局联合优化（违背信息约束），用"降阶预处理 → 局部逼近 → 独立全局检验"，并以少量"参照单元"固定参考系。

## 可迁移到
- 同类题（同法）：分布式定位/排布、一致性控制、多智能体协同。
- 同思想异解法：局部目标换（范数/角度/能量），全局检验换（误差平方和/覆盖率/平面化函数）；预处理换（径向/刚性对齐）。

## 素养对照（可迁移规则）
- **数学素养**：局部-全局分层、降阶与收敛、误差估计。
- **创新素养**：分布式局部模型、参照系固定、只读全局检验。
