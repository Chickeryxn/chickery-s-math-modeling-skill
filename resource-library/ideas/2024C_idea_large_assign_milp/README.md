# 思路：大规模指派——把业务规则翻译成 0-1+线性+分段

- **category**：ideas
- **entry_id**：2024C_idea_large_assign_milp
- **source**：自写提炼（2024 CUMCM C 题 C038/C063/C094/C234 的共性）。
- **year/contest**：2024 / 高教社杯全国大学生数学建模竞赛（CUMCM）
- **tags**：大规模指派、0-1 开关、大 M、分段线性化、集合分块约束、MILP/MINLP

## 一句话
- 遇到"资源×类别×时点"分配（地块×作物×季×年），先列索引与决策张量（连续量+0-1 开关+大 M 衔接），再把每条"不能/至少/不宜/不超过/不连续"翻译成 0-1+线性+分段，最后按规模与精度选精确求解器或启发式。

## 数学本质
- **对象→变量→关系→约束/目标**：对象=资源单元×类别×时点；变量=连续量（面积）$x$ 与 0-1 开关 $y$（是否做）；关系=$sum_k x_{t j k}le S_j$（面积上限）、$xle M y$（大 M 衔接）、$xgearepsilon y$（最小量）、$sum_j yle q$（横向分散）、$sum_k yle p$（纵向多样）、不重茬 $y_{t,j,k}+y_{t+1,j,k}le1$、三年豆类 $sum_{t=t_0}^{t_0+2}sum_k I_k xge S_j$；目标=$maxsum[min(	ext{产量},q)p+alpha(	ext{产量}-q)_+ p - c x]$（分段线性化）。

## 创新点
- 把业务"规则"统一收进"0-1+线性+分段"的**建模语言**；用**集合分块**（地块-作物适配）把杂散的约束结构化；用**大 M/小下界**接通"是否做"与"做多少"；用**辅助变量**线性化 `min/max/(·)₊` 分段收益。

## 主要风险
- 分散度易写成"面积和≤5"（应为**地块数≤5**，量纲错）；大 M 取值影响数值稳定性；"最小面积占比"从观测强行推广会压缩可行域；启发式无全局最优/收敛保证，须说清；模型类型命名要准确（MILP/MINLP，不是 LP）。

## 教训
- 先列索引与变量类型，再逐条把约束翻译成可运算形式，比"堆约束文字"更可解、可查；求解器与启发式按"规模+是否要全局最优"选，并做**主方法 vs 基线**互证。

## 可迁移到
- 同类题（同法）：排产、选址、运输、资源分配、投资组合。
- 同思想异解法：0-1 开关+分段线性化可迁移到任何"是否做+做多少+封顶/至少/不能连续"的指派题；求解器可换 CBC/CPLEX/Gurobi/LINGO，或改启发式（DE/GA/退火/PSO）。

## 素养对照（可迁移规则）
- **数学素养**：先抽象（索引/变量/约束/目标）再选实现；分段线性化、大 M、量纲一致。
- **创新素养**：把"规则言"翻译成"可解建模语言"；精确与启发式的取舍视角。
