# formulas/ —— 优秀公式

放**优秀公式片段**（LaTeX）+ 说明，训练对照"数学素养"。每条目一个文件；若含数值验证，用条目目录：

- **条目目录**（推荐）：`formulas/<entry_id>/{README.md, content/(公式 .tex), code/(数值验证脚本可选)}`
- **扁平条目**（兼容）：`formulas/<name>.md`（内嵌公式）

`content/`、`code/` 为支持目录，由 `scripts/resource_index.py` 归入 `supporting`。
