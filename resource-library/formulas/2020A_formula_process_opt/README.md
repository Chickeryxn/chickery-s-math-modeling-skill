# 公式：炉温曲线约束优化（面积 / 对称度 / 制程界限）

- **category**：formulas
- **entry_id**：2020A_formula_process_opt
- **source**：自写提炼（2020 CUMCM A 题 A070/A147/A195/A212 的共性）。
- **tags**：面积、对称度、制程界限、约束优化、多目标标量

## 公式
1) 制程界限：升/降温斜率 $|dT/dt|\le3$℃/s；$150\le T\le190$℃ 时长 $\in[60,120]$s；$T>217$℃ 时长 $\in[40,90]$s；峰值 $240\le T_{max}\le250$℃；带速 $v\in[65,100]$cm/min、温区偏差 $\pm10$℃。
2) 面积（>217℃ 阴影）：$S=\int_{t_s}^{t_p}\big(T(t)-217\big)\,dt$（用梯形/解析，避免矩形网格误差）。
3) 对称度：$E=\sqrt{\frac1N\sum_i\big|T(2t_p-(t_s+i\Delta t))-T(t_s+i\Delta t)\big|^2}$。
4) 目标/多目标：Q2 $\max v$；Q3 $\min S$（变量 $T_1..T_4,v$）；Q4 $\min\{S,E\}$ 归一化+加权 $u=w_s\hat S+w_e\hat E$（或分层序列），s.t. 制程界限 + 模型。
（符号：$T(t)$=板温曲线，$t_p$=峰值时刻，$t_s$=$T$ 首次到 217℃ 时刻，$S$=面积，$E$=对称度，$v$=带速，$T_i$=温区温度。）

## 符号与前提
- **符号**：见上式；时间 s、温度 ℃、面积 ℃·s、带速 cm/min。
- **适用前提**：目标由仿真（模型）给出、不可显式；需在制程界限约束下寻优；多目标需归一化+标量化。

## 推导链
1. 把工艺约束写成集合指标与不等式。
2. 定义面积/对称度目标。
3. 用可行性筛子 check(·) + 求解器（单变量二分/遍历、多变量模拟退火/遗传、多目标归一化加权）寻优。
4. 多次独立运行并说明收敛/贴界。

## 数值算例
- 2020A：Q2 $v_{max}\approx76\sim80$cm/min；Q3 $S\approx403\sim484$℃·s（口径不同）、$v\approx86\sim97$；Q4 $S\approx449$、$E\approx9.99$℃。示例仅示意，口径不一。

## 陷阱
- 面积用离散矩形 vs 梯形引入网格误差；"最优"常贴峰值 240 下限/带速上限（鲁棒弱）；归一化/加权系数主观未做敏感性；"150≤T≤190""T>217"等把温度/时间表述要一致；℃ vs K。

## 可迁移
- 同类题：工艺/质量控制、曲线/轨迹约束优化、多目标权衡。
