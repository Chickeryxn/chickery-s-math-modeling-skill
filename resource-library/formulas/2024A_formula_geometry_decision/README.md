# 公式：几何判据与消参（碰撞 → 阶跃；相切 → 消参/不变量）

## 公式
1) 碰撞近似（点到直线距离）：
$$d=rac{ig|(y_{j+1}-y_j)x_{A_i}-(x_{j+1}-x_j)y_{A_i}+x_{j+1}y_j-x_jy_{j+1}ig|}{sqrt{(x_{j+1}-x_j)^2+(y_{j+1}-y_j)^2}}le d_2$$
2) 碰撞严谨（分离轴定理 SAT）：把两凸多边形投影到各轴，若在任一轴上投影区间不重叠则分离；重叠判据
$$Q_{max}ge R_{min} wedge R_{max}ge Q_{min} Leftrightarrow 	ext{相交}$$
3) 阶跃化：$P(t)=1$（未碰）/ $0$（碰）；$min{Q_{max}-R_{min},,R_{max}-Q_{min}}=0$ 时 $P$ 由 1 跳 0。
4) 相切消参：两圆相切 ⇒ 圆心距=半径和/差；半径比 $2:1$ 的 S 形双圆弧 ⇒ 圆心距=$1.5R_大$，消去偏移角，路径化为单变量。
5) 不变量：$S=dfrac{Dalpha}{2cosalpha}$（与两弧半径比无关 → 优化变求解）；盘出路径中心对称，$	heta	o	heta+pi$。
（符号：$d_2$=半板宽/安全阈值=$0.15$ m；$Q,R$=投影值；$P(t)$=碰撞阶跃；$R$=圆弧半径；$D$=调头圆直径；$alpha$=切线夹角。）

## 符号与前提
- **符号**：见上式说明；单位：长度 m、角度 rad。
- **适用前提**：把"是否重叠/越界/相切"规范化为几何不等式；对象为凸多边形或可近似为带状/点-线时用近似式，需严谨矩形重叠时用 SAT。

## 推导链
1. 物理判定 → 几何关系（距离/投影/相位）。
2. 写成不等式或阶跃函数。
3. 使"恰好不碰/相切/临界"变成可二分/遍历/单变量搜索的边界。

## 数值算例
- 2024A Q2：阈值 $d_2=0.15$ m，得盘入终止 $tapprox412.47$ s；Q4：$R_1=2R_2$、$R_1+R_2=4.5$ m → $R_1=3$ m、$R_2=1.5$ m，路径长与半径比无关。仅作示例，非唯一答案。

## 陷阱
- 近似判据偏保守/乐观取决于位形；只查代表点/忽略板宽与端部会漏检；SAT 更严谨但成本高；圆心角与单位须自洽；中心对称易把 $	heta	o	heta+pi$ 弄反。

## 可迁移
- 同类题：重叠/越界/相切类几何判定、轨道衔接、最短路径。
- 同思想异解法："把布尔判定写成分段阶跃/边界函数"可迁移到调度约束、可行性判断、临界参数搜索；碰撞严格与否按题换 SAT/距离/布尔几何。
