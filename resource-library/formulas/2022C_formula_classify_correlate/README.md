# 公式：判别/分类（规则/边界/打分）与关联（检验/关联度）

- **category**：formulas
- **entry_id**：2022C_formula_classify_correlate
- **source**：自写提炼（2022 CUMCM C 题 C065/C155/C229 的共性）。
- **tags**：判别、决策树、线性 SVM、VIP、卡方、灰色关联、相关性

## 公式
1) 关联检验（定类）：Pearson 卡方 $x^2=\sum\frac{(O-E)^2}{E}$（小样本用 Yates 校正/Fisher）；秩相关 $\rho=1-\frac{6\sum d_i^2}{N(N^2-1)}$。
2) 判别（线性 SVM/二分类边界）：$w\cdot clr(x)+b \gtrless 0$；或决策树（信息增益）$G(D,A)=H(D)-H(D|A)$；PLS-DA 打分/VIP。
3) 灰色关联系数：$\xi_i(k)=\frac{a+\rho b}{|x_0(k)-x_i(k)|+\rho b}$，$a=\min\min|x_0-x_s|$、$b=\max\max|x_0-x_s|$、$\rho=0.5$。
4) 相关性（对数比值协方差/SVD-PCA）：对 clr 协方差阵做 SVD，读双标图。
（符号：$O,E$=观测/期望频数；$d_i$=秩差；$w,b$=超平面参数；$x_0$=母序列；$\xi$=关联度；$clr$=中心对数比。）

## 符号与前提
- **符号**：见上式；相关性无量纲、检验 p 值、关联度 0~1。
- **适用前提**：在成分数据（clr 后）上做分类/关联；定类变量用列联表检验；小样本+需可解释用判别边界/规则；样本小关联用秩相关/灰色关联。

## 推导链
1. 定类→列联表检验（卡方/Yates/Fisher）。
2. 判别→线性 SVM/决策树/PLS-DA（在 clr 空间），给显式边界/规则与重要性（VIP）。
3. 关联→秩相关/灰色关联/协方差 SVD-PCA，比较不同类别的关联结构差异。

## 数值算例
- 2022C：判别特征以 PbO 为主（阈值约 6~8.5），高钾/铅钡判别边界清晰；类型-风化卡方 p≈0.02 显著、纹饰/颜色不显著；两类灰色关联结构不同。示例仅示意。

## 陷阱
- 类别非平衡（18 vs 49）会影响判别；决策树/阈值可能过拟合（正确率 100% 需交叉验证）；Pearson/Spearman 口径前后一致；clr 空间与原始占比口径不同（展示注明）；关联度/相关不独立（成对比较需稳健）。
