# 公式：出租车单位时间净收益决策（机会成本 + 生灭/等待 + 平衡分界）

- **category**：formulas
- **entry_id**：2019C_formula_taxi_decision
- **source**：自写提炼（2019 CUMCM C 题 C044/C137/C308 的共性）。
- **tags**：机会成本、单位时间净收益、生灭、等待时间、平衡分界

## 公式
1) 决策（二选一）：$Z=Q\,P_1+(1-Q)\,P_2$，$Q\in\{0,1\}$（排队/空返）；$P_1=W_1-V_1-\pi_1\,T_w$（等待收入−成本−时间成本），$P_2$=空返收益。
2) 量纲归一：单位时间净收益 $\bar P=\dfrac{\text{净收益}}{\text{耗时}}$（比较不同时长方案时先归一化再判号）。
3) 排队等待（生灭过程/M/M/1）：$T_w\approx\dfrac{\rho}{\mu-\lambda}$（$\lambda$=到达率、$\mu$=服务率、$\rho=\lambda/\mu$）。
4) 平衡分界：$N_b(t)=\int_t^{t+t_w}\rho_r(t)\,dt$（需求/车量相等定分界时段）；$\mathrm{sgn}(\Delta E_A-\Delta E_B)$ 判号。
（符号：$P_i$=方案 i 净收益，$W_1$=等待载客收入，$V_1$=成本，$\pi_1$=单位时间机会成本，$T_w$=等待时间，$\lambda,\mu,\rho$=排队参数，$\rho_r$=需求率，$N_b$=平衡队列，$Q$=0-1 决策。）

## 符号与前提
- **符号**：见上式；收益元、时间 h/min、率 辆或人/h。
- **适用前提**：比较"排队 vs 空返"（/等待 vs 行动）；先统一折算机会成本；队列可用排队论/生灭/模拟给等待时间。

## 推导链
1. 算两方案净收益（含时间/机会成本）。
2. 拉平到单位时间净收益（量纲归一）。
3. 用排队论/模拟给等待时间；用"收益相等"定分界/时段。
4. 用 sgn 判号给策略；给敏感性/鲁棒（参数、噪声）。

## 数值算例
- 2019C：高峰（如 3:30-9:30）等待、10:00-15:00 空返；某时刻分界（如 12:24-15:00 空返、其余排队），等待时段收益约 26.5 元（示例）。仅示意，口径不一。

## 陷阱
- 机会成本/小时收益参数主观（无来源）；"收益最大化"实为损失最小化（方案二恒负）；忽略偏好/风险/经验/季节；队列有上限/拒绝/分批放行（排队论近似）；口径（65.23 vs 46.29 vs 65）致不可复现。
