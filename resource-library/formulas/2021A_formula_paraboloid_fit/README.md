# 公式：抛物面几何 / 理想面 / 径向贴近 / 接收比

- **category**：formulas
- **entry_id**：2021A_formula_paraboloid_fit
- **source**：自写提炼（2021 CUMCM A 题 A028/A115/A217 的共性）。
- **tags**：抛物面、理想面、径向贴近、RMS、接收比、球面镜

## 公式
1) 旋转抛物面：$z=\frac{x^2+y^2}{4f}-p$（焦点 $P$，焦距 $f$；球面径向距离 $\rho(\theta;f)=\frac{2f\cos\theta+2\sqrt{f^2\cos^2\theta-f(p-f)\sin^2\theta}}{\sin^2\theta}$，$\rho(0)=p-f$）。
2) 理想面贴近度量：$E(f)=\int_{\theta\le\theta_{max}}[\rho(\theta;f)-R]^2\,dS$（/离散 $E=\sum_i|C X_i^{理想}-C X_i^{实际}|^2$）。
3) RMS：$\mathrm{RMS}=\sqrt{\frac1n\sum_i|C X_i^{理想}-C X_i^{实际}|^2}$。
4) 球面镜反射/接收比：$x_E=(\tfrac{R}{2\cos\theta}-(1-0.466)R)\tan 2\theta$，$|x_E|<0.5$ 判落入有效圆盘；$\eta=\dfrac{\text{有效区域接收}}{\text{反射面反射}}$。
（符号：$f$=焦距；$p$=顶点深度；$R$=基准球面半径；$\theta$=极角；$C$=球心；$X_i$=节点坐标；$\eta$=接收比。）

## 符号与前提
- **符号**：见上式；长度 m、角度 rad/°。
- **适用前提**：几何光学/直线传播、面板视为无孔、主索节点坐标作为面板顶点；轴对称或经坐标旋转规范化。

## 推导链
1. 由"以 SC 为轴、P 为焦点"定理想旋转抛物面。
2. 用径向贴近/RMS 度量"实际反射面"与理想面的偏差。
3. 在约束（索长定长、距变、伸缩范围）下优化贴近度量（或对焦距做一维最小化）。
4. 逐面板求反射线与焦面交点、判是否落入有效圆盘，得接收比。

## 数值算例
- 2021A：焦距 f≈280.85m（Q1 正上方）、接收比 调节前 0.81%→调节后 1.10%（+36%）。示例仅示意，非唯一答案。

## 陷阱
- 口径：R 取 300 还是 300.4、工作态口径/焦径比 0.466R、α/β（方位/仰角）与 θ/φ 混用；顶点坐标的方向/符号（应朝向天体一侧）；接收比提升可能由"人为修正系数/口径不一致/变量被约去"产生——须归因；未纳入 0.07% 与索长约束时是妥协解。
