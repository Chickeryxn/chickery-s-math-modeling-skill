## 符号与前提
- **符号**：见上式；单位：收益/损失元。
- **适用前提**：把不确定元素参数化；需要描述期望/尾部/最坏之一的风险态度；关系（替代/互补/相关）可转成系数或回归。

## 推导链
1. 参数化不确定元素（区间/分布/趋势）。
2. 选风险度量（期望/CVaR/三准则/鲁棒）。
3. 关系（替代/互补/相关）转成系数或回归，代入模型。
4. 用蒙特卡洛/采样/求解器求解，并做敏感性（波动幅度、风险权重、模型参数）。

## 数值算例
- 2024C：Q2（期望/CVaR）与 Q3（加相关性）对比，后者略高；敏感性发现"销量影响最大、食用菌价影响最小、其他作物介中"。示例仅示范用法，不作唯一答案。

## 陷阱
- 期望≠风险；CVaR 用"跨情景最差 5%"而非个体内子项排序；λ、相关系数、系数（1.01/0.99/α）须有来源与敏感性；区间/情景参数化要与题面波动范围一一对应；MC 用"采样+候选择优"要说明非两阶段最优；相关传导方向要自洽（销量↑→价↑、销量↑→成本↓ 可能推出 价与成本负相关，需一致）。
