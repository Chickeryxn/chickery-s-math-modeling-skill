# 公式：球-鼓碰撞与鼓刚体运动（平动 + 转动 + 倾角）

- **category**：formulas
- **entry_id**：2019B_formula_drum_dynamics
- **source**：自写提炼（2019 CUMCM B 题 B047/B057/B136 的共性）。
- **tags**：碰撞、动量/能量、恢复系数、刚体转动、倾角、四元数、小角度

## 公式
1) 碰撞（球-鼓）：动量守恒 + 能量守恒（含恢复系数 e）：
$$\frac12 m v_1^2=\frac12 m v_2^2+\frac12 M V^2+\dots,\quad e=\frac{v_2^+ - v_2^-}{v_1}$$（e 关联相对速度；颠高 $h_2$ 由能量/碰撞决定）。
2) 鼓位移（水平拉绳）：$$\ddot x+\frac{pF}{ML}x=\frac{pF H_0}{ML}-g$$，解得 $x(t)=\big(H_0-\frac{gML}{pF}\big)\big(1-\cos\sqrt{\frac{pF}{ML}}t\big)$。
3) 转动（小角度解耦）：力矩 $M_i=-OQ_i\times OP_i$，$\alpha=\frac{\sum_i M_i+M'}{J}$（$J=\frac{1}{12}M h_0^2+\frac12 M R^2$，空心应 $\frac{1}{12}M(3R^2+H^2)$），$\Delta\omega=\frac12\alpha\Delta t^2$；倾角 $\gamma\approx\arcsin\sqrt{\sin^2\alpha+\sin^2\beta}$。
4) 四元数旋转：$n'=H n H^{-1}$。
（符号：$m,M$=球/鼓质量，$v_1,v_2,V$=速度，$e$=恢复系数，$p$=人数，$F$=拉力，$L$=绳长，$H_0$=初降高度，$g$=重力，$J$=转动惯量，$\alpha,\beta,\gamma$=转角/倾角，$n$=鼓面法向量。）

## 符号与前提
- **符号**：见上式；质量 kg、力 N、绳长 m、高度 m、角度 rad（或 °，勿混）、惯量 kg·m²。
- **适用前提**：鼓=刚体、球=质点、绳手水平、小角度/对称、恢复系数已知；碰撞瞬时或含 t0/冲量/功。

## 推导链
1. 受力/动量/能量守恒建立球-鼓碰撞与鼓平动。
2. 写出鼓刚体转动（力矩合成+转动定律）+ 倾角。
3. 用四元数/方向余弦/小角度解耦处理空间旋转。
4. 时间离散递推求 0.1s 倾角/位移。

## 数值算例
- 2019B：理想最优（8 人、L=1.7）约 F≈81N、颠高≈0.434m；各工况 0.1s 倾角约 0.14~0.64°；第 4 问精确控制（10 人、L=2、H=60cm）把 1° 倾角降约到 0.15°、颠高 0.6→0.54m。示例仅示意。

## 陷阱
- 惯量公式（空心/实心、对轴）、恢复系数 e、弧度 vs 度、R（鼓半径/球半径）区分、v2 量级（$\sqrt{2gH}\approx2.8$）、小角度成立范围、碰撞瞬时假设。
