# 公式：团队协作策略优化（目标/约束/无量纲化/反演）

- **category**：formulas
- **entry_id**：2019B_formula_team_strategy
- **source**：自写提炼（2019 CUMCM B 题 B047/B057/B136 的共性）。
- **tags**：多目标、无量纲化、软约束、反演、约束降维、模拟退火

## 公式
1) 目标（理想）：$\min \sum_i F_i$（或单位功率 $P=E/(nT)$），s.t. 颠高 $\ge H_{min}$、同步同力。
2) 多目标（调整）：$\min\ \mathrm{ind}=\omega_1\,\mathrm{ind}_F+\omega_2\,\mathrm{ind}_{vF}+\omega_3\,\mathrm{ind}_{vt}$（无量纲化因子 $\mathrm{ind}$ 承载均匀性/同时性/突变小），加相对误差软约束 $(\Delta\le\epsilon)$。
3) 反演重现：由末端结果 $y$ 反解缺失输入 $\hat x=\arg\min_x\|F(x)-y\|^2$（最小二乘）。
4) 倾斜调整（沿轴零力矩）：$\sum_i M_i=0$（构造一组可行力）。
（符号：$F_i$=各绳拉力，$T$=时机，$n$=人数，$H_{min}$=最小颠高，$\omega_k$=权重，$\mathrm{ind}$=无量纲化偏好因子，$\epsilon$=软约束相对误差，$M_i$=力矩。）

## 符号与前提
- **符号**：见上式；力 N、时机 s、高度 m、力矩 N·m。
- **适用前提**：理想情形无实测、需正向物理推导；现实中误差/倾斜需多目标调整；缺中间态需先反演。

## 推导链
1. 定义目标（理想总力/单位功率、调整多目标）与约束（颠高/间距/同步同力）。
2. 把工程偏好编码成无量纲化因子、加软约束。
3. 缺中间态先反演重现（最小二乘）。
4. 用约束化降维搜索/模拟退火求策略，并给多次运行/方差。

- 2019B：理想 F≈81N、颠高≈0.434m；第 4 问精确控制找到各队员力/时机把 1° 倾角降到约 0.15°；现实误差下效果下降。示例仅示意。

## 陷阱
- 权重/无量纲化因子主观无敏感性；软约束 ε 与量级；反演误差叠加无残差/置信；强假设（同步/对称）限制解；单次最优无多次方差。
