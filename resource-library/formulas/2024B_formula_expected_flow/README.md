## 符号与前提
- **符号**：见上式；单位：成本与售价元/件，率为无量纲。
- **适用前提**：把质量流分解成"筛选/更新 + 层级合成"；决策为 0/1；期望值框架下率为常数（方差用蒙特卡洛/敏度补充）。

## 推导链
1. 对每个"是否检测"节点写**检出后剩余率与成分更新**。
2. 按装配层级用**连乘合成**得成品次品率。
3. 各阶段成本随决策条件展开（检测/装配/调换/拆解/回流），得期望利润。
4. 多阶段用状态-决策+DP；循环回收用收敛判据；次品率带不确定性时用共轭后验 + 端点敏度。

## 数值算例
- 2024B Q2/Q3：先合成成品次品率再枚举/DP，得各情形最优决策与指标（元/件）；Q4 用后验置信区间端点重跑，决策几乎不变（仅个别情形调整）。示例仅示范用法，不作唯一答案。

## 陷阱
- 成本项必须按"是否检测/是否拆解"**条件耦合**（检成品会拦截次品→调换/拆解成本应随之下降；不检测的次品会流入下游）；数量按**瓶颈（min）**约束；"单位/批次"口径统一；期望法忽略方差；多目标若只优化单维、其余仅供记录需明说。
