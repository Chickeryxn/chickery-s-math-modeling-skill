# 公式：订购-转运优化模型（0-1 选供应商 + 逐周订购 + 库存递推 + 产能约束）

- **category**：formulas
- **entry_id**：2021C_formula_ordering_transport
- **source**：自写提炼（2021 CUMCM C 题 C066/C085/C169/C283 的共性）。
- **tags**：0-1 选择、逐周订购、库存递推、产能约束、转运分配、双目标

## 公式
1) 选供应商（0-1）：$\min \sum_i y_i-\lambda\sum_i s_i y_i$，s.t. $\sum_i [\hat x_{i,t}(1-\alpha_{i,t})/p_i]\ge P_{prod}$，$y_i\in\{0,1\}$。
2) 库存递推：$I_k=I_{k-1}+\sum_i x_{i,k}(1-\alpha_i)-\text{消耗}_k$，$I_k\ge 2\times\text{周产能}$。
3) 产能/消耗系数：$P_{prod,j}=\sum_i\big[x_{i,j}(1-\alpha_{i,j})(1-l_{k,j})/\eta_i\big]$，$\eta$=0.6/0.66/0.72。
4) 转运分配：单供应商尽量由单转运商，$\sum_j y_{ij}\le1$，转运商能力 $\le6000$；损耗率 $\alpha=(\text{供货}-\text{接收})/\text{供货}$。
5) 双目标：$\min\sum_i r_i x_{i,k}$（成本）、$\min\sum_j (s_{i,k}-t_{i,k})/z_i$（损耗），s.t. $\sum_j s_{i,k}\le6000$、$I_k\ge28200\times2$、$s=p\,d$、$t=(1-l)s$、$0\le d\le6000$。
（符号：$y_i$=选否；$s_i$=重要性；$\hat x$=供货能力；$\alpha$=损耗率；$p_i/\eta_i$=每 m³ 产品耗料；$I_k$=库存；$r_i$=采购单价；$s_{i,k},t_{i,k}$=供货/接收量；$d$=订货量。）

## 符号与前提
- **符号**：见上式；量 m³、库存 m³、产能 m³/周、损耗率/单价。
- **适用前提**：多类原料先统一换算成"可产产品"；库存 ≥ 两周产能；转运商能力上限；订供偏差/损耗率可用分布拟合。

## 推导链
1. 评价入选（收敛供应商集合）。
2. 用 0-1 整数规划定最少家数，再 LP/GA 定逐周订购。
3. 用库存递推 + 产能折算 + 转运能力约束，做转运分配（损耗最小）。
4. 多目标（成本/损耗/结构/重要性）按优先级或 Pareto；定位瓶颈（供给 vs 转运）。

## 数值算例
- 2021C：402 家 →top50、最少 24~39 家、24 周周采购成本约 2 万/损耗 1.34%、A/C 占比改善、每周产能 28200→约 43000~48000。示例仅示意，口径不一。

## 陷阱
- 口径（α=0.05 vs 1.34%、万 m³ vs m³、成本 元/m³ vs 万元/千m³）；原料未统一换算则目标不可比；损耗率当常数违背随机规划；"一家尽量由一家转运商"被弱化；"至少几家/产能提高"给确定可核而非随机区间；随机性需多实现与置信。
