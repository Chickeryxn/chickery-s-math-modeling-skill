# 公式：稳态控制优化（偏差平方和 + 遍历/坐标下降 + 减压阀/双喷参数）

- **category**：formulas
- **entry_id**：2019A_formula_control_opt
- **source**：自写提炼（2019 CUMCM A 题 A023/A190/A240 的共性）。
- **tags**：偏差平方和、周期窗口、遍历、坐标下降、减压阀、双喷

## 公式
1) 目标：$\min\ Z=\int_{t_1}^{t_2}\big(P(t)-P_e\big)^2 dt$（差分 $\sum(P_n-P_e)^2\Delta t$），$P_e$=期望压力。
2) 求解：遍历（$T\in[0.25,0.35]$ms、粗 0.5→细 0.0001）或坐标下降（固定其余逐维遍历）——利用"稳态-决策一一对应+目标下凸"。
3) 减压阀/双喷：泄压阀式 $P>P_R$ 开启、电磁阀式 $T_{on}/T_{off}$+相位；喷油时差 $\Delta t$（双喷 $B_2$ 初相为变量）。
（符号：$Z$=偏差平方和，$P,P_e$=实际/期望压力，$T$=开阀时长，$P_R$=泄压阈值，$T_{on}/T_{off}$=电磁阀开关时长，$\Delta t$=双喷时差。）

## 符号与前提
- **符号**：见上式；压力 MPa、时长 ms、角速度 rad/s（勿用 rad/ms 混）。
- **适用前提**：周期稳态、目标下凸/稳态-决策一一对应（否则换全局/随机）；偏差平方和定义于周期公共窗口。

## 推导链
1. 写周期边界与守恒 ODE（/加柱塞腔、双喷、减压阀子系统）。
2. 定目标（偏差平方和）与可行域。
3. 用差分+遍历/坐标下降（粗-细）找极小；给判稳（幅值/方差）与敏感性。
4. 对比控制方案（如阈值泄压 vs 电磁阀）并给鲁棒性。

## 数值算例
- 2019A：$T\approx0.29$ms（100MPa）、$0.72\sim0.9$ms（升150MPa）；$\omega\approx27.2\sim27.5$rad/s；双喷 $\Delta t\approx50$ms；泄压 $P_R\approx102.25$MPa。示例仅示意，口径不一。

## 陷阱
- 单位（rad/s vs rad/ms）；目标在 |min| 与 min∫ 间切换；周期公倍数近似；遍历+阈值为网格次优；判稳仅用"偏差和→0"且只截末段；减压阀对比仅单扰动定性。

## 可迁移
- 同类题：受迫/脉动系统稳态控制、参数寻优。
- 同思想异解法：目标换（偏差平方/幅值/CVaR），求解换（遍历/坐标下降/启发式/梯度），控制方式换（阀/电磁/泄压/相位）。
