# 公式：天气马尔可夫 / 期望收益 / 博弈纳什

- **category**：formulas
- **entry_id**：2020B_formula_weather_game
- **source**：自写提炼（2020 CUMCM B 题 B078/B108/B125/B175 的共性）。
- **tags**：马尔可夫、天气等效、期望、博弈、纳什、双指标

## 公式
1) 天气马尔可夫：状态转移矩阵 $P$，极限分布 $\pi P=\pi$；天气等效 $xB_1+yB_3=(x+y)B_2$（如晴朗:沙暴≈5:1 等效高温）。
2) 期望收益：$V^\pi(s)=E_\pi[\sum_t\gamma^t R_t|s_0=s]$；$Q^\pi(s,a)=\sum_{s'}P(s'|s,a)[R(s'|s,a)+\gamma V^\pi(s')]$；失败率=未达终点比例。
3) 博弈（纯/混合策略、纳什）：支付矩阵 $M$（$M_{ij}$=两路线不冲突−冲突）；混合策略 $U=q^T M q'$，$\max_{q}\min_{q'}U$（/$\min\max$），求纳什 $q$。
（符号：$P$=天气转移矩阵，$\pi$=平稳分布，$\gamma$=折扣，$s,a$=状态/动作，$M$=支付矩阵，$q,q'$=策略概率。）

## 符号与前提
- **符号**：见上式；概率无量纲、收益元、支付矩阵元素（冲突/不冲突数）。
- **适用前提**：未来天气/他人策略有概率/博弈结构；多人路径第 1 天前拟死、交互公开。

## 推导链
1. 用历史/统计建天气转移矩阵（或天气等效）。
2. 对每种（/抽样）天气用确定性 DP 求最优，加权取期望；评价用"期望收益+失败率"。
3. 多主体：构造支付矩阵、求纯/混合纳什（按阶段分解可"单日纳什再拼接"）；无占优/不可概率化则退化为期望。

## 数值算例
- 2020B：天气极限分布约 (0.31 晴 /0.48 高温 /0.21 沙暴)；期望收益约 9350/10500、失败率<2.5%；多人博弈给混合/纯策略（如路线 q={0,0.22,0.78} 选路线3）。示例仅示意。

## 陷阱
- 概率/势非负+归一化（表出现 Inf/NaN 粗暴置零）；天气等效/沙暴概率主观无敏感性；博弈均衡存在性、纯/混规范、"逐日纳什再拼接"的合理性；随机模拟单次/无种子；循环论证（用虚构天气再模拟验证）。
