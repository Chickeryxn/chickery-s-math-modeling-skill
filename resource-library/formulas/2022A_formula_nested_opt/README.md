# 公式：嵌套优化模型（ODE 约束 + 积分目标 + 稳态 + 参数区间）

- **category**：formulas
- **entry_id**：2022A_formula_nested_opt
- **source**：自写提炼（2022 CUMCM A 题 A001/A022/A171 的共性）。
- **tags**：嵌套优化、ODE 约束、稳态平均、参数区间、边界最优

## 公式
1) 目标（稳态平均输出功率）：$max ar P=dfrac{1}{10T}int_{90T}^{100T}eta,|dot x_z-dot x_f|^2,dt$（取末周期平均滤瞬态）。
2) 等式约束（ODE 运动方程）：$dot X=f(X;eta,alpha)$，初值 $X(0)=0$；由 ODE 隐式决定 $dot x_z-dot x_f$。
3) 不等式约束：$etain[0,1e5]$、$alphain[0,1]$、几何安全（不越界/不浸顶）$x_0+x_2-x_1+H_3le H_1$、$x_1le L_{max}$。
（符号：$X$=状态（位移/速度/角位移/角速度），$eta$=阻尼系数，$alpha$=幂指数，$T$=激励周期，$H/L$=几何安全高度/长度。）

## 符号与前提
- **符号**：见上式；功率 W、阻尼 N·s/m、长度 m。
- **适用前提**：目标由状态经微分方程耦合、无法显式化；需先解 ODE 再积分目标；取稳态（末若干周期）平均才有工程意义。

## 推导链
1. 定义决策（阻尼/幂）与目标（时均功率）。
2. 把 ODE 作为等式约束嵌入。
3. 写参数区间与几何安全不等式约束。
4. 用梯形/Simpson 算目标 + 求解器（fmincon/GlobalSearch/GA/枚举）寻优；辨析边界/内部最优。

## 数值算例
- 2022A：幂律最优 $etaapprox9.75e4$、$alphaapprox0.34sim0.40$、$Papprox230$W（部分落在 $eta$ 上界）；Q4 双阻尼 $approx(6.2e4,9.6e4)$、$Papprox328$W。示例仅示意。

## 陷阱
- 取末周期平均而非前段（滤瞬态）；目标/功率口径统一；最优可能落边界（须说明并判断可否放宽）；双参数可能近似退化（某通道增益近 0）；单次评估贵、注意评估预算与收敛。
