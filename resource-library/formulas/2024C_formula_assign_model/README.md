# 公式：指派建模——0-1 开关 + 大 M + 分段线性化 + 集合分块约束

- **category**：formulas
- **entry_id**：2024C_formula_assign_model
- **source**：自写提炼（2024 CUMCM C 题 C063/C094 为主）。
- **tags**：0-1 开关、大 M、分段线性化、集合分块、指派

## 公式
1) 0-1 开关与大 M / 小下界衔接：
$$Xle M,Y,qquad Xgearepsilon,Y,qquad Yin{0,1}$$
2) 分段收益（超量滞销 / 五折）：
$$max sum_{t,j,k}Big[min(mathrm{Output}_{t j k},q_{t j k}),p_{t k}+alpha,(mathrm{Output}_{t j k}-q_{t j k})_{+},p_{t k}-c_{t j k},X_{t j k}Big]$$
（可加辅助变量与约束线性化 `min`/`(·)₊`。）
3) 地块面积 / 最小量：$sum_k X_{t j k}le S_j$，$X_{t j k}gealpha_{min} S_j,Y_{t j k}$。
4) 不重茬（相邻/跨季）：$Y_{t,j,k}+Y_{t+1,j,k}le1$（二季/跨季用乘积=0 线性化）。
5) 三年豆类：$sum_{t=t_0}^{t_0+2}sum_k I_k,X_{t j k}ge S_j$。
6) 分散度：$sum_j Y_{t j k}le q$（横向地块数），$sum_k Y_{t j k}le p$（纵向类数）。
（符号：$X$=面积(亩)，$Y$=0-1 开关，$M,arepsilon$=大 M 与小下界，$mathrm{Output}$=亩产×面积，$q$=预期销量，$p$=售价，$c$=成本，$I_k$=豆类标志，$S_j$=地块面积，$alpha$=滞销/折价因子，$p,q$=分散度上限。）

## 符号与前提
- **符号**：见上式；单位：面积亩、价格元/斤、成本元。
- **适用前提**：对象为"是否做+做多少+封顶/至少/不连续"的指派问题；约束可写成线性/分段线性；用 0-1 表达离散逻辑。

## 推导链
1. 定义决策张量与 0-1 开关。
2. 逐条把业务规则翻译成不等式（面积/最小量/品种适配/轮作/豆类/分散度）。
3. 用大 M/小下界接通开关与连续量；用辅助变量线性化 `min/max/(·)₊`。
4. 按规模选精确求解器（Gurobi/CBC/LINGO）或启发式，并做基线互证。

## 数值算例
- 2024C：54 地块×41 作物×7 年≈1.5 万级 0-1+连续变量；Q1（滞销/五折）得 七年总收益（约 4530 万/6469 万）。示例仅示范建模，不作唯一答案。

## 陷阱
- `min/max/(·)₊` 须线性化不能直接非线性；大量 0-1 用大 M（取值影响数值稳定）；"地块数"与"面积"量纲勿混；豆类标志 $I_k$ 方向须自洽（否则约束失效）；从观测强行推广的最小面积占比要谨慎。

## 可迁移
- 同类题：一切"是否做+做多少+封顶/至少/不能连续"的指派/排产。
- 同思想异解法：分段收益线性化换大 M 或 SOS1；求解器换算法（精确→启发式）。
