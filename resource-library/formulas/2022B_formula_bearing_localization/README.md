## 符号与前提
- **符号**：见上式；角度 ° 或 rad、长度 m。
- **适用前提**：纯方位无源（仅方向夹角）+ 发射机位置无偏/编号已知；共面、相对位置不变；接收与发射角按约定（与任意两发射连线夹角）。

## 推导链
1. 由两个夹角与两发射坐标，用正弦定理在三角形（圆心-两发射-接收）中解出接收机极坐标。
2. 用角量化（圆/正多边形）与集合唯一性反推未知编号/最少发射。
3. 由角度误差一阶近似得径向/切向调整量，再预处理降阶。

## 数值算例
- 2022B：圆心 FY01+FY00 等两/三发射，得某接收机极坐标；编号未知时由角量化唯一化归；调整后各机 $\rhoapprox R$、$\theta\approx$均匀（示例仅示意）。

## 陷阱
- 接收夹角 $alpha_i$ 的符号/方向约定要一致；共面/共圆退化会多解/无解（需特判）；一阶近似在小误差内；唯一性依赖角间隔不被误差抹平（界定 ε）；"接收角"是两发射机连线夹角而非单条射线方向。
