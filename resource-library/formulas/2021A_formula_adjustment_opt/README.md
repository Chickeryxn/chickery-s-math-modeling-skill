# 公式：反射面调节优化模型（变量 / 约束 / 目标 / 求解）

- **category**：formulas
- **entry_id**：2021A_formula_adjustment_opt
- **source**：自写提炼（2021 CUMCM A 题 A028/A115/A217 的共性）。
- **tags**：调节优化、minimax、约束、变步长、BFGS

## 公式
1) 变量：节点工作坐标（/促动器径向伸缩量 $l_i\in[-0.6,0.6]$m）。
2) 约束：下拉索定长（$|P_i^{动}-P_i^{地}|=\text{const}$）、邻近节点距变 $\frac{|\Delta d|}{d}\le0.07\%$、$l_i$ 范围。
3) 目标：$\min_{\{l_i\}}\ \sum_i|X_i^{实际}(l)-X_i^{理想}|^2$（/ $\min\ \max_i$ 相邻距变率·minimax）。
4) 求解：一维（对焦距 $f$）用变步长/二分；高维带光滑凸约束用拟牛顿（BFGS）/内点（fmincon）。理想面 $z=\frac{x^2+y^2}{4f}$。
（符号：$X_i$=节点坐标，$l_i$=促动器伸缩量，$f$=焦距，$\Delta d/d$=相邻距变率，$P_i^{动}/P_i^{地}$=节点工作/地锚点坐标。）

## 符号与前提
- **符号**：见上式；伸缩 m、距变率无量纲、坐标 m。
- **适用前提**：以"节点径向位移"为可控变量、面板近似刚性；几何约束（索长+距变+伸缩范围）可写成等式/不等式。

## 推导链
1. 定义可控变量（节点位移/促动器伸缩）与目标（贴近理想面）。
2. 写约束（索长定长、距变、伸缩范围）。
3. 用贴近度量 + 约束求解（BFGS/minimax/变步长）。
4. 若目标约束不可同时满足，明确"放宽/妥协解"并说明。

## 数值算例
- 2021A：Q2 节点距变约 ±0.06%（在用满 0.07% 裕度）、伸缩量存 result.xlsx；Q1 焦距 f≈280.85m。示例仅示意。

## 陷阱
- 算法叙述与实现一致（拉格朗日+BFGS vs fmincon 内点）；0.07% 可能无法真正满足（为妥协解）；贴近度量忽略面板刚性/力学会失真；变量数大注意收敛/评估预算。
