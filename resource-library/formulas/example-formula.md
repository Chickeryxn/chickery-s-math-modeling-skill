# 示例公式：加权综合得分与灵敏度（演示模板，非真实竞赛内容）

- **公式**：$$S_i=\sum_{j=1}^{m} w_j\, z_{ij},\qquad z_{ij}=\frac{x_{ij}-\min_j}{\max_j-\min_j}$$
- **适用**：评价类（熵权-TOPSIS 前处理）；无量纲化后再聚合
- **推导要点**：先极差标准化保证可比；权重 $w_j$ 来自熵权（信息量）或主观
- **陷阱**：方向性（成本型指标需正向化）；权重主导（某一 $w_j$ 过大）；极差为零的分母保护
- **可迁移**：任何"多指标聚合"场景；灵敏度 $S_i$ 对 $w$ 的偏导可做扰动分析
