# 公式：测线布设优化模型（总长最小 + 全覆盖 + 10%~20% 重叠）

## 公式
1) 目标（总长最短）：$min sum_i ell_i$（每条测线长度 $ell_i$）。
2) 覆盖/重叠约束：$sum_i W_i-sum_ieta_i W_i ge 	ext{待测区域宽}/cosalpha$，$10%leeta_ile20%$。
3) 递推排线：沿等深线/最有利方向，用临界 $eta=10%$ 反解相邻间距 $d_i$，逐条推进直到覆盖全区域。
（符号：$W_i$=第 i 条覆盖宽度，$eta_i$=相邻重叠率，$ell_i$=第 i 条长度，$alpha$=坡度，$eta$=方向角。）

## 符号与前提
- **符号**：见上式；长度 m（/海里）；覆盖与漏测率互补（漏测率 $=1-$覆盖率）。
- **适用前提**：规则/半规则待测海域；先证"沿等深线覆盖最宽/最稳"再排线；真实地形先分块拟合。

## 推导链
1. 由几何模型得每个位置/方向的覆盖宽度与重叠率。
2. 找出最有利方向（沿等深线/⊥梯度）。
3. 用临界重叠率递推/贪心求间距与条数，满足全覆盖；必要时用主要目标法（漏测为主目标、其余转约束）。
4. 用启发式（退火/PSO）交叉验证或用分治拟合分块坡面。

## 数值算例
- 2023B：Q3 2×4 海里、中心110m、θ=120°、α=1.5°，取 η=10% 递推约 34 条、总长约 125936m；Q4 分块后约 437 条、漏测 3.48%。示例仅示意。

## 陷阱
- 需先证"沿等深线最宽/最稳"否则重叠失控；重叠率口径一致（水平/投影）；覆盖率与漏测率互补（漏测 2.3%⇔覆盖 97.7%）；总长单位 m/海里别混；"沿东西向"与"平行等深线（南北）"要一致。
