# 公式：抽样最小样本量的 OC/双风险范式

- **category**：formulas
- **entry_id**：2024B_formula_sampling_min_n
- **source**：自写提炼（2024 CUMCM B 题 B159/B195/B196）。
- **tags**：抽样、OC 函数、双风险、正态近似、t 统计量、样本量

## 公式
1) 二项接受概率（OC 函数）：
$$L(p,n,c)=sum_{k=0}^{c} C(n,k),p^k(1-p)^{n-k}$$
2) 双风险约束：
$$L(p_1)leeta,qquad 1-L(p_0)lealpha$$
3) 正态近似下的最小样本量（n 大、$ksim B(n,p)	o N$）：
$$n_{min}=rac{ig[Z_alphasqrt{p_0(1-p_0)}-Z_{1-eta}sqrt{p_1(1-p_1)}ig]^2}{(p_1-p_0)^2}$$
4) 方差未知时用 t 统计量：
$$t=rac{ar X-p_0}{S_n/sqrt n}sim t(n-1)$$
（符号：$p_0$=可接受次品率，$p_1$=可拒次品率，$alpha$=弃真/拒收风险，$eta$=取伪/漏收风险，$c$=接收数，$ar X=k/n$，$S_n$=样本标准差。）

## 符号与前提
- **符号**：见上式；$p_0<p_1$，$Z$ 为标准正态分位。
- **适用前提**：把"信度/置信度"落成检验方向上的 α/β；需要给定 p₀、p₁（或其一 + 另一由功效/容差设定）；大 n 才能用正态近似，否则用精确二项。

## 推导链
1. 写出 OC 函数 L(p,n,c)（接受概率随 p 单调递减）。
2. 用第一/二类错误约束：p≥p₁ 时 L≤β、p≤p₀ 时 L≥1−α。
3. 正态近似把二项改写到标准正态分位，联立两条约束反解 n（与 c 的区间/阈值）。
4. 方差未知换 t 统计量；为"最小"可加检测成本×漏检损失的权衡（功效函数）。

## 数值算例
- 例：$p_0=0.10$、$alpha=0.05$、$p_1$ 与 $eta$ 取定时代入可得最小 n（2024B Q1 各论文给 n≈43 或一组 (n,c) 对，如 n=1600/2646 为 t/工程容差口径）。示例仅示范用法，不作唯一答案。

## 陷阱
- 单侧/双侧、接收/拒收方向要区分；p₀、p₁ 是**建模输入**，需论证取值；正态近似在大 n 才准；n_min 常不唯一，应给"最小可行"而非"一对可行"；"检测次数尽可能少"的真解是**序贯抽样**，固定 n 只是近似。
