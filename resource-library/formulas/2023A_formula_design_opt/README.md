## 公式
1) 目标（单位镜面面积年平均输出热功率）：$max P_d=dfrac{ar E_{field}}{sum_i A_i}=dfrac{rac{1}{T}sum_t DNI_tsum_i A_ieta_i(t)}{sum_i A_i}$（$T$=月均/年均时刻数）。
2) 约束：半径 $le350$m、距塔 $ge100$m、相邻中心距 $ge w+5$m、$2le hle wle8$、$2le zle6$ 且 $zge h/2$、额定 $ar Ege60$MW。
3) 降维：把 $P_d$ 看作塔南移 $D$、镜宽 $w$ 的单峰函数，三分查找 $D^*=arg_{	ext{三分}}max P_d(D)$；或"粗搜定位→缩步精搜"（步长 1→0.1）。
（符号：$P_d$=单位镜面面积年平均输出热功率；$A_i$=镜面积；$ar E_{field}$=年平均场功率；$h,w,z$=镜高/宽/安装高；$D$=塔南移距离。）

## 符号与前提
- **符号**：见上式；单位：功率 kW/MW、长度 m、面积 m²。
- **适用前提**：设计问题需在几何+功率约束下最大化单位资源产出；目标为昂贵黑箱、对单变量近似单峰。

## 推导链
1. 定义设计变量（塔位/尺寸/安装高/数目/位置）与目标（单位面积功率）。
2. 写出几何/功率/工程约束。
3. 用对称性/降维把决策变量压到少数，再用三分/变步长/启发式搜索。

## 数值算例
- 2023A：Q2 塔偏南（如 (0,−79)~(0,−250)）、6×6~5.5×5.5m、高 2.75~6m、约 2740~3385 面，单位面积约 0.45~0.72 kW/m²。示例仅示意。

## 陷阱
- "额定≥60MW"与"单位面积最大"是折中目标，非纯最大化；自由度高时指标可能反降；用"恰达额定"而非"超发"更贴近题意；降维/单峰须先证；未收敛/非全局最优要标注。

## 可迁移
