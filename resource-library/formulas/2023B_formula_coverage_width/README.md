# 公式：覆盖宽度与重叠率（解三角形 / 线面角）

- **entry_id**：2023B_formula_coverage_width

## 公式
1) 深度随位置：$D=D_0-y	analpha$；三维：$D=H_0+L	analphacoseta$。
2) 覆盖宽度（开角 θ、坡度 α）：$W=Dcdotdfrac{sin(	heta/2)}{sin(rac{pi}{2}-rac{	heta}{2}-alpha)}+dfrac{sin(	heta/2)}{sin(rac{pi}{2}-rac{	heta}{2}+alpha)}$ 的乘 $D$ 等价式（有的写成 $W=Dsin	hetacosalpha/[cos(	heta/2+alpha)cos(	heta/2-alpha)]$）。
3) 线面角（方向 β）：$delta=arcsinBig(dfrac{|sinetasinalpha|}{sqrt{cos^2eta+sin^2alphasin^2eta}}Big)$。
4) 重叠率（平坡）：$eta=1-dfrac{d}{W}$；坡面需口径一致重定义（用"有效覆盖/条带宽"）。
（符号：$D$=水深，$D_0,H_0$=中心水深，$alpha$=坡度，$eta$=测线方向与坡面法向水平投影夹角，$	heta$=换能器开角，$W$=覆盖宽度，$d$=测线间距，$eta$=重叠率。）

## 符号与前提
- **符号**：见上式；角度 ° 或 rad；长度 m（或海里，1海里=1852m）。
- **适用前提**：多波束/声呐/探测条带覆盖；海底近似坡度；开角 θ 与坡度 α 已知。

## 推导链
1. 由几何（水深随位置/方向变化）求两边缘射线与海面/坡面的交点，得左右边缘。
2. 用正弦定理/解三角形把覆盖宽度写成 D、θ、α、（方向 β）的函数。
3. 由相邻条带重叠定义反解测线间距（保证 10%~20%）。

## 数值算例
- 2023B：θ=120°、α=1.5°、D₀=70m、d=200m，中心处 W≈243m、η≈21%；随远离中心（水深变浅）W 减小、η 变负（漏测）。示例仅示意。

## 陷阱
- 重叠率定义在坡面有歧义（d 水平间距 vs 坡面投影）须一贯；由平坡公式切换到含 D 的口径要交代；β=90°/270°（沿等深线）时 W 恒为常数，β=0° 时变化最大；单位 m/海里、角度。
