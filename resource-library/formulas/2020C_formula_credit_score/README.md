# 公式：信用评分 / 违约概率 / 风险量

- **category**：formulas
- **entry_id**：2020C_formula_credit_score
- **source**：自写提炼（2020 CUMCM C 题 C109/C142/C170/C227/C305 的共性）。
- **tags**：Logistic、评分卡、违约概率、PCA 指数、AUC、评级

## 公式
1) 逻辑回归（违约概率）：$P(y=1|x)=\frac{1}{1+e^{-(\beta_0+\beta_1x_1+\dots+\beta_kx_k)}}$（/守约率 logit）。
2) 综合指数（PCA/打分）：$I=a\cdot z$ 或 $Score=\sum_j w_j z_{ij}$（熵权/TOPSIS/投影寻踪定权）。
3) 判别/评级：树/集成/XGBoost 给类别或连续概率；用 AUC/准确率/KS/混淆矩阵评估。
4) 违约概率函数（人工/拟合）：$d=d(I)$（如 $d=\sqrt{5/\pi}\exp(-10 I^2)$，注意系数与假设方差一致）。
（符号：$x_j$=特征（实力/信誉/供求/作废票比…），$P$=违约概率，$I$=综合指数，$w_j$=权重，$z_{ij}$=标准化指标，$d$=违约概率。）

## 符号与前提
- **符号**：见上式；概率无量纲、指数无量纲、指标已正负向化/标准化。
- **适用前提**：特征工程先行（清洗/去异常/补缺失）、样本足以评估；小样本+需可解释用 Logistic/评分卡，否则可加集成/XGBoost 并给基线/AUC。

## 推导链
1. 特征工程（业务语义指标）。
2. 选评分模型（Logistic/PCA 指数/树/集成/XGBoost 多分类），做训练/测试划分与 AUC/基线评估、防过拟合。
3. 用插补/迁移为缺标签企业补评级（最近邻/两级网络/聚类）。
4. 输出违约概率/评级作下游优化系数。

## 数值算例
- 2020C：若干篇 6 特征 Logistic/集成 AUC≈0.94-0.99、评级准确率约 0.88，D 级违约风险≈0.7；部分篇基分类器训练 1.0 vs 测试 0.806-0.871（过拟合）。示例仅示意。

## 陷阱
- 特征方向（正负向化）、标准化；样本小/类不平衡过拟合；无训练/测试/AUC/基线；AUC 高≠可靠；人工 d(I) 与假设方差一致；级联误差（用预测值当输入）；符号（P=守约率 vs 违约率、R 评级）口径一致。
