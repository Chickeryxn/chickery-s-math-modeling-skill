# 公式：穿越沙漠 DP 递推（转移 / 消耗倍率 / 负重约束）

- **category**：formulas
- **entry_id**：2020B_formula_dp_transition
- **source**：自写提炼（2020 CUMCM B 题 B078/B108/B125/B175 的共性）。
- **tags**：DP 递推、消耗倍率、负重、购买、挖矿、状态转移

## 公式
1) 状态转移（移动）：$dp(i+1,j',k-2c_w,l-2c_f)=\max\{\cdot,dp(i,j,k,l)\}$，需 $k\ge2c_w,\ l\ge2c_f$。
2) 村庄/起点购买：$dp(i,j,k+k',l+l')=\max\{\cdot,dp(i,j,k,l)-2k'p_w-2l'p_f\}$。
3) 消耗倍率：行走 2×基础、沙暴停留 1×、挖矿 3×（并 + 挖矿收益）；负重约束 $m_w W+m_f F\le M_{load}$；$W,F>0$；$t\le T_{max}$。
4) 目标：$\max\ R(end,T_0)$，$W(end,T_0)=F(end,T_0)=0$。
（符号：$i$=天数、$j$=位置、$k,l$=水/食物量、$c_w,c_f$=基础单位消耗、$p_w,p_f$=单价、$m_w,m_f$=单位重量、$M_{load}$=负重上限、$R$=资金。）

## 符号与前提
- **符号**：见上式；水/食物按箱或 kg，资金元，重量 kg。
- **适用前提**：决策满足无后效性+重叠子问题+最优子结构；状态可离散；负重与截止日约束。

## 推导链
1. 定义状态（天/位置/水/食物/资金）与动作（走/停/挖/买）。
2. 写五类转移（起点买/村庄买/停留/挖矿/走）的 DP 递推与消耗/收益。
3. 用结构性质压缩（只值得去功能点、朝功能点最短路）并加凸性优化降复杂度。
4. 回溯求"到终点剩余资产最大"；随机/多主体时在外层套期望/博弈。

## 数值算例
- 2020B：第一关最优剩余 10470（挖 7~9 天）、第二关 12730（挖 13 天）、第三关直奔终点约 9350、第四关约 10500（挖 13 天）。示例仅示意。

## 陷阱
- 消耗倍率（走 2/挖 3/沙暴停 1）与价格（起点/村 2 倍/终点退半）口径一致；购买公式水/食勿共用 RHS/量纲乱；"2k vs 2^k"；状态离散化/凸性优化的正确性；幸存者偏差（确定性 DP 偏乐观）。
