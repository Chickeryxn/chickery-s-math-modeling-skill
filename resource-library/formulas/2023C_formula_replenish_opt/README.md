# 公式：补货定价优化模型（混合 0-1 + 单/多目标 + 约束）

## 公式
1) 目标（单目标，品类/单品周利润最大）：$max sumig[Q_i(P_i-B_i)-R_i B_i L_iig]$（毛利−损耗）。
2) 混合决策：定价 $P_i=(1+w_i)C_i$、补货量 $R_i$、选品 0-1 $z_i$（$z_i=0Rightarrow R_i=0$）。
3) 约束：$Q_ile R_i$、$27lesum_i z_ile33$、$z_i R_ige2.5$（kg 最小陈列）、损耗上限、品类补货比例；多目标时加 $max$ 需求满足度。需求度用 VIKOR：$S_i=sum_j w_jrac{f_j^*-f_{ij}}{f_j^*-f_j^-}$（融合销量+销售次数）。
4) 需求满足度：$	ext{满足度}=rac{	ext{实际满足需求}}{	ext{总需求}}$（应为 0~1，不应超 1）。
（符号：$P$=售价，$B$=单位成本，$C$=进价，$w$=加成率，$L$=损耗率，$R$=补货量，$Q$=销量，$z$=0-1 选品，$f_j$=需求度指标。）

## 符号与前提
- **符号**：见上式；价格元、量 kg、损耗率无量纲。
- **适用前提**：把"补货量+定价+选品"作为决策；需在数量/陈列/损耗约束下最大化收益（或收益+需求满足度）。

## 推导链
1. 定义决策变量（连续补货/定价 + 0-1 选品）与目标。
2. 写出约束（销量≤补货、17-33 种、最小陈列、损耗）。
3. 用需求弹性/预测把"定价→销量"接入目标，形成闭环。
4. 用 SA/GA/NSGA-II/PSO/整数规划求解；多目标给 Pareto 前沿。

## 数值算例
- 2023C：Q2 一周最大收益约 5105~1810 元（口径不同）、Q3 约 1282~16686（含 0-1 选品），单品利润率多聚在 1.19 附近。示例仅示意。

## 陷阱
- 目标-约束自洽：不得为满足约束用辅助变量放宽到"需求满足度>1"或"含负利润单品"；弹性内生；"销量"必须与定价内生耦合而非外生给定；最小陈列量单位（kg）与数量一致。
