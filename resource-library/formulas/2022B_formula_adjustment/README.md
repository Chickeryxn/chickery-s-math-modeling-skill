# 公式：调整方案（局部目标 + 全局检验 + 几何引理）

- **category**：formulas
- **entry_id**：2022B_formula_adjustment
- **source**：自写提炼（2022 CUMCM B 题 B030/B035/B086 的共性）。
- **tags**：调整方案、局部目标、全局检验、几何引理

## 公式
1) 局部目标：$min f_i(Delta)=|alpha_i-alpha_i^*|^2$（在邻域 2δ×h 搜索），$Delta$=位置调整量。
2) 全局只读检验：$E=sum_{i=2}^{9} f_i$（或平面化函数 $Phi=sum(cdots)$），判断整体是否合格（不进入调整）。
3) 几何引理（锥形/等距）：正三角形/圆心角关系用于把点调到"定比分点/几何中心"，贪心逐步落位。
（符号：$alpha_i$=观测方位角，$alpha_i^*$=理想方位角，$f_i$=局部目标，$E$=全局误差，$Phi$=平面化检验。）

## 符号与前提
- **符号**：见上式；角度 °/rad、长度 m。
- **适用前提**：信息受限（各机只收方向、不共享），用局部模型逼近、事后用独立全局度量判合格；编队结构有对称性/可分解。

## 推导链
1. 定义局部目标（方位角范数平方）与邻域搜索。
2. 固定少量参照单元/发射机（固定参考系），其余按局部模型逐步调整。
3. 预处理（径向/刚性对齐）降阶，再局部搜索。
4. 用独立只读全局检验判断是否达到整体优；给多组扰动鲁棒性。

## 数值算例
- 2022B：每轮选 2 或 3 架发射，其余最小化局部目标，多轮后全局误差收敛到 e-6；锥形平面化检验 3.893→0.206。示例仅示意。

## 陷阱
- 局部最优≠全局最优（须检验）；"只读全局检验"要独立、不参与调整；对称/退化需特判；误差口径（±0.5°/1°/1%→15%）要一致；搜索步长/邻域与收敛。
