# 公式：收率优化（盒约束）与实验设计（均匀/加权广度）

- **category**：formulas
- **entry_id**：2021B_formula_yield_opt
- **source**：自写提炼（2021 CUMCM B 题 B007/B026/B050/B160 的共性）。
- **tags**：盒约束优化、收率、均匀设计、加权欧氏距离广度、五因素

## 公式
1) 目标（盒约束）：$\max\ \hat\omega(x)$，s.t. $x_j\in[L_j,U_j]$（如 $T\in[300,500]$、质量/负载量/浓度区间）；$\hat\omega$=响应面/回归/神经网络拟合的收率。
2) 实验设计（均匀设计）：$U_n(n^s)$（用较少的点覆盖因子空间）。
3) 补充实验（广度量）：$\max\ \min_k\ d(x^*,x_k)$（新增点与已有组合的最小距离尽量大），如 $d^2=\sum_i w_i(x_i^*-x_{ki})^2$（加权欧氏距离）。
（符号：$\hat\omega$=收率拟合，$x_j$=因素，$[L_j,U_j]$=盒约束，$d$=距离，$w_i$=权重。）

## 符号与前提
- **符号**：见上式；收率 %，温度 ℃，质量/浓度单位按题。
- **适用前提**：目标由拟合模型给，且在因素盒约束内；实验次数受限（如仅 5 次）需设计原则。

## 推导链
1. 用响应面/回归/NN 拟合收率。
2. 在盒约束下优化（fmincon/quadprog/LINGO；注意非凸目标可能局部）。
3. 若需补充实验，用均匀设计/补空白/验证非偶然，或用"广度量"最大化与已有样本的分离。

## 数值算例
- 2021B：Q3 最优约 450℃（约 400mg 组合）收率≈51.3%~56.3%，<350℃ 约 29.8%~38.5%；Q4 加权欧氏距离广度给出 5 次补充实验。示例仅示意。

## 陷阱
- 目标非凸（含交叉项）→ 未必全局最优，须说明/多起点；只搜部分组合却断言全局峰；"最优"措辞谨慎；盒约束外推（超出实测区间）；实验设计无功效/样本量依据。
