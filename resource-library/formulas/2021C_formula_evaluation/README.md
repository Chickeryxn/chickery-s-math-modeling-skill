# 公式：多指标综合评价（熵权 / 投影寻踪 / TOPSIS）

- **category**：formulas
- **entry_id**：2021C_formula_evaluation
- **source**：自写提炼（2021 CUMCM C 题 C066/C085/C169/C283 的共性）。
- **tags**：熵权、TOPSIS、投影寻踪、贴近度、综合评价

## 公式
1) 归一化/正向化：极差/向量规范化（成本型先正向化）；熵 $E_j=-\frac{1}{\ln n}\sum_i p_{ij}\ln p_{ij}$，权重 $W_j=\frac{1-E_j}{\sum_j(1-E_j)}$。
2) TOPSIS 贴近度：$D_i^+=\sqrt{\sum_j w_j(v_{ij}-v_j^+)^2}$、$D_i^-=\sqrt{\sum_j w_j(v_{ij}-v_j^-)^2}$，$C_i=\frac{D_i^-}{D_i^++D_i^-}$（越大越优）。
3) 投影寻踪：$\max Q(a)=S_z\,D_z$，s.t. $\sum_j a_j^2=1$（$S_z$=投影值标准差，$D_z$=局部密度，$a$=投影/权重向量）。
4) 加权综合：$S_i=\sum_j w_j z_{ij}$。
（符号：$p_{ij}$=第 i 对象第 j 指标比重；$v^\pm$=正/负理想解；$C_i$=贴近度；$S_z,D_z,a$=投影寻踪量。）

## 符号与前提
- **符号**：见上式；指标无量纲化、权重和为 1。
- **适用前提**：多指标评价、无先验权重或避免主观；指标方向/量纲已处理、相关性已诊治。

## 推导链
1. 选指标、正向化、无量纲化。
2. 客观定权（熵权/投影寻踪/PCA）或叠加 AHP 校准。
3. 用 TOPSIS 贴近度/加权综合排序。
4. 结合后续约束/优化，先"评价收敛"再规划。

## 数值算例
- 2021C：6 指标定权（稳定性 0.31 最高等）、EWM+TOPSIS 得 Top3 ≈0.94/0.88/0.84、取 top50。示例仅示意。

## 陷阱
- 指标方向（成本型）未正向化；熵权对 0/极端值敏感；相关性/冗余未去（用 PCA/主成分）；AHP 主观；剔除/异常无敏感性；评价口径与规划口径不一致。
