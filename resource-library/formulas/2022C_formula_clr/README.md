# 公式：成分数据闭合与中心对数比变换（clr）

- **category**：formulas
- **entry_id**：2022C_formula_clr
- **source**：自写提炼（2022 CUMCM C 题 C065/C155/C229 的共性）。
- **tags**：闭合、几何均值、clr、成分数据、缺失替换

## 公式
1) 闭合（定和 c）：$C(x)=\big(c x_1/\sum_k x_k,\dots,c x_D/\sum_k x_k\big)$。
2) 几何均值：$g(x)=\big(\prod_k x_k\big)^{1/D}$。
3) 中心对数比变换：$clr(x)=\big(\ln\frac{x_1}{g(x)},\dots,\ln\frac{x_D}{g(x)}\big)$（把单形等距映射到欧氏空间，且 $\sum_j clr_j=0$）。
4) 零/缺失替换（乘法替换）：$r_{ij}=x_{ij}(1-\sum_{k:x_{ik}=0}\delta_{ik}/c)$（$x_{ij}>0$）、$r_{ij}=\delta_{ij}$（$x_{ij}=0$），$\delta$=检出下限/列小值。
（符号：$x$=成分占比；$c$=定和常数；$g(x)$=几何均值；$clr$=中心对数比；$\delta$=零/未检出替换值。）

## 符号与前提
- **符号**：见上式；占比（%或 0~1），clr 无量纲。
- **适用前提**：变量为成分/占比、满足定和且只含相对信息；无 0（或 0 已按检出下限替换）；需在保持总量/相对信息的前提下做欧氏分析。

## 推导链
1. 识别成分数据（定和、只含相对信息、缺失=未检出）。
2. 剔除有效度外样本、对未检出/0 做替换。
3. 用闭合/几何均值/扰动把相对信息规范化，再 clr 映射到欧氏空间。
4. 在欧氏空间做相关/聚类/分类/回归；需要时 clr 逆变换还原（保守恒）。

## 数值算例
- 2022C：clr 后做相关/分类，用 clr 逆变换把风化前预测还原为累加和=100% 的成分。示例仅示意。

## 陷阱
- clr 在 0 处无定义（须替换，且"未检出≠0"）；clr 冗余（分量和为 0）需注意；闭合/几何均值与"含量百分比"口径不同（展示要注明）；对补值、量纲预处理敏感性要检验。
