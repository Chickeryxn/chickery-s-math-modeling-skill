# 公式：传热机理模型与分段参数辨识

- **category**：formulas
- **entry_id**：2020A_formula_heat_ode
- **source**：自写提炼（2020 CUMCM A 题 A070/A147/A195/A212 的共性）。
- **tags**：热传导、牛顿冷却、有限差分、分段参数、炉温曲线

## 公式
1) 一维热传导：$\frac{\partial T}{\partial t}=\alpha\frac{\partial^2 T}{\partial x^2}$，$\alpha=k/(c\rho)$；对流边界 $-k\frac{\partial T}{\partial x}+h T=h T_{air}$。
2) 集总参数（Newton 冷却）：$\frac{dT}{dt}=-k(t)\big(T(t)-T_{air}(t)\big)$，$T_{air}$ 沿炉呈"分段线性+指数"分布。
3) 炉温曲线（线性区域/指数趋近）：$T_e=T_i-(T_i-T_s)e^{-t/\tau}$，$\tau=\rho VC_p/(hA)$；$\tau$/$k$ 分段辨识。
4) 参数辨识（最小二乘）：$\min_\theta\ \sum_i (T_{model}(t_i;\theta)-T_{obs}(t_i))^2$；$\mathrm{RMSE/MAE}$ 度量。
（符号：$T$=温度，$x$=厚度，$t$=时间，$\alpha$=热扩散率，$k$=导热，$c$=比热，$\rho$=密度，$h$=对流传热系数，$T_{air}$=环境温度，$\tau$=热时间常数，$T_s$=初始温度，$T_i$=温区设定温度。）

## 符号与前提
- **符号**：见上式；温度 ℃（或 K，勿混），时间 s，长度 m（板厚 mm），$\alpha$ m²/s，$h$ W/(m²·K)，$k$ W/(m·K)。
- **适用前提**：一维传热/集总参数近似；参数可由附件观测曲线拟合；升/降温机理不同则分模型、参数分段。

## 推导链
1. 由机理（能量守恒/傅里叶定律）写 PDE 或 ODE。
2. 给出环境温度 $T_{air}$ 沿炉分布（分段线性+指数）。
3. 用有限差分（显式/隐式，注意 Courant 稳定）或解析解正演。
4. 用观测曲线最小二乘辨识 $\alpha/h/k/\tau$，并分段。

## 数值算例
- 2020A：拟合 $\tau_1\approx57.4$s（前段）、$\tau_2\approx43.7$s（后段）、$h\approx14.46$ W/(m²·K)、分段 $\alpha\sim(2.4\sim7.4)e-11$ m²/s；关键点温度约 129/166/188/223℃。示例仅示意。

## 陷阱
- 单位/范围（℃ vs K、cm/min vs cm/s、板厚 mm vs m、$h$ W/mm²·K vs W/m²·K）；差分格式稳定性与网格误差；分段/分模型边界；忽略热辐射/对流的假设。
