# 公式：信贷组合优化模型（额度/利率/约束/多目标 + 外部冲击）

- **category**：formulas
- **entry_id**：2020C_formula_portfolio_opt
- **source**：自写提炼（2020 CUMCM C 题 C109/C142/C170/C227/C305 的共性）。
- **tags**：组合优化、额度利率、多目标、约束、外部冲击、RAROC

## 公式
1) 目标（多目标加权）：$\max\ \sum_i\big[a_i r_i(1-d_i)-a_i\,d_i\,LGD\big](1-l_i)-\sum_i M_i l_i$，$\min\ \mathrm{Risk}$（如 $\max_i\{(1-d_i)a_i\}$ / 集中度 / CVaR）。
2) 约束：$10\le a_i\le100$、$4\%\le r_i\le15\%$、$\sum a_i\le T$、期限、流失率 $\le\bar l$；$d_i=d(\text{评分}_i)$、$l_i=l(r_i)$。
3) 外部冲击（乘数/折价）：指标 $z_j'=z_j\times\mu_{j}$（按行业/规模）、风险乘数 $\beta$（聚类分层×评级交叉）、信贷基准/优惠（FTP、利率下浮）。
4) RAROC / 违约金字塔分档：$RAROC=\frac{r\,a(1-d)-a\,d\,LGD}{a\,(1-d)}$；按评级分档定利率下界。
（符号：$a_i$=额度（万元），$r_i$=年利率，$d_i$=违约概率，$LGD$=违约损失率，$l_i$=客户流失率，$M_i$=客户价值，$T$=总预算，$\mu_j/\beta$=外部冲击/风险乘数。）

## 符号与前提
- **符号**：见上式；额度万元、利率 %、概率无量纲、金额元。
- **适用前提**：先由评分给违约概率/评级；组合层面关注相关性/集中度；外部冲击用乘数/折价/情景。

## 推导链
1. 定义决策（额度/利率/是否放贷）与目标（收益-风险-流失）。
2. 写约束（额度/利率/总额/期限/流失率）。
3. 用违约概率/评级作为系数，加外部冲击乘数/折价。
4. 用非线性规划/GA/LINGO/fmincon 求解；给约束满足与敏感性；关注组合相关性/集中度。

## 数值算例
- 2020C：Q1 总预算 5000 万（A 5.85%/99.99 万、B 7.5%/53.5 万、C 11%/10 万），Q2/Q3 总预算 1 亿；利润约 143.8/393.97/89.51 万元（口径不一）。示例仅示意。

## 陷阱
- 单位（元 vs 万元）、结果满足自身约束（各行加总=总额）；同一损失率前后矛盾（0.22 全损 vs 只损利息）；"最大单笔风险/同等级同违约率"低估组合相关性；多目标加权/乘数主观无敏感性；硬截断"概率>50% 拒贷"。
