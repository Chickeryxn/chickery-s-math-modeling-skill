# 公式：响应面/回归 与 收率定义/标准化

- **category**：formulas

- **source**：自写提炼（2021 CUMCM B 题 B007/B026/B050/B160 的共性）。

## 公式
1) 业务定义：收率 $\omega=\eta\times z$（转化率×选择性）。
2) 一元二次（温度）：$\eta(T)=\beta_0+\beta_1 T+\beta_2 T^2$；S 型/Logistic、三次多项式为候选。
3) 标准化：$x^*=(x-\bar x)/\sigma$（或 $\beta_j=\beta_j^*\sqrt{L_{yy}/L_{jj}}$），用标准化系数比较影响度。
4) 多元二次响应面（含交互）：$y=\beta_0+\sum_j\beta_j x_j+\sum_{j<k}\beta_{jk}x_jx_k+\sum_j\beta_{jj}x_j^2$。
5) 双因素方差分解：$SS_{total}=SS_A+SS_B+SS_{AB}+SS_c$，$F=MS_A/MS_c$。
（符号：$\eta$=转化率，$z$=选择性，$\omega$=收率；$x_j$=因素（质量/负载量/装料比/浓度/温度）；$\beta$=回归系数；$SS/MS/F$=方差分解。）

## 符号与前提
- **符号**：见上式；转化率/选择性/收率无量纲或 %，温度 ℃，质量 mg，负载量 wt%。
- **适用前提**：关系为"非线性/含交互、可先按同场指标定型"；样本足以拟合所选参数数（防过拟合）；因素可量化、区间已知。

## 推导链
1. 在候选模型上同场比 R²/MSE 定型（且参数数<样本量）。
2. 用逐步回归提取主效应与交互、标准化去量纲。
3. 用双因素/逐步回归做显著性判断（谁影响大）。
4. 把目标（收率）用响应面代入，做盒约束优化（fmincon/quadprog）。

## 数值算例
- 2021B：二次 R²≈0.98（候选最优先择），温度对转化率/选择性影响均最大、收率峰值约 406~450℃（51.31%~56.3% 因口径/模型而异）、<350℃ 约 29.8%~38.5%。示例仅示意，非唯一答案。

## 陷阱
- 口径：转化率 vs 选择性 vs 收率混用；装料比 vs 负载量；正文系数与代码/目标不符；Logistic x_m 远>100%（作代理判据）；"n 点对 n 参必 R²=1"（防过拟合）；优化区间外推（250-450 vs 300-500）；目标含交叉项非凸。
