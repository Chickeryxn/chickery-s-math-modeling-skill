# 公式：上车点 / 乘车效率优化 与 短途优先权插队

- **category**：formulas
- **entry_id**：2019C_formula_boarding_efficiency
- **source**：自写提炼（2019 CUMCM C 题 C044/C137/C308 的共性）。
- **tags**：泊位排队、效率、目标优化、蒙特卡洛、优先权、收益均衡

## 公式
1) 效率：$\eta=\dfrac{1}{\frac1n\sum_i t_p^i+\frac1m\sum_j t_c^j}$（平均乘客逗留 + 平均车辆逗留；越小越优）。
2) 目标（上车点/泊位）：$\max\ \eta$，s.t. 泊位数 $k\le$上限、安全（泊位×限速、反应时间、双车道）；用蒙特卡洛搜索 $k$。
3) 优先权（短途再返回插队）：$g(m_0)=\varepsilon_1\dfrac{\beta_{long}-\beta_{short}}{\Delta\beta_{max}}+\varepsilon_2\dfrac{W_{long}-W_{short}}{\Delta W_{max}}$（空载率差 + 单位时间收益差加权），令 $g$ 极小给插队位置 $m_0$。
4) 上车完成/可行：$P_n=(1-e^{-\lambda t})^n$（/服务完成概率）。
（符号：$\eta$=乘车效率，$t_p,t_c$=乘客/车辆逗留，$k$=泊位数，$\beta$=空载率，$W$=单位时间收益，$m_0$=插队位置，$\varepsilon$=权重，$\lambda$=到达率。）

## 符号与前提
- **符号**：见上式；时间 min、率 辆或人/h、效率无量纲、泊位/位置单位。
- **适用前提**：两层/双车道乘车区；需在安全与批次放行约束下最大化总乘车效率；短途优先使收益均衡。

## 推导链
1. 定义效率（乘客+车辆逗留）与目标。
2. 写约束（泊位数、安全距离、双车道、批次放行）。
3. 用排队论/蒙特卡洛搜索最优泊位数/上车点；给效率与敏感性（λ/L/v ±10%）。
4. 优先权：用价值函数（空载率+单位时间收益差）给短途再次返回的插队位置，使收益均衡。

## 数值算例
- 2019C：双车道、泊位约 5/10、184 辆/h；不同 λ 下效率约 0.0465/0.045/0.135（人车相当折中最优）；短途（如 15km）插队约 31 位。示例仅示意，口径不一。

## 陷阱
- 目标不可封闭（用仿真）；"上车点非越多越好"需定量；效率/优先权权重主观；参数（k1/k2/v/τ/β）无来源；收益为负时"最大化"实为损失最小化；无参考/误差带比对。
