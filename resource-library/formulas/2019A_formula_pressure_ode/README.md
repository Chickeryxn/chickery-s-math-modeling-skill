# 公式：高压油管守恒/节流/本构 与 周期边界

- **category**：formulas
- **entry_id**：2019A_formula_pressure_ode
- **source**：自写提炼（2019 CUMCM A 题 A023/A190/A240 的共性）。
- **tags**：质量守恒、节流律、本构、周期边界、集总

## 公式
1) 质量守恒（0D）：$\frac{d\rho_2}{dt}=\frac{1}{V}[\rho_1 I(t)-\rho_2 O(t)]$（/$\frac{dm}{dt}=\rho_I I-\rho E$，$m(0)=\rho(0)V$）。
2) 孔口节流律：$Q=CA\sqrt{\frac{2\Delta P}{\rho}}$（$C=0.85$，$A$=孔面积，$\Delta P$=孔两侧压差）。
3) 本构：$dP=\frac{E(P)}{\rho}d\rho$（积分+拟合 $E$-$P$ 二次曲线后定标，如 $\rho_0=0.850$mg/mm³↔$100$MPa）。
4) 周期边界：喷油周期 $100$ms、进油周期 $T+10$ms、凸轮 $2\pi/\omega$、柱塞腔 $P_c(kT_c)=0.5$MPa。
（符号：$\rho$=密度（mg/mm³），$P$=压力（MPa），$I,O$=进/出流量，$V$=管腔容积，$C$=流量系数，$A$=孔面积（mm²），$E$=弹性模量，$T$=开阀时长，$\omega$=凸轮角速度。）

## 符号与前提
- **符号**：见上式；密度 mg/mm³、压力 MPa、体积 mm³、流量 mm³/ms。
- **适用前提**：集总（数量级证明：压力波速/流速/相对进出体积使空间非均匀可忽略）；周期脉冲输入；阀门开闭逻辑已知。

## 推导链
1. 由数量级论证用集总参数（0D）。
2. 写质量守恒 ODE（进/出流量由节流律给）。
3. 用 $dP=(E/\rho)d\rho$ + 拟合 $E$-$P$ 定标，得到 $P$-$ρ$ 本构。
4. 加周期边界（喷油/进油/凸轮/腔压复位），差分离散。

## 数值算例
- 2019A：$V\approx39270$mm³、$A=\pi\cdot0.7^2\approx1.539$mm²、$C=0.85$、$\rho_I(160\mathrm{MPa})=0.87143$、$\rho(0)=0.850$；开阀 $T\approx0.29$ms（100MPa）等。示例仅示意。

## 陷阱
- 单位（rad/s vs rad/ms、MPa、mg/mm³、ms）；$E$-$P$ 拟合对 $\rho$ 积分是简化；$Q=CA\sqrt{2\Delta P/\rho}$ 的 $\rho$ 取高压/低压侧不同；集总假设抹掉压力波；针阀面积取 min{S1,S2}。
