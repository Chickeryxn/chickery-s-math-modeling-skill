# 赛后复盘模板（Post-Contest Review）

> 目的：把一次竞赛变成可复用的判断力。**复盘的对象是"你的建模判断"，不是"分数"。**
> 建议在提交后 1–3 天内完成（记忆还热），用时 30–60 分钟。核心素材：`methods/Qx/qx_decisions.jsonl`（决策账本）、`results/Qx/reports/`、`paper/`。

## 一、决策时间线回放（15 分钟）

从决策账本中按时间导出全部 `DECIDED` 记录，填表：

| 决策 ID | 类型 | 你的选择 | 当时理由（账本原话） | 事后证据（结果/复盘） | 判定：对/错/不确定 |
|---|---|---|---|---|---|
| q1_method_choice | method_choice | M2 | … | … | |
| q1_result_verdict | result_verdict | accept | … | … | |
| … | | | | | |

判定规则：
- **对**：结果与理由一致，且换个更好的方法也不会有实质差别。
- **错**：结果推翻了理由（如假设失效、方法退化、基线更强）。
- **不确定**：证据不足，或差异在误差内——这本身也是发现（下次要收集什么证据）。

## 二、三类典型失败复盘（15 分钟）

1. **假设失败**：哪些"必要假设"在数据/结果上站不住？→ 对 `planning/model_assumptions.md` 补充"现实检验"列。
2. **方法退化**：哪些方法在风险探针/结果中输出退化（分数集中、排名翻转）？→ 记入"方法黑名单与原因"。
3. **时间/预算误判**：哪些环节超时？→ 更新你对"每类题型耗时"的直觉。

## 三、可复用资产沉淀（15 分钟）

- 把本题的"方法—风险—教训"三条写成一行，追加到 `references/upstream/method-index/method-index.md` 的真题演练索引（或你的私人题库）。
- 把"这次最好的一段结果分析/一张图"标记为模板（复制到你的作品集）。
- 把"下次绝不这样做"写成一条红线（如：不验证假设就选模型）。

## 四、学习摘要（自动生成 + 人工补充）

```powershell
python scripts/learning_summary.py . --out results/learning_summary.md
```

脚本从决策账本与冻结数字生成骨架（决策时间线 + 各 Qx 判定 + 冻结值清单）；**"教训"列需要你人工填写**——AI 只摘录事实，不替你总结判断。

## 五、提交复盘成果

- 将 `results/learning_summary.md` 与本题的 `workspace/archived/` 归档保留。
- 若用 `submission` 模式重跑，`frozen_numbers.json` 与三审报告会留下完整证据链，复盘时可追溯每一步。
