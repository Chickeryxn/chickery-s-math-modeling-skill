# Upstream method resources (pointer)

Pointers to repository-level method knowledge. Load only what the current screening needs.

## Repository-level resources

- `references/upstream/method-index/method-index.md` — method family index (self-written): evaluation / prediction / optimization / classification / clustering / mechanism / simulation / graph, one row per family with applicability, typical approaches, risks, and links to upstream repos.
- `references/upstream/method-index/xiaomacoltai-methodology.md` — self-written mapping of XiaoMaColtAI gate timing (M1/P1/P2/W1/W2) to G1–G6 and the 9-point numerical robustness checklist.
- `references/upstream/lupynow-writing/model-selection-matrix.md` — MIT decision matrix; use its conflict-resolution rules (problem features → problem size → user background; candidate A/B anti-homogenization) and its "when not to pick the first choice" column.

## Usage rules

- These resources are **routing aids**, not decision instructions: the human still owns the method choice (G2.5), and every candidate still goes through the risk probe.
- Never copy content from upstream repos that carry no license; the index only links to them.
- Keep the shortlist role-based: one main candidate + one usable baseline + ≤1 conditional fallback.
