# 抽象模式库（Abstraction Patterns）

> 用途：给 agent 在 G2 之前提供"从问题描述到数学结构"的**多范式抽象模板**，确保候选不只有一种视角。
> 使用规则：对每个子问题，先做"抽象四步"（对象→变量→关系→约束/目标），再从下方模式库为**同一问题生成 ≥2 种建模范式**的候选；把"为什么这题不走另一范式"写进方法卡。本库是路由参考，不是决策指令。

## 抽象四步（每步都先于方法选择）

1. **对象**：题中有哪些实体（物品/城市/人群/时间点/资源）？它们之间有什么相互作用？
2. **变量**：哪些是输入（数据/参数）、哪些是决策（要定的）、哪些是状态（随时间/规则演化）？
3. **关系**：实体间是"流量/守恒/因果/博弈/时空临近"哪类关系？给出数学形式（等式/不等式/微分/概率）的**候选骨架**。
4. **约束与目标**：硬约束（必须满足）、软约束（代价）、目标（最大化/最小化什么，输出形式是标量/向量/排名/方案）。

## 多范式生成（每题型给 2–3 种视角）

### 评价/排序类
- **范式 A（客观赋权+聚合）**：熵权/变异系数/CRITIC 定权 → TOPSIS/灰色关联聚合。适用：指标矩阵完整、需可解释权重。
- **范式 B（学习排序）**：若有标签/偏好数据 → 学习排序（rank aggregation、pairwise）。适用：有历史评判数据。
- **范式 C（数据包络）**：DEA 效率前沿（多投入多产出、无需主观权重）。适用：效率对比、规模收益。
- **为什么不走另一范式**：无标签→排除 B；投入产出不明确→排除 C。

### 预测类
- **范式 A（时间序列）**：趋势+季节分解 → 指数平滑/ARIMA/SARIMA；短序列加 GM(1,1)。适用：只有历史序列。
- **范式 B（回归/ML）**：特征驱动（外生变量+滞后）→ 岭回归/RF/XGBoost。适用：有协变量、非线性。
- **范式 C（机理+校正）**：机理模型（如增长曲线）+ 残差校正。适用：有物理/领域规律。
- **为什么不走**：无外生变量→排除 B；无机理→排除 C。

### 优化类
- **范式 A（精确建模）**：LP/MILP/网络流/DP——约束线性化、目标明确。适用：规模适中、需最优解与对偶解释。
- **范式 B（元启发式）**：GA/PSO/SA——非线性/组合爆炸、仅需高质量可行解。适用：大规模、精确法不可行。
- **范式 C（仿真+优化）**：蒙特卡洛/离散事件评估策略 → 结合启发式调参。适用：随机性主导、解析不可行。
- **为什么不走**：规模小且线性→应走 A（元启发式无法证明最优）；随机性强→A 的确定性假设不成立。

### 分类/聚类类
- **范式 A（成分数据+聚类）**：CLR 变换 → 层次/K-Means/DBSCAN。适用：比例/成分型数据（如化学组成）。
- **范式 B（判别模型）**：逻辑回归/RF/SVM（有标签）→ 类别不平衡处理。适用：有明确标签。
- **范式 C（混合模型）**：GMM-EM（软聚类、可解释为分布）。适用：数据呈多峰、需概率归属。
- **为什么不走**：无标签→排除 B；想硬分组→C 的软归属不必要。

### 机理/动力学类
- **范式 A（微分方程）**：ODE/PDE + 数值求解 + 参数拟合。适用：规律可写为连续演化。
- **范式 B（离散/仿真）**：差分方程、元胞自动机、离散事件。适用：离散个体/事件驱动。
- **范式 C（数据驱动替代）**：神经网络/响应面近似机理（黑箱）。适用：机理不明但数据充足。
- **为什么不走**：无解析规律且数据少→A、C 都危险，先考虑 B 的简化版本。

### 图/网络类
- **范式 A（图论精确）**：最短路/流/匹配/生成树/CPM。适用：结构清晰、规模可控。
- **范式 B（组合启发式）**：TSP/VRP 的 GA/邻域搜索。适用：路径/排程大规模。
- **范式 C（网络分析）**：中心性/K-Shell/社区发现（描述性）。适用：只做结构洞察而非决策。

## 简化阶梯（与 3A 决策联动）

复杂模型 → **必要假设**（保留承重关系）→ **简化假设**（可解形式，如线性化/定常/独立）→ **可验证的简化模型**。每降一级要回答：哪个结论会变、误差可接受吗、用什么 baseline 兜底。只有当复杂模型无法在预算内求解/解释时，才沿阶梯下移，并记入方法卡 Fallback trigger。（"3A" 指 `references/README.md` 中"合并 frozen_numbers.json 为唯一数字真相源"这一历史锁定决策的编号；此处仅借其"单一真相源"精神：简化以不破坏可验证性为限。）

## 使用规则

1. 至少两种范式进入候选（除非题目输出唯一锁定一种）。
2. 每个候选的风险探针必须覆盖"该范式的前提"（如 ARIMA 需平稳、LP 需线性）。
3. "为什么不走另一范式"是方法卡的必填项——这既是给评委看的理由，也是逼 agent 想全视角。
