# 顶刊风格图库规范（Publication Gallery）

> 用途：给 `math-figure-generator` 提供"顶刊审美的可执行标准"。顶刊实例图受版权限制不能入库，本库以**自写规范 + 好坏对比文字样例**替代，供 agent 生成前对照、生成后用 `audit_panel_alignment.py` 等机械复核。
> 总原则：**一个图只讲一个主结论；信息密度高但层次清楚；配色克制；文字在最终尺寸下可读。**

## 0. 通用基线（所有图）

- 主色：技能 `color-systems.md` 的 `#1A6FC4`（主方法），baseline 恒灰 `#767676`；方向色（绿升/红降）只用于差异。
- 字体：sans-serif（Arial/DejaVu Sans）；标题 ≥ 10pt，轴标签 ≥ 8pt，刻度 ≥ 7pt；最终排版尺寸下最小 5pt。
- 线宽：主序列 1.6–2.2pt，参考线 0.8–1.2pt 虚线；散点 20–40 像素、边缘白描 0.5pt。
- 坐标：轴标签含单位；不截断误导性坐标轴；图例置于图内（右上/左上）或图下方，不占 >10% 版面。
- 导出：PDF/SVG 矢量（`svg.fonttype=none`、`pdf.fonttype=42`），PNG ≥ 300dpi。
- 多面板：每面板回答一个独立问题；阅读顺序 左→右、上→下 对应论证顺序；共轴时 sharey/sharex 并统一范围。

## 1. 排名/评分类（顶刊：排序条形图 + 参考线）

- 横向条形、按值排序；前 N 名主色、其余灰；标注数值于条端。
- 好样例："Top-10 城市韧性评分（熵权-TOPSIS），基准线=全体均值，误差条=±扰动区间"。
- 坏样例：未排序、颜色随机、无基准线、条端无数值。

## 2. 分布对比类（顶刊：云雨图/小提琴+散点）

- 半边小提琴（KDE）+ 抖动散点 + 中位数/均值标记 + 配对连线（若配对）；组间差异标注显著性。
- 好样例："两组方法误差分布对比（n=50），中位数差 0.31，配对 Wilcoxon p<0.01"。
- 坏样例：只画箱线、无样本点、无统计标注、坐标轴从非零截断。

## 3. 相关/聚类类（顶刊：下三角相关矩阵 + 显著性星号）

- 下三角散点+拟合线+CI，对角直方/KDE，上三角色块（RdBu_r）+ 显著性星号；或环形热图分组。
- 好样例："13 特征相关矩阵：下三角散点、上三角 Spearman ρ（*p<0.05）"。
- 坏样例：整格全色块无星号、色带无标签、特征名重叠。

## 4. 时间序列/多面板（顶刊：共享 x 轴堆叠面板）

- 同时间轴多行面板（原始→分解→残差→预测），共享 x、独立 y；预测区间带淡色填充。
- 好样例："2021–2026 周销量：观测、趋势-季节分解、SARIMA 预测 ±95% 区间"。
- 坏样例：面板间 x 不齐、区间带过深盖住数据、每面板不同时间范围。

## 5. 模型对比/敏感性类（顶刊：参数扫描热图/森林图）

- 森林图：点估计 ±CI 横向排列 + 参考竖线；或双参数网格热图 + 等高线。
- 好样例："超参数敏感性：学习率×树数 网格 RMSE 热图，最优区虚线框标出"。
- 坏样例：3D 曲面遮挡、无等高线/最优标注、色标非线性未注明。

## 6. 结构/机制示意类（顶刊：简洁矢量示意图）

- 3–6 个节点、统一形状语义（矩形=处理、圆角=数据、菱形=判断）、箭头标注流向；≤4 色。
- 好样例："四阶段流水线：数据→特征→模型→验证，菱形处标注人工决策点（G2.5）"。
- 坏样例：超过 8 个节点、颜色随机、箭头无标注、直接贴截图。

## 7. 不确定性表达（跨类通用）

- 误差带/CI 必须与声称一致（±1σ/95% 写清）；点估计必须有来源（冻结宏）；区间与主方法同色浅 50% 透明度。

## 生成后自检（agent 执行）

1. 跑 `audit_panel_alignment.py`/`audit_pdf_text.py`（本仓库 `references/upstream/nature-figure/`，Apache-2.0 引入）做机械复核；
2. 按 `render-check.md` 逐项人眼核对（裁切/重叠/字号/图例/空面板）；
3. 对照本库"好/坏样例"做一次自评，把结论写进 `methods/Qx/qx_figure_table_plan.md`。
