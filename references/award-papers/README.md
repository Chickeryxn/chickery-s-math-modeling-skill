# 历届国赛获奖论文库（award-papers）

> 来源：https://github.com/Chickeryxn/paper （作者本人整理的历届 CUMCM 全国大学生数学建模竞赛获奖论文与赛题）。
> 定位：**论文写作的结构/格式/容量标杆**。生成论文前，按 `references/reference-sources.md` 把这里当作重要参考（`modeling` 模式），只学习组织与容量，不照抄。

## 目录结构

```text
award-papers/
├── 2019/ … 2024/            # 每届获奖论文（.pdf.md 结构化正文 + .pdf.pdf 原始 PDF）
├── 数学建模题目2019/ … 2025/  # 历年赛题与附件
└── ...
```

每篇获奖论文同时提供两种形态：
- `.pdf.md`：从 PDF 转写的结构化 Markdown，**便于逐节学习内容安排与容量**；
- `.pdf.pdf`：原始 PDF，**便于核对最终排版与图表实际效果**。

## 怎么用（写作前对照）

### 1. 内容安排（Structure）
- 摘要如何用一句话点题、每问给出一个关键数字与结论；
- 问题重述、假设、符号说明、问题分析、模型构建/求解、结果分析、稳健性、结论、参考文献的**顺序与衔接**；
- 结果分析如何做到 数值 -> 意义 -> 与基线对比 -> 稳健性 四步。

### 2. 论文格式（Format）
- 章节编号（中文：一、二……与 1.1 小节）、图/表编号与 `ref` 引用；
- 公式编号与交叉引用、符号字体一致性；
- 参考文献格式与 AI 使用声明位置。

### 3. 论文容量（Capacity）
- 每节篇幅、每篇总页数（国赛正文一般 ≤ 30 页、摘要 ≤ 1 页）；
- 每篇配多少张图/表、图注写法、表格取舍；
- 附录与支撑材料清单的规模。

## 使用纪律

- `modeling`（正式建模）模式：可查阅、可借鉴结构/格式/容量，**不得照抄文字或冒充自己的判断**；
- `training`（闭卷）模式：**禁止查看本目录**，直到闭卷解题完成且建模者明确同意开卷对照（training-reflector）；
- 版权：本库为公开参赛获奖论文，使用时应标注来源；仅作学习参考，不用于抄袭。

> 与 `resource-library/` 的关系：resource-library 里已按题型**蒸馏**了这批论文与赛题的要点（papers/ideas/formulas/tables，供生成时快速对照）；本目录存放**完整原始文件**（获奖论文 `.pdf`/`.md` + 历届赛题与附件），供精读全文、核对容量/格式/排版。
